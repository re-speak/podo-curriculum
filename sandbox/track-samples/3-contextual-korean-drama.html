ㄴ 적? 은 적? (ㄴ적 と 은적、どっち？)

동사 끝 글자에 받침이 있으면 은, 없으면 ㄴ!最後の文字にパッチムが あれば「은」、なければ「ㄴ」！

받침 없음 母音で終わる + ㄴ 적
보다
받침 없음
→본 적
가다
받침 없음
→간 적
받침 있음 子音で終わる + 은 적
먹다
받침 ㄱ
→먹은 적
받다
받침 ㄷ
→받은 적

아도? 어도? (아도 と 어도、どっち？)

동사의 마지막 모음을 봐 주세요.動詞の最後の母音を見てください。

ㅏ, ㅗ 最後の母音が ㅏ / ㅗ → 아도

그 외 それ以外の母音 → 어도
먹다 → 먹어도 찍다 → 찍어도
하다 → 해도 (例: 전화해도 돼요?)

ネイティブのコツ

「~지 않아요?」를 붙이면 더 부드럽게 들려요. 確信せず、そっと確認するニュアンス。

본 적 있어요? → 본 적 있지 않아요? 見たことありますか？ → 会ったこと、ありませんか？（やわらかい）

친구 사이라면 「요」를 빼고 더 편하게 말해요.

물어봐도 돼요? → 물어봐도 돼? 聞いてもいい？（タメ口）
