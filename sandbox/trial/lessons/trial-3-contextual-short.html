ㄴ 적과 은 적 (ㄴ적 と 은적、どっち？)

동사에서 다를 떼고, 남은 글자를 봐 주세요. 받침이 없으면 ㄴ, 있으면 은이에요.動詞から「다」を取って、残った文字を見てください。パッチムがなければㄴ、あれば은です。

받침 없음 母音で終わる → ㄴ 적
보다 → 본 적 가다 → 간 적 만나다 → 만난 적
받침 있음 子音で終わる → 은 적
먹다 → 먹은 적 읽다 → 읽은 적 받다 → 받은 적

ㄴ과 은 고르기 (ㄴ と 은 を選ぼう)

받침을 보고, 맞는 쪽을 눌러 보세요.パッチムを見て、正しいほうをタップしてください。

食べたことがあります。 먹은/ㄴ 적 있어요.
行ったことがあります。 가은/ㄴ 적 있어요.
読んだことがあります。 읽ㄴ/은 적 있어요.
会ったことがあります。 만나ㄴ/은 적 있어요.

ㅏ · ㅗ 最後の母音が ㅏ か ㅗ → 아도 돼요?

그 외 それ以外の母音 → 어도 돼요?
먹다 → 먹어도 찍다 → 찍어도 읽다 → 읽어도
하다 → 해도 돼요?보다 → 봐도 돼요?

ネイティブのコツ

끝을 돼요? 대신 될까요?로 바꾸면 훨씬 조심스러워져요.

最後を「돼요?」から「될까요?」に変えるだけで、ぐっと遠慮ぎみになります。

여기 앉아도 돼요? → 여기 앉아도 될까요?（はじめて会う人に）
혹시 번호 물어봐도 돼요? → 혹시 번호 물어봐도 될까요?（ドキドキするとき）
