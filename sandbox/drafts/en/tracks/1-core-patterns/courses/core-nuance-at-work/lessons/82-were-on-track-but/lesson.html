GOAL

We're on track, but (順調ですが)

Summarise where a task stands and flag a possible delay early. タスクの進み具合をまとめ、遅れそうな点を早めに伝えましょう。

Give the current status 現在の進み具合を伝える
Name the deadline 期限を示す
Flag the main risk 一番大きなリスクを伝える

Words you already know (もう知っている単語)

Start with three familiar words, then use them in today's patterns. まず知っている3つの単語を確認して、今日のパターンで使いましょう。

プロジェクト → project

PART 1

We're on track to ___ by ___.

今のペースなら、いつまでに何が終わる見込みかを伝えます。

Today's pattern (今日のパターン)

Meaning & use 意味・使い方 Use this to give a positive progress forecast tied to a concrete deadline. 具体的な期限とともに、順調な進捗の見通しを伝える言い方です。

We’re on track to finish by Friday. 金曜日までに終える予定で、順調に進んでいます。
We’re on track to send the draft by noon. 正午までに下書きを送れるよう、順調に進んでいます。
We’re on track to get approval by tomorrow. 明日までに承認を得られるよう、順調に進んでいます。

Read together (一緒に読もう)

Read the four sentences. 4つの文を読みましょう。

We're on track to finish the report by Friday. 金曜日までにレポートを終える予定で、順調です。
We're on track to send the draft by noon. 正午までに下書きを送れる予定で、順調です。
We're on track to ship the order by Tuesday. 火曜日までに注文を出荷できる予定で、順調です。
We're on track to get approval by tomorrow. 明日までに承認を得られる予定で、順調です。

Tie the forecast to a deadline (見通しを期限につなげよう)

This is a progress forecast rather than a promise, so update it when the risk changes. これは約束ではなく進捗の見通しなので、リスクが変わったら更新します。

on track to + plain verb + by + deadline Status plus deadline進捗と期限 on track to finish by Friday on track to send by noon

PART 2

The main issue is that ___.

よい進捗を伝えたあと、遅れにつながる一番大きな問題を早めに示します。

Today's pattern (今日のパターン)

Meaning & use 意味・使い方 Use this to name the one risk that most needs the other person's attention. 相手が最も注意すべき一つのリスクをはっきり示す言い方です。

The main issue is that the supplier’s late. 一番の問題は、取引先が遅れていることです。
The main issue is that the draft isn’t ready. 一番の問題は、下書きの準備ができていないことです。
The main issue is that we’re waiting for approval. 一番の問題は、承認を待っていることです。

Read together (一緒に読もう)

Read the four sentences. 4つの文を読みましょう。

The main issue is that the shipment is delayed. 一番の問題は、出荷が遅れていることです。

Name the risk early (リスクを早めに伝えよう)

State the risk early enough for the other person to respond instead of hiding it after a long introduction. 長い前置きのあとに隠さず、相手が対応できる早さでリスクを伝えます。

You are giving a project update; read your lines while I read the manager. プロジェクトの進捗を報告する場面で、自分のセリフを読み、私は上司を読みます。

Native tip (ネイティブのひとこと)

Choose the stronger or softer opening according to how certain and serious the risk is. リスクの確かさと深刻さに合わせて、強い言い方かやわらかい言い方を選びます。

The central, confirmed risk 中心となる確かなリスク The main issue is that the supplier's late. 一番の問題は、取引先が遅れていることです。
Pick by meaning 意味で選ぶ
A possible or less certain risk 可能性のあるリスク One concern is that the supplier may be late. 懸念の一つは、取引先が遅れるかもしれないことです。
