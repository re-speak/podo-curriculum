GOAL

I was wondering if you could (もしよければ、していただけますか)

Make a diplomatic request and offer a bounded alternative.丁寧に頼み、範囲を限った代案を出しましょう。

I was wondering if you could extend the deadline.期限を延ばしていただけないでしょうか。
What I can do is send you the first half.私にできるのは、前半を送ることです。
How about you?あなたはどうですか？

Could you or would you be able to? (could you と would you be able to)

Both are polite. “Would you be able to” puts extra focus on practical availability.どちらも丁寧です。「Would you be able to」は、実際に対応可能かにより焦点を当てます。
