One useful rule (一つのルール)

Can carries the grammar, so the next verb stays plain—never add to or -s.can が文法を担うので、次の動詞は原形のままにし、to や -s はつけません。

PATTERN 2

I can ride a bike, but I can't drive.

See the pattern (パターンを見よう)

Ask about an ability and contrast what you can and cannot do.できることをたずね、できることとできないことを対比しましょう。

I can ride a bike, but I can't drive.自転車には乗れますが、運転はできません。
I can walk, but I can't run.歩くことはできますが、走ることはできません。
I can cook, but I can't bake.料理はできますが、お菓子作りはできません。

Read the sentences (文を読もう)

Read the four sentences.4つの文を読んでみましょう。

I can ride a bike, but I can't drive.自転車には乗れますが、運転はできません。
I can walk, but I can't run.歩くことはできますが、走ることはできません。
I can cook, but I can't bake.料理はできますが、お菓子作りはできません。
I can read it, but I can't write it.読むことはできますが、書くことはできません。
