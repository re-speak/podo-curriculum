PATTERN 1

I'd like the chicken, please.

See the pattern (パターンを見よう)

Order something politely in two common ways.よく使う二つの言い方で、丁寧に注文しましょう。

I'd like the chicken, please.チキンをお願いします。
I'd like the soup, please.スープをお願いします。
I'd like this one, please.これをお願いします。

Read the sentences (文を読もう)

Read the four sentences.4つの文を読んでみましょう。

I'd like the chicken, please.チキンをお願いします。
I'd like the soup, please.スープをお願いします。
I'd like this one, please.これをお願いします。
I'd like a ticket, please.チケットを1枚お願いします。

How it works (形を見よう)

Keep I'd like together, add the complete item, and put please at the end.I'd like をひとまとまりにし、品物を続け、最後に please を置きます。

I'd like the chicken, please.チキンをお願いします。

Build the sentence (文を組み立てよう)

Put the three meaning chunks in order.3つの意味のまとまりを順番に並べましょう。

please.the chicken,I'd like
スープをお願いします。
please.the soup,I'd like
これをお願いします。
please.this one,I'd like

please.a ticket,I'd like

Read the sentences (文を読もう)
