PART 2

The sooner we start, the sooner we can finish.

早く始めるほど結果も早くなるときに使います。

Today's pattern (今日のパターン)

Meaning & use 意味・使い方Use this when an earlier start brings an earlier result.早く始めるほど結果も早くなるときに使います。

The sooner we start, the sooner we can finish.早く始めるほど、早く終えられます。
The sooner we leave, the sooner we can arrive.早く出るほど、早く着けます。
The sooner we decide, the sooner we can book.早く決めるほど、早く予約できます。
