Today's pattern (今日のパターン)

Meaning & use 意味・使い方Use need to when the situation makes an action necessary.状況によって行動が必要になったときに need to を使います。

If you feel worse, you need to get help.もっと具合が悪くなったら、助けを求める必要があります。
If you feel worse, you need to call home.もっと具合が悪くなったら、家に電話する必要があります。

Direct or softer? (直接・やわらかく)

Add “maybe” before should when you want the advice to sound less direct.助言をやわらかく伝えたいときは、should の前に「maybe」を加えます。

Direct advice直接的な助言You should get some rest.少し休んだほうがいいですよ。
Pick by meaning 意味で選ぶ
Softer suggestionやわらかい提案Maybe you should get some rest.少し休んだほうがいいかもしれません。
