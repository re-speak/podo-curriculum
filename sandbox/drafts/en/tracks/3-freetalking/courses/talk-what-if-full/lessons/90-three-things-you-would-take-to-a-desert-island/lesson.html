Three things you would take to a desert island (無人島に持っていく三つの物)

Let's choose what would matter most on a desert island. Please read the title aloud.無人島で最も大切になるものを選びましょう。タイトルを声に出して読んでください。

Have the learner read the title once, then move on.

What makes an item essential (物を必需品にするもの)

Did you have any questions about the article?記事について何か質問はありましたか？

Answer the learner's questions, then move on. If there are none—or the learner did not complete the pre-study—skip the article; do not spend class time reading it.
A desert-island list compresses survival, comfort, and identity into only three objects.無人島のリストでは、生存、快適さ、自分らしさを三つの物に絞り込みます。
An essential item addresses a need whose delay would carry a serious cost.必需品とは、先延ばしにすると重大な結果が出る必要を満たす物です。essential item必需品
Practical equipment can outrank a treasured possession when conditions are harsh.厳しい状況では、大切な持ち物より実用的な道具が優先されることがあります。
Comfort is not automatically frivolous; rest and hope can support endurance.快適さは必ずしも無駄ではなく、休息や希望が耐える力を支えます。
A versatile object earns its place by meeting several different needs.多用途の物は、複数の必要を満たすことで選ぶ価値が高まります。
The object that almost made the list reveals which need was sacrificed.最後に外した物は、どの必要を犠牲にしたかを示します。
An apparently useless object may protect memory, motivation, or a sense of self.一見役に立たない物でも、記憶や意欲、自分らしさを守る場合があります。
Regret often attaches to the meaningful object left behind rather than the practical object selected.後悔は、選んだ実用品より、置いてきた大切な物に結びつくことがあります。
Adding a companion changes the scenario from inventory management to shared responsibility.同行者が加わると、持ち物の管理ではなく、責任を分け合う状況に変わります。
No list is sensible until the environment and available resources are known.環境や利用できる資源が分からなければ、妥当なリストは作れません。

8 QUESTION POOL

Let's talk (話そう)

We don't need to answer every question. Let's follow the most interesting parts of your answers.全部の質問に答える必要はありません。答えの中でいちばん面白いところを広げていきましょう。

Treat these pages as a pool, not a sequence. React or share briefly before choosing the next prompt, skip freely, and move to feedback with 2–3 minutes left.

Three objects (三つの物)

WARM-UP 1Which three objects would give you the best chance of managing life on a desert island?無人島で暮らすために最も役立つ三つの物は何ですか？

Follow up
  • Which need would you address first?
  • Which selection or need is the most essential?

Why those three (その三つの理由)

WARM-UP 2Which underlying need should determine a desert-island packing list?無人島への持ち物リストを決めるべき基本的な必要は何ですか？

Follow up
  • Which object would address that need most reliably?
  • Which secondary need should follow?

The near-pick (選びかけた物)

QUESTION 1Which object would compete most strongly for the final place on a three-item list?三つの持ち物の最後の一枠を最も強く争う物は何ですか？

Follow up
  • Which capability would that object add?
  • Which trade-off should determine the final place?

The useless one (役に立たない一つ)

QUESTION 2Would any apparently useless object still earn a place?一見役に立たない物でも、選ぶ価値がありますか？

Follow up
  • Which emotional need would it meet?
  • Which form of comfort would you sacrifice?

Left behind (置いていく物)

QUESTION 3Which object could you regret excluding, if any?外すと後悔しそうな物があるとすれば、何ですか？

Follow up
  • Which unmet need makes that object memorable?
  • Which practical priority could keep it outside a three-item limit?

What the island has (島にあるもの)

QUESTION 4Which unknown condition on a desert island would most change what you packed?無人島のどの未知の条件が、持ち物を最も大きく変えますか？

Follow up
  • Which available resource would remove one selection or need?
  • Which risk would force a complete rethink?

One person (一人の同行者)

QUESTION 5How would one companion change the risks and responsibilities of island life?一人の仲間がいることで、島での危険と責任はどう変わりますか？

Follow up
  • Which responsibility would you share?
  • Which burden would be simpler alone?

Coming home (帰ったあと)

QUESTION 6Which survival object would have the lowest value once ordinary life resumed?普通の生活に戻った後、最も価値が低くなるサバイバル用品は何ですか？

Follow up
  • Which island condition gave one most of its value?
  • What would make its value persist or disappear after the return?
