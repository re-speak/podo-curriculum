Have the learner read the title once, then move on.

When free changes behaviour (無料が行動を変えるとき)

Did you have any questions about the article?記事について何か質問はありましたか？

Answer the learner's questions, then move on. If there are none—or the learner did not complete the pre-study—skip the article; do not spend class time reading it.
Permanent free access can change frequency, habits, expectations, and value as well as cost.永久に無料になると、費用だけでなく頻度、習慣、期待、価値も変わります。
Removing price can increase use even when the additional use creates little benefit.価格をなくすと、追加の利用にほとんど利益がなくても使用が増える場合があります。
The most expensive option is not necessarily the most valuable if it rarely fits daily life.最も高価な選択肢でも、日常に合わなければ最も価値があるとは限りません。
A practical choice saves friction, while an aspirational choice may open experiences that were previously inaccessible.実用的な選択は手間を減らし、理想的な選択は今まで届かなかった経験を可能にします。
Sharing access, time, or experience can spread the benefit without turning it into a resale business.利用、時間、経験を共有すれば、転売せずに利益を広げられます。
Reselling free access raises legal, contractual, and fairness questions before it raises profit.無料の利用権を転売するなら、利益より先に法律、契約、公平さの問題が生まれます。resell転売する
An unexciting essential may create more lasting value than a glamorous luxury.目立たない必需品のほうが、華やかなぜいたく品より長く価値を生む場合があります。
A zero price does not eliminate the opportunity costs of time, space, attention, and environmental impact.価格がゼロでも、時間、空間、注意、環境への影響という機会費用はなくなりません。
Permanent access can reveal whether genuine interest or scarcity created the original desire.永久に利用できると、本当の関心と希少性のどちらが、もともとの欲求を生んだのか分かることがあります。
The useful question is which ordinary limitation the free option would actually remove.大切なのは、その無料の選択が日常のどの制限を実際になくすかです。

8 QUESTION POOL

Let's talk (話そう)

We don't need to answer every question. Let's follow the most interesting parts of your answers.全部の質問に答える必要はありません。答えの中でいちばん面白いところを広げていきましょう。

Treat these pages as a pool, not a sequence. React or share briefly before choosing the next prompt, skip freely, and move to feedback with 2–3 minutes left.

Free for life (一生無料)

WARM-UP 1Which service would create the greatest lifetime value if it were permanently free?どのサービスが永久に無料なら、生涯で最も大きな価値を生みますか？

Follow up
  • Which recurring cost or difficulty would disappear?
  • Which practical or personal benefit supports the choice?

Real use (実際の利用)

WARM-UP 2How much actual use would justify choosing one permanently free service?一つのサービスを永久に無料にする選択は、実際にどのくらい使えば正当化されますか？

Follow up
  • Which service could realistically reach that threshold?
  • Which hidden cost could weaken its value?

A changed week (変わる一週間)

QUESTION 1Which part of an ordinary week could permanent free access change most?永久に無料で利用できると、普通の一週間のどの部分が最も変わりますか？

Follow up
  • Which weekly routine would be altered first?
  • How would the saved resources be used?

Beyond you (自分以外への利益)

QUESTION 2When can non-transferable free access still create value for other people?譲渡できない無料の利用権でも、どんなときにほかの人へ価値を生みますか？

Follow up
  • What legitimate form would sharing take?
  • Which feature makes the access non-transferable?

The boring answer (退屈でも正しい答え)

QUESTION 3Which unexciting service would offer the strongest practical lifetime return?どの地味なサービスが、生涯で最も大きな実用的利益をもたらしますか？

Follow up
  • Which recurring expense would make it superior?
  • Could rational value overcome a less exciting experience?

Reselling (転売)

QUESTION 4When would it be legitimate to resell access to a free service?無料サービスの利用権を転売することが正当になるのは、どんなときですか？

Follow up
  • Which legal or contractual permission would be necessary?
  • Which fairness concern could still rule it out?

Still not free (残る負担)

QUESTION 5Which non-financial costs can survive after a service becomes free?サービスが無料になっても残る、金銭以外の負担は何ですか？

Follow up
  • Which non-financial cost could reverse the decision?
  • What change would make the service worthwhile again?

Paying on purpose (あえて払うもの)

QUESTION 6Which added value could justify rejecting a free alternative?どんな追加価値があれば、無料の代わりを選ばないことが正当化されますか？

Follow up
  • Which added value would justify paying?
  • Which quality makes free access sufficient?
