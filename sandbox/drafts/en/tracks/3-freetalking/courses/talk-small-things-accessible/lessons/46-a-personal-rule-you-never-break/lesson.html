Rules we choose for ourselves (自分で選ぶルール)

Answer the learner's questions, then move on. If there are none—or the learner did not complete the pre-study—skip the article; do not spend class time reading it.
A personal rule turns a repeated decision into a clear boundary.自分のルールは、繰り返す判断を明確な境界に変えます。
It can protect time, money, health, relationships, or peace of mind.そのルールは、時間、お金、健康、人間関係、心の平穏を守れます。
Many strong rules begin after one experience we do not want to repeat.厳しいルールの多くは、二度と経験したくない出来事のあとに生まれます。
The rule makes future choices faster, but too much rigidity can become a problem.そのルールは今後の判断を速くしますが、融通が利かなすぎると問題になることがあります。rigidity融通のなさ
An exception does not always destroy the value of a rule.例外があっても、そのルールの価値がなくなるとは限りません。
Other people may see a boundary as strange when they do not know its history.背景を知らない人には、その境界が変に見えることがあります。
Explaining the reason can be useful, but nobody owes every detail.理由を説明すると役立ちますが、すべての細部を話す必要はありません。
Some rules outlive the problem they were designed to solve.解決するはずだった問題がなくなったあとも残るルールがあります。
Reviewing a rule is different from breaking it carelessly.ルールを見直すことと、軽く破ることは違います。
The best rule still serves a clear purpose today.よいルールには、今でも明確な役割があります。

Conversation style (会話スタイル)

8 QUESTION POOL

Let's talk (話そう)

全部答えなくても大丈夫です。一つの答えをゆっくり広げましょう。

One personal rule (一つの自分ルール)

WARM-UP 1Is there something you never do, by choice?自分で決めて、絶対にしないことはありますか？

Follow up
  • If there is, how would you state the rule simply?
  • If there is not, what decision would benefit from a clear rule?

How strict (厳しさ)

WARM-UP 2How strict is that real or possible rule?その実際のルール、または作るとよいルールは、どのくらい厳しいものですか？

Follow up
  • Would any exception be reasonable?
  • How would you know the boundary had been crossed?

Where it came from (始まり)

QUESTION 1What happened to create the rule, or what could justify it?何があってそのルールができたか、または、何があれば作る理由になりますか？

Follow up
  • Was there one turning point?
  • What cost is the rule meant to prevent?

Ever broken it? (破ったこと)

QUESTION 2Have you ever broken the rule—or ignored a similar boundary?そのルールを破ったこと、または似た境界を無視したことはありますか？

Follow up
  • If you have, what happened afterward?
  • If you have not, is the rule established—or still only an idea?

What others think (ほかの人の見方)

QUESTION 3Would other people find the rule strange?ほかの人は、そのルールを変だと思いそうですか？

Follow up
  • If they would, what part might be hard to understand?
  • If they would not, is the rule more common than it feels?

Explain or keep private (説明する？)

QUESTION 4How much of the reason would you explain to someone affected by the rule?そのルールの影響を受ける人に、理由をどこまで説明しますか？

Follow up
  • What do they genuinely need to know?
  • Which detail can remain private?

Still useful? (役立つ？)

QUESTION 5How would you check whether the rule serves—or could serve—you?そのルールが今役立っているか、または今後役立つかを、どう確かめますか？

Follow up
  • What evidence would support adopting or keeping it?
  • What change would justify revising it?

A rule you need (まだ作れていないルール)

QUESTION 6What personal rule should you make but haven't?作るべきなのに、まだ作れていない自分のルールは何ですか？

Follow up
  • What repeated decision would it simplify?
  • What is the smallest version you could start with?

Today's feedback (今日のフィードバック)

Before we finish, here's one strength and one thing to focus on next.最後に、よかった点を一つと、次に意識する点を一つ伝えます。

Before closing, ask the learner to repeat one useful correction.
