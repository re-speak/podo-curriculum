# Korean curriculum release scope

The first Korean curriculum release contains the **480 written lessons** in these four tracks:

- `1-hangul` — 14 lessons
- `2-core-patterns` — 116 lessons
- `3-contextual-korean` — 140 lessons
- `4-freetalking` — 210 lessons

`5-pronunciation` is deliberately **deferred**. Its ten planned lessons are not missing release
content, are not part of the 480-lesson proofreading gate, and must not block this release. They
will be authored and reviewed as a later curriculum addition.

The table of contents and catalog may continue to show the pronunciation plan so that future work
keeps its intended place. Release-readiness reports must distinguish `planned` from `in scope` and
use 480, not 490, as the denominator for this release.
