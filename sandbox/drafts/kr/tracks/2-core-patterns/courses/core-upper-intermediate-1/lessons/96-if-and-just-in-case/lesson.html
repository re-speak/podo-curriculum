동사 · 형용사 · 명사 (動詞・形容詞・名詞)

동사에는 ‘ㄴ다면’이나 ‘는다면’, 형용사에는 ‘다면’, 명사에는 (이)‘라면’이 붙어요. 명사는 받침이 있으면 ‘이라면’, 없으면 라면이에요.動詞には「ㄴ다면」か「는다면」、形容詞には「다면」、名詞には(이)라면がつきます。名詞はパッチムがあれば「이라면」、なければ「라면」です。

ㄴ/는다면 동사動詞 오다 → 온다면먹다 → 먹는다면
다면 형용사形容詞 부족하다 → 부족하다면바쁘다 → 바쁘다면
(이)라면 명사名詞 부자 → 부자라면학생 → 학생이라면

받침을 보고 ㄹ까 · 을까 (パッチムを見て ㄹ까・을까)

붙이는 법은 ‘텐데’와 같아요. 받침이 없으면 ‘ㄹ까 봐’, 있으면 ‘을까 봐’예요. 뒤에는 이미 한 행동이 오고, ‘하세요’ 같은 시키는 말은 못 와요.つけ方は「텐데」と同じです。パッチムがなければ「ㄹ까 봐」、あれば「을까 봐」です。後ろにはもうやったことがきて、「하세요」のような命令は来られません。

ㄹ까 봐 받침 없음パッチムなし 막히다 → 막힐까 봐오다 → 올까 봐
을까 봐 받침 있음パッチムあり 늦다 → 늦을까 봐없다 → 없을까 봐
뒤에는 한 일 이미 한 행동もうやったこと 막힐까 봐 → 일찍 출발했어요늦을까 봐 → 택시를 탔어요

‘(으)면’과 오늘의 ‘다면’은 둘 다 ‘~면’이에요. 다른 건 거리예요 — 면은 실제로 있을 수 있는 일, 다면은 현실에서 먼 상상이에요. 그래서 상상하는 이야기에는 다면이 더 어울려요.(으)면と今日の다면はどちらも「〜なら」です。違うのは距離で、면は実際に起こりうること、다면は現実から遠い想像です。だから想像の話には다면のほうが合います。
