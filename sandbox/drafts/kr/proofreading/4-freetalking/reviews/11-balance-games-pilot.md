# 밸런스 게임 파일럿 검수

검수 대상:

- `talk-balance-games-advanced/lessons/01-more-money-or-more-time/lesson.html`
- `talk-balance-games-intermediate/lessons/01-more-money-or-more-time/lesson.html`

## 판정

**통과.** 한 개의 밸런스 선택으로 25분 수업을 만들 수 있다. 단, 여덟 번 같은 양자택일을
묻는 방식이 아니라 선택의 근거를 차례로 바꾸어야 한다.

이 파일럿은 다음 순서로 대화를 넓힌다.

1. 돈을 아끼려고 시간을 쓴 최근 장면
2. 자유 시간 세 시간이 생겼을 때의 실제 행동
3. 지금의 첫 선택과 현재 부족한 것
4. 선택한 자원이 늘었을 때 달라질 하루
5. 반대쪽이 더 중요했던 최근 예외
6. 월급과 근무 시간이 함께 늘어나는 가상 조건
7. 미래에 선택을 바꿀 수 있는 사건
8. 반대쪽으로 넘어가는 정확한 경계

빠른 학습자는 24개의 후속 질문까지 쓰고, 천천히 말하는 학습자는 앞부분의 한 답을 길게
이어 갈 수 있다. 모든 질문을 끝내는 것이 목표가 아니라는 공통 안내도 유지했다.

## 자체 교정에서 바로 반영한 것

- 일본어의 직역투 `お金の多い暮らし` / `時間の多い暮らし`를
  `お金に余裕のある暮らし` / `時間に余裕のある暮らし`로 고쳤다.
- `今より必要`가 “지금보다 더 필요하다”로 읽히는 의미 오류를 `今必要`로 고쳤다.
- 고급 지문의 `예상하지 못한 지출을 견디다`를 자연스러운 `지출에 대처하다`로 고쳤다.
- 고급 지문의 `생활비가 불안하다`를 자연스러운 `생활비가 걱정되다`로 고쳤다.
- 질문 3과 질문 6의 일본어를 실제 대화에서 쓰는 질문형으로 고쳤다.
- `누구에게도 변화가 생겨요?`의 모호한 조사를 `주변 사람에게도`로 고쳤다.
- 몸풀기 2의 세 시간은 매일이 아니라 평소 일정에 더해 오늘 한 번 생긴 추가 자유 시간임을
  한국어·일본어 질문과 튜터 노트에 명시했다.
- 중급 지문은 같은 논지를 유지하면서 고급보다 한국어 기준 71자를 줄였고, 질문 2·4·5·6의
  문장 부담을 낮췄다.

## 안전성과 수업 운영

- 정확한 수입이나 금액을 묻지 않도록 질문 1의 튜터 노트에 명시했다.
- 월급 조건은 가상 상황이며 현재 직업이나 실제 금액을 공개하게 하지 않도록 명시했다.
- 어느 쪽이 옳다는 결론을 내리지 않고, 학습자의 현재 조건과 선택 변화에 집중한다.

## 검증 결과

- 고급·중급 각 13페이지, 같은 페이지 순서와 ID
- 각 7줄 양면 지문, 줄마다 강조 2개와 어휘 2개
- 각 8개 본질문과 24개 후속 질문
- 모든 로컬 에셋 참조 해석 성공
- yomi, 인라인 CSS, 인라인 JavaScript 없음
- 184개 작성 덱을 포함하는 11개 교정 패킷 재생성 및 current check 통과
- 교정 패킷 단위 테스트 6개 통과
- 전체 코스 dry-run과 `git diff --check` 통과
- Orca 내장 브라우저에서 440px 카드 폭으로 목표·지문·질문 4·피드백 화면을 확인했고,
  가로 넘침 없이 13페이지 이동, 대화 스타일 선택, 교정칸 추가가 동작했다. 콘솔 오류와
  실패한 lesson asset 요청은 없었다. 브라우저의 별도 `/favicon.ico` 요청만 404였으며 수업
  화면과 무관하다.

## 남은 제품 판단

파일럿 자체에는 막는 문제가 없다. 다만 전체 14과를 쓸 때는 각 주제가 “최근 장면 → 반대
사례 → 조건 변화 → 전환 경계”를 실제로 만들 수 있는지 먼저 확인한다. 계절처럼 가벼운
주제는 이 네 단계를 만들지 못하면 25분 독립 과가 아니라 다른 과의 짧은 몸풀기로 내린다.
