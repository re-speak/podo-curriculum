# Pattern Lesson: 〜을/를 좋아해요 — What Do You Like?

## Design Notes

**Curriculum type:** Absolute-beginner, pattern-based drilling. Speaking-first design where the learner swaps vocabulary into rigid sentence templates.
**Assumed prior knowledge:** Ability to read Hangul and familiarity with the polite copula `~예요/이에요` ("it is ~").

**Two focused concepts ONLY:**

1. **The Object Particle (을/를)**
   - After a consonant (batchim) → **을** (밥을, 물을, 책을, 음악을)
   - After a vowel → **를** (커피를, 영화를, 티비를)

2. **The "Like" Pattern (좋아해요)**
   - Statement: `[noun]을/를 좋아해요.` (I like ~)
   - Negative: `[noun]을/를 안 좋아해요.` (I don't like ~)
   - Q: `[noun]을/를 좋아해요?` (Do you like ~? ↗)
   - Q: `무엇을 (뭘) 좋아해요?` (What do you like?)

*Note: By using ONLY "좋아해요", we completely remove the cognitive load of verb conjugation. The verb looks and sounds exactly the same every time, allowing the learner to focus 100% on attaching the correct particle to the noun. (Earlier draft used 먹어요/마셔요/봐요/들어요 — four different conjugation behaviors, including a ㄷ-irregular — which smuggled four stealth concepts into "vocabulary." Anchoring on one invariant verb fixes that.)*

**Target Nouns (8):** 밥(rice/meal) · 빵(bread) · 물(water) · 커피(coffee) · 책(book) · 티비(TV) · 영화(movie) · 음악(music)

## Lesson Flow (14 Pages)

| Page | Activity                          | Time  | Focus                                   |
| ---- | --------------------------------- | ----- | --------------------------------------- |
| 1    | Greeting & Intro                  | 1 min | Warm-up                                 |
| 2    | Review (예요/이에요)               | 2 min | Fill-in + translate prior knowledge     |
| 3    | Today's Patterns                  | 2 min | 을/를 좋아해요 + particle rule           |
| 4    | Pattern Drill A (Statements/Neg)  | 3 min | I like / I don't like                   |
| 5    | Pattern Drill B (Questions/What)  | 3 min | Do you like? / What do you like?        |
| 6    | Vocab Connect                     | 2 min | Sorting nouns by 을 vs. 를                |
| 7    | Quick Practice                    | 2 min | Multiple choice & Reorder               |
| 8    | Short Dialogues                   | 2 min | 4 rapid-fire Q&A exchanges              |
| 9    | Guided Conversation               | 2 min | Reading a natural "getting to know you" chat |
| 10   | Free Discussion                   | 2 min | Personalizing the patterns              |
| 11   | Roleplay                          | 2 min | Open-ended conversation missions        |
| 12   | Travel in Korea                   | 2 min | Choosing a menu with a friend           |
| 13   | BONUS: Translate                  | 2 min | No-hint translation challenge           |
| 14   | Mission Complete                  | 1 min | Recap and sign-off                      |

### PAGE 3 — Today's Patterns

```text
+-------------------------------------------------------------------------+
|                                                                         |
|  TODAY'S PATTERNS: LIKES & DISLIKES                                     |
|  ==================================                                     |
|                                                                         |
|  THE VERB: 좋아해요 (Like)                                               |
|  The verb stays exactly the same! Just swap the noun in front of it.    |
|                                                                         |
|  1. STATEMENTS & NEGATIVES                                              |
|     • 저는 커피를 좋아해요.                                              |
|       I like coffee.                                                    |
|                                                                         |
|     • 저는 커피를 안 좋아해요.                                           |
|       I don't like coffee. (Put 안 in front of the verb)                 |
|                                                                         |
|  2. ASKING QUESTIONS                                                    |
|     • 커피를 좋아해요? ↗                                                 |
|       Do you like coffee? (Just raise your pitch!)                      |
|                                                                         |
|     • 뭘 좋아해요?                                                       |
|       What do you like? (무엇을 = 뭘)                                     |
|                                                                         |
|  ────────────────────────────────────────────────────────               |
|  THE RULE: Object Particles (을/를)                                     |
|  Ends in a CONSONANT → 을 (밥을, 물을, 책을, 음악을)                      |
|  Ends in a VOWEL     → 를 (커피를, 영화를, 티비를)                        |
|  ────────────────────────────────────────────────────────               |
|                                                                         |
|                                                                  PAGE 3 |
+-------------------------------------------------------------------------+
```

