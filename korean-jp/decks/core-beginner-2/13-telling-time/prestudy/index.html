시 の前の数

「하나 시」ではありません。「한 시」です。前が少し短くなります。「세 개」、「네 잔」と言うときとまったく同じです。「다섯」からはそのままです。

パート 2

N시 N분N シ N プン

N時N分。分になると、数の数え方がとつぜん変わります。今日いちばん大事なところです。

今日のパターン

意味・使い方~時~分分は漢字語の数で数えます。

지금 세 시 삼십 분이에요.チグム セ シ サムシプ プニエヨ 今3時30分です。
지금 아홉 시 십 분이에요.チグム アホプ シ シプ プニエヨ今9時10分です。
지금 열 시 사십오 분이에요.チグム ヨル シ サシボ プニエヨ今10時45分です。

時 と 分、数字がちがう

韓国語は数字が2種類ありますよね？時間は、その2つを1つの文でいっしょに使います。「分」は「일」、「이」、「삼」。「세 시 삼십 분」、こうです。これはまるごと覚えてください。

시シ 사과 세 개、커피 네 잔 と 同じ数 두 시トゥ シ일곱 시イルゴプ シ
분プン 삼천 원 と 同じ数 십 분シプ プン삼십 분サムシプ プン
