게 のうしろに何が来るか

「게」の作り方はパート1と同じです。変わるのはうしろです。別の動詞が来れば、その動作をどうするかになり、「해 주세요」が来れば、その状態に作ってほしいというお願いになります。

게 + 다른 동사ゲ + ほかの動詞 パート1 — どうするか 크다 → 크게 말해 주세요クゲ マレ ジュセヨ짧다 → 짧게 잘라 주세요ッチャルケ チャルラ ジュセヨ
게 해 주세요ゲ ヘ ジュセヨ パート2 — その状態に 맵다 → 덜 맵게 해 주세요トル メプケ ヘ ジュセヨ조용하다 → 조용하게 해 주세요チョヨンハゲ ヘ ジュセヨ
