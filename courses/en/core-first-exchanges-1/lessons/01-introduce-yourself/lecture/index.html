PART 1

I'm Mina.

Use I'm before a name, a state, or a job. Please read the title aloud.I'm の後ろに、名前・状態・仕事を続けます。タイトルを声に出して読んでください。

Have the learner read the title once, then move on.

Today's pattern (今日のパターン)

Meaning & use 意味・使い方Use I'm before a name, a state, or a job.I'm の後ろに、名前・状態・仕事を続けます。

Briefly explain the meaning, then have the learner read each example aloud.
I'm Mina.私はミナです。
I'm happy.私はうれしいです。
I'm a designer.私はデザイナーです。

Read the sentences (文を読もう)

Please read each sentence aloud.一文ずつ声に出して読んでください。

I'm Mina.私はミナです。
I'm happy.私はうれしいです。
I'm a designer.私はデザイナーです。
I'm an engineer.私はエンジニアです。

Choose what comes after I'm (I'm の後ろを選ぶ)

Keep I with am; use I'm in conversation, then add a name, state, or job.I と am を一緒にして会話では I'm を使い、そのあとに名前・状態・仕事を続けます。

I'm + 名前 / 状態 / a・an + 仕事One frame, three meanings一つの形で三つの意味I'm Mina.I'm happy.I'm a designer.

Say the complete sentence (文をまるごと言おう)

Say each whole sentence aloud, including the missing words.空欄に入る言葉も含めて、文をまるごと声に出して言ってください。

Type only the missing words exactly as the learner says them.
私はミナです。 Mina.
私はうれしいです。 happy.
私はデザイナーです。 designer.
私はエンジニアです。 engineer.

Say it in English (英語にしよう)

Read the Japanese, then say it in English.日本語を見て、英語で言ってみましょう。

Type the learner's complete English sentence exactly as they say it.

私はうれしいです。うれしい:happy
私はデザイナーです。デザイナー:designer
私はエンジニアです。エンジニア:engineer

Make it yours (自分の文にしよう)

Use “I'm ___.” to say your name, how you feel, or your job.「I'm ___.」で、名前・気分・仕事のどれかを伝えてください。

Let the learner answer aloud before you capture it. React first, then add only a useful correction.
