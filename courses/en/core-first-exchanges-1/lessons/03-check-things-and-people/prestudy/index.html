Have the learner read the title once, then move on.

PART 1

Is this your bag?

Use an Is this question to check a thing, description, or situation. Please read the title aloud.「Is this」 の質問で物・特徴・状況を確かめます。タイトルを声に出して読んでください。

Have the learner read the title once, then move on.

Today's pattern (今日のパターン)

Meaning & use 意味・使い方Use an Is this question to check a thing, description, or situation.「Is this」 の質問で物・特徴・状況を確かめます。

Briefly explain the meaning, then have the learner read each example aloud.
Is this your bag?これはあなたのかばんですか？
Is this the right key?これは正しい鍵ですか？
Is this yours?これはあなたのものですか？

Read the sentences (文を読もう)

Let's read each sentence aloud.一文ずつ声に出して読んでみましょう。

Put the complement after Is this (Is this の後ろに内容を置く)

Move is before this, then add a complete thing, owner, or description.is を this の前に移し、そのあとに物・持ち主・説明を一まとまりで続けます。

Is this + 所有・名詞句・形容詞?Check a thing物を確かめるIs this your bag?Is this the right key?Is this yours?Is this okay?

Type only the missing words exactly as the learner says them.

A broad frame still needs a natural question (広い形でも自然な質問を)
