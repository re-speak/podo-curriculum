Meaning & use 意味・使い方Use this to state the only condition that would stop your plan.予定を止める唯一の条件を伝えるときに使います。

Unless equals if not (unless は if not)

Unless means if not; use a positive present form after it.「unless」 は 「if not」 の意味で、そのあとは肯定の現在形を使います。

Unless + 肯定形 = if + 否定形Only stopping condition唯一の中止条件Unless it rains, I'll walk.Unless the train's late, I'll be there by nine.
