I've finished or I'm done? (I've finished と I'm done)

“I've finished” is a neutral progress update. “I'm done” is shorter and more conversational.「I've finished」は中立的な進捗報告です。「I'm done」は短く、より会話的です。

Neutral update中立的な報告I've finished the report.レポートを終えました。

Conversational会話的I'm done with the report.レポートは終わりました。
