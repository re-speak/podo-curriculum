A personal rule you never break (絶対に破らない自分のルール)

Let's talk about how personal rules can make repeated decisions easier. Please read the title aloud.自分のルールが、繰り返す判断をどのように楽にするか話しましょう。タイトルを声に出して読んでください。

Have the learner read the title once, then move on.

Rules we choose for ourselves (自分で選ぶルール)

Did you have any questions about the article?記事について何か質問はありましたか？

Answer the learner's questions, then move on. If there are none—or the learner did not complete the pre-study—skip the article; do not spend class time reading it.
A personal rule turns a repeated decision into a clear boundary.自分のルールは、繰り返す判断を明確な境界に変えます。
It can protect time, money, health, relationships, or peace of mind.そのルールは、時間、お金、健康、人間関係、心の平穏を守れます。
Many strong rules begin after one experience we do not want to repeat.厳しいルールの多くは、二度と経験したくない出来事のあとに生まれます。
The rule makes future choices faster, but too much rigidity can become a problem.そのルールは今後の判断を速くしますが、融通が利かなすぎると問題になることがあります。rigidity融通のなさ
An exception does not always destroy the value of a rule.例外があっても、そのルールの価値がなくなるとは限りません。
Other people may see a boundary as strange when they do not know its history.背景を知らない人には、その境界が変に見えることがあります。
Explaining the reason can be useful, but nobody owes every detail.理由を説明すると役立ちますが、すべての細部を話す必要はありません。
Some rules outlive the problem they were designed to solve.解決するはずだった問題がなくなったあとも残るルールがあります。
Reviewing a rule is different from breaking it carelessly.ルールを見直すことと、軽く破ることは違います。
The best rule still serves a clear purpose today.よいルールには、今でも明確な役割があります。

8 QUESTION POOL

Let's talk (話そう)

We don't need to answer every question. Let's follow the most interesting parts of your answers.全部の質問に答える必要はありません。答えの中でいちばん面白いところを広げていきましょう。

Treat these pages as a pool, not a sequence. React or share briefly before choosing the next prompt, skip freely, and move to feedback with 2–3 minutes left.

A useful personal rule (役立つ自分ルール)

WARM-UP 1What personal rule can make life easier?どのような自分のルールが、生活を楽にできますか？

Follow up
  • What choice would the rule make easier?
  • What problem would it prevent?

How strict (厳しさ)

WARM-UP 2How strict should a useful personal rule be?役立つ自分のルールは、どのくらい厳しくするとよいですか？

Follow up
  • What exception would be reasonable?
  • When would an exception go too far?

Where rules come from (ルールの始まり)

QUESTION 1What could make someone turn a preference into a firm rule?何がきっかけで、好みが固いルールに変わることがありますか？

Follow up
  • Could one bad experience do it?
  • What problem would the rule prevent?

A reasonable exception (納得できる例外)

QUESTION 2When is breaking a personal rule reasonable?どのようなときは、自分のルールを破ってもよいですか？

Follow up
  • How can you tell if it is an honest exception or just an excuse?
  • What should happen afterward?

What others see (ほかの人の見方)

QUESTION 3Why can someone else's personal rule seem strange?ほかの人の自分ルールが、なぜ不思議に見えることがあるのでしょうか？

Follow up
  • Which missing detail could explain it?
  • When might the rule be more common than it seems?

Explain or keep private (説明する？)

QUESTION 4If your personal rule affects someone else, how much should you explain?自分のルールがほかの人に影響するなら、どこまで理由を説明すべきですか？

Follow up
  • What do they genuinely need to know?
  • Which detail can remain private?

Still useful (今も役立つか)

QUESTION 5How can you tell whether a personal rule is still useful?自分のルールが今も役立っているか、どう判断できますか？

Follow up
  • What problem does the rule solve now?
  • What change would make you rewrite it?

A rule to try (試したいルール)

QUESTION 6What personal rule would be worth trying this month?今月、どのような自分のルールを試す価値がありますか？

Follow up
  • How could you make the rule easy to try?
  • What result would show that it helps?
