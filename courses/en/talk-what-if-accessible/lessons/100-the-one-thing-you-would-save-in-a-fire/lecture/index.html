Safety before possessions (持ち物より安全)

Did you have any questions about the article?記事について何か質問はありましたか？

Answer the learner's questions, then move on. If there are none—or the learner did not complete the pre-study—skip the article; do not spend class time reading it.
In this scenario, every person and pet is already safe.この想像では、人もペットもすでに安全です。
Nobody should re-enter a fire for an object.物のために火の中へ戻ってはいけません。
No possession is worth delaying a safe evacuation.どんな持ち物も、安全な避難を遅らせるほど大切ではありません。
If one object is already within safe reach, the choice becomes meaningful.安全に手が届く場所に一つ物がある場合だけ、選択を考えられます。
Irreplaceable means that something cannot truly be replaced.かけがえのないとは、本当には置き換えられないことです。irreplaceableかけがえのない
Market price and personal value can point in opposite directions.市場の値段と個人的な価値は、反対になることがあります。
Digital copies can make some records replaceable.デジタルのコピーで、置き換えられる記録もあります。
Other people may save different things because their histories differ.人によって歴史が違うので、持ち出す物も違います。
Past loss can change what we protect now.過去に物を失った経験で、今守るものが変わる場合があります。
The safest lesson is preparation, not a faster rescue.いちばん安全な学びは、速く取りに行くことではなく準備です。

8 QUESTION POOL

Let's talk (話そう)

We don't need to answer every question. Let's follow the most interesting parts of your answers.全部の質問に答える必要はありません。答えの中でいちばん面白いところを広げていきましょう。

Treat these pages as a pool, not a sequence. React or share briefly before choosing the next prompt, skip freely, and move to feedback with 2–3 minutes left.

One thing (一つの物)

WARM-UP 1Once everyone is safe, which possession would be hardest to lose?全員が安全になった後、失うのが最もつらい持ち物は何ですか？

Follow up
  • What memory or meaning gives it that value?
  • How could you preserve part of that value beforehand?

Why that one (それを選ぶ理由)

WARM-UP 2What can make one possession feel irreplaceable?一つの持ち物が、かけがえのないものに感じられるのはなぜですか？

Follow up
  • Is the value practical, historical, or emotional?
  • Could a copy preserve any part of it?

Your own answer (自分の答えへの驚き)

QUESTION 1Which possession do people often value more than expected?人が予想以上に大切にすることが多い持ち物は何ですか？

Follow up
  • Why might people overlook its value?
  • Which need or memory does it represent?

A different choice (ほかの人と違う選択)

QUESTION 2What might another person take even if you would take nothing?自分は何も持ち出さない場合でも、ほかの人なら何を持ち出すかもしれませんか？

Follow up
  • Why might it matter to them?
  • Why would you still leave it?

A past loss (過去に失った物)

QUESTION 3Why can losing an ordinary object feel deeply important?普通の物を失っても、とても大切に感じられるのはなぜですか？

Follow up
  • Which meaning could make an ordinary object important?
  • Can the memory remain after the object is gone?

What loss teaches (失うことから学ぶこと)

QUESTION 4What can losing an object teach us?物を失うことから、何を学べますか？

Follow up
  • Does it change what we protect?
  • Can a memory remain without the object?

Preparing safely (安全な準備)

QUESTION 5How can people protect important possessions before an emergency?緊急事態の前に、大切な持ち物をどう守れますか？

Follow up
  • Would a backup, list, or safer storage help most?
  • Which evacuation preparation should come first?

What cannot burn (燃えないもの)

QUESTION 6What important part of life cannot be saved or destroyed as an object?物として救ったり失ったりできない、人生の大切なものは何ですか？

Follow up
  • How is it protected instead?
  • Can an object still help us remember it?

Before we finish, here's one strength and one thing to focus on next.最後に、よかった点を一つと、次に意識する点を一つ伝えます。

Before closing, ask the learner to repeat one useful correction.
