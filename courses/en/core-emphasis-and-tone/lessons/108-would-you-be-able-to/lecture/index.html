Careful distance (丁寧な距離)

After Would you be able to, use a plain verb; the longer frame adds distance.「Would you be able to」 の後ろは動詞の原形にし、長い形で丁寧な距離を作ります。

Would you be able to + plain verb?Less familiar or higher-stakesあまり親しくない・重要度が高いWould you be able to send it over?Would you be able to confirm the date?
