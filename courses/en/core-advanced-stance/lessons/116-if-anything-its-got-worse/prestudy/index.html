GOAL

If anything, it's got worse (むしろ悪化しています)

Correct an assumption by showing that the evidence points the opposite way. Please read the title aloud.想定を修正し、事実が逆方向を示していると伝えましょう。タイトルを声に出して読んでください。

Have the learner read the title once, then move on.

PART 1

If anything, it's got worse.

First, let's practice this pattern.まず、このパターンを練習しましょう。

Introduce Part 1 with this one line, then move on.

Today's pattern (今日のパターン)

Meaning & use 意味・使い方Use this when the evidence does not merely weaken an assumption but points in the reverse direction.事実が想定を弱めるだけでなく、逆方向を示すときに使います。

Briefly explain the meaning, then have the learner read each example aloud.
If anything, it's got worse.むしろ悪化しています。
If anything, it's become less reliable.むしろ信頼性が下がっています。
If anything, delays have increased.むしろ遅れが増えています。

Read the sentences (文を読もう)

Let's read each sentence aloud.一文ずつ声に出して読んでみましょう。

If anything, it's got worse.むしろ悪化しています。
If anything, it's become less reliable.むしろ信頼性が下がっています。
If anything, delays have increased.むしろ遅れが増えています。
If anything, the workload has doubled.むしろ作業量は2倍になっています。

Reverse the expectation (予想を逆転)

Use If anything before the clause that reverses the listener's expectation.相手の予想と逆の事実を述べる節の前に 「If anything」 を置きます。

If anything, + 逆方向の節Stronger than a small correction小さな修正より強いIf anything, it's got worse.If anything, delays have increased.

Let's say each whole sentence aloud, including the missing words.空欄に入る言葉も含めて、文をまるごと声に出して言ってみましょう。

Type only the missing words exactly as the learner says them.

Actually or if anything? (actually と if anything)

Use “actually” for a correction. Use “if anything” only when the truth points beyond neutral in the opposite direction.単なる修正には「actually」を使います。事実が中立を越えて逆方向にあるときだけ「if anything」を使います。

Simple correction単なる修正Actually, demand is stable.実際、需要は安定しています。
