Native tip (ネイティブのひとこと)

Both are correct. Read them aloud and compare how direct they sound.どちらも正しい言い方です。声に出して読み、直接的なひびきの違いを比べてください。

Have the learner read both versions, then ask which one fits a friend and which one fits a stranger or coworker.
