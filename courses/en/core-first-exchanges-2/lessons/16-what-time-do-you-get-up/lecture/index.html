Today's pattern (今日のパターン)

Meaning & use 意味・使い方Use this to ask for the clock time of a routine.日課の時刻をたずねるときに使います。

Briefly explain the meaning, then have the learner read each example aloud.

What time do you start work?何時に仕事を始めますか？
What time do you have lunch?何時に昼食をとりますか？

Start with What time (What time から始める)

Put What time first, then use do you plus the action.「What time」 を最初に置き、その後ろを 「do you」 と動作の順にします。

What time + do you + 動作 + ?Ask for a clock time時刻をたずねるWhat time do you get up?What time do you start work?

What time or when? (What time と when)

Use “What time” when you want a clock time. “When” can invite a broader answer.時計の時刻を知りたいなら「What time」を使います。「When」はもっと幅広い答えにも使えます。
