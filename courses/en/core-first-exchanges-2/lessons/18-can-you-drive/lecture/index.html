GOAL

Can you drive? (運転できますか？)

Ask about an ability and contrast what you can and cannot do. Please read the title aloud.できることをたずね、できることとできないことを対比しましょう。タイトルを声に出して読んでください。

Have the learner read the title once, then move on.

Today's pattern (今日のパターン)

Meaning & use 意味・使い方Use this to ask whether someone has an ability.あることができるかたずねるときに使います。

Briefly explain the meaning, then have the learner read each example aloud.
Can you drive?運転できますか？
Can he swim?彼は泳ぐことができますか？
Can you cook?料理ができますか？

Read the sentences (文を読もう)

Let's read each sentence aloud.一文ずつ声に出して読んでみましょう。

Can he swim?彼は泳ぐことができますか？
Can you cook?料理ができますか？
Can they ski?彼らはスキーができますか？

Put a plain verb after can (can の後ろは動詞の原形)

Use Can you plus a plain verb to ask about an ability.できるかたずねるときは 「Can you」 の後ろに動詞の原形を置きます。

Can + 人 + 動詞の原形 + ?Ability questionできるかの質問Can you drive?Can he swim?

Choose the answer that matches the Japanese, then read the complete sentence aloud.日本語に合う答えを選び、完成した文を声に出して読んでください。

After each choice, have the learner read the entire completed sentence before moving on.

Make it yours (自分の文にしよう)

Now use “Can you ___?” to ask me about one ability you want to know.では、「Can you ___?」を使って、知りたい能力を一つ私に聞いてください。

PART 2

I can ride a bike, but I can't drive.

Next, let's practice this pattern.次に、このパターンを練習しましょう。

Introduce Part 2 with this one line, then move on.

Today's pattern (今日のパターン)

Meaning & use 意味・使い方Use this to contrast one ability with something you cannot do.できることと、できないことを対比するときに使います。

Briefly explain the meaning, then have the learner read each example aloud.
I can ride a bike, but I can't drive.自転車には乗れますが、運転はできません。
I can walk, but I can't run.歩くことはできますが、走ることはできません。
I can cook, but I can't bake.料理はできますが、お菓子作りはできません。

Read the sentences (文を読もう)

Let's read each sentence aloud.一文ずつ声に出して読んでみましょう。

I can ride a bike, but I can't drive.自転車には乗れますが、運転はできません。
I can walk, but I can't run.歩くことはできますが、走ることはできません。
I can cook, but I can't bake.料理はできますが、お菓子作りはできません。
I can read it, but I can't write it.読むことはできますが、書くことはできません。

Contrast can and can't (can と can't を対比する)

Put a plain verb after both can and can't; use but to contrast the two abilities.can と 「can't」 の後ろはどちらも動詞の原形にし、二つを but で対比します。

I can + 動作, but I can't + 動作Two abilities二つのできることI can walk, but I can't run.I can cook, but I can't bake.

Choose the pattern (パターンを選ぼう)

Choose the answer that matches the Japanese, then read the complete sentence aloud.日本語に合う答えを選び、完成した文を声に出して読んでください。

After each choice, have the learner read the entire completed sentence before moving on.
自転車には乗れますが、運転はできません。I can ride a bike, but I can't/can drive.
歩くことも走ることもできます。I can walk, and I can't/can run.
料理はできますが、お菓子作りはできません。I can cook, but I can't/can bake.
読むことも書くこともできます。I can read it, and I can/can't write it.

Say the complete sentence (文をまるごと言おう)

Let's say each whole sentence aloud, including the missing words.空欄に入る言葉も含めて、文をまるごと声に出して言ってみましょう。

Type only the missing words exactly as the learner says them.

Say it in English (英語にしよう)

Let's read the Japanese, then say it in English.日本語を見て、英語で言ってみましょう。

Now use “I can ___, but I can’t ___” to contrast two real abilities.では、「I can ___, but I can’t ___」を使って、本当のできることとできないことを対比してください。
