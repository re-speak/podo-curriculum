GOAL

Can I try this on? (これを試着してもいいですか？)

Ask permission and answer a permission request. Please read the title aloud.許可を求め、許可を求められたときにも答えましょう。タイトルを声に出して読んでください。

Have the learner read the title once, then move on.

Can I or could I? (Can I と Could I)

Both ask permission. “Could I” can sound a little more polite or tentative.どちらも許可を求めます。「Could I」は少し丁寧で控えめに聞こえます。

NeutralふつうCan I try this on?これを試着してもいいですか？
Pick by meaning 意味で選ぶ
More tentative少し控えめCould I try this on?これを試着してもよろしいですか？
