GOAL

How much is this? (これはいくらですか？)

Ask a price and confirm a number you heard. Please read the title aloud.値段をたずね、聞いた数字を確認しましょう。タイトルを声に出して読んでください。

Have the learner read the title once, then move on.

PART 1

How much is this one?

First, let's practice this pattern.まず、このパターンを練習しましょう。

Introduce Part 1 with this one line, then move on.

Today's pattern (今日のパターン)

Meaning & use 意味・使い方Use this to ask the price of one item.一つの品物の値段をたずねるときに使います。

Briefly explain the meaning, then have the learner read each example aloud.
How much is this one?これはいくらですか？
How much is that bag?あのかばんはいくらですか？
How much is the ticket?そのチケットはいくらですか？

Read the sentences (文を読もう)

Let's read each sentence aloud.一文ずつ声に出して読んでみましょう。

How much is this one?これはいくらですか？
How much is that bag?あのかばんはいくらですか？
How much is the ticket?そのチケットはいくらですか？
How much is a coffee?コーヒーはいくらですか？

Use How much is with one item (一つの品物には How much is)

Use How much is plus the complete item to ask its price.値段をたずねるときは 「How much is」 の後ろに、品物をひとまとまりで置きます。

How much is + 品物 + ?Ask a price値段をたずねるHow much is this one?How much is the ticket?

Choose the pattern (パターンを選ぼう)

Choose the answer that matches the Japanese, then read the complete sentence aloud.日本語に合う答えを選び、完成した文を声に出して読んでください。

After each choice, have the learner read the entire completed sentence before moving on.

りんごはいくつありますか？How many/much apples are there?
そのチケットはいくらですか？How much/many is the ticket?
チケットは何枚必要ですか？How much/many tickets do we need?

Let's say each whole sentence aloud, including the missing words.空欄に入る言葉も含めて、文をまるごと声に出して言ってみましょう。

Type only the missing words exactly as the learner says them.

Make it yours (自分の文にしよう)

Now use “How much is ___?” to ask me the price of one item you can see.では、「How much is ___?」を使って、見える品物の値段を一つ私に聞いてください。

Let the learner answer aloud before you capture it. React first, then add only a useful correction.
PART 2

Is that fifteen or fifty?

Next, let's practice this pattern.次に、このパターンを練習しましょう。

Introduce Part 2 with this one line, then move on.

Today's pattern (今日のパターン)

Meaning & use 意味・使い方Use this to check which of two similar numbers you heard.似た二つの数字のどちらを聞いたか確認するときに使います。

Briefly explain the meaning, then have the learner read each example aloud.
Is that fifteen or fifty?それは15ですか、それとも50ですか？
Is that thirteen or thirty?それは13ですか、それとも30ですか？
Is that fourteen or forty?それは14ですか、それとも40ですか？

Read the sentences (文を読もう)

Let's read each sentence aloud.一文ずつ声に出して読んでみましょう。

Is that fifteen or fifty?それは15ですか、それとも50ですか？
Is that thirteen or thirty?それは13ですか、それとも30ですか？
Is that fourteen or forty?それは14ですか、それとも40ですか？
Is that sixteen or sixty?それは16ですか、それとも60ですか？

Put or between the two numbers (二つの数字の間に or)

Use the frame Is that X or Y to check which of two numbers you heard.聞こえた数字を確認するときは 「Is that X or Y」 の形を使います。

Is that + X + or + Y + ?Check what you heard聞いた数字を確認するIs that fifteen or fifty?Is that thirteen or thirty?
