今日のゴール

韓国のお店や教室では、こんな言葉を毎日聞きます。今日はこの言い方を覚えて、自分でも言ってみましょう。

もう知っている単語

今日はお店や病院で聞く言葉を勉強します。その単語、もう知っています。これも漢字から来ています。

パート 1

-(으)세요（ウ）セヨ

〜してください。お願いも、すすめるのも、これ1つ。まずは聞き取れるようにします。

今日のパターン

意味・使い方~してください動詞のうしろに세요をつけるだけです。

여기 앉으세요.ヨギ アンジュセヨ ここに座ってください。
이 책을 읽으세요.イ チェグル イルグセヨこの本を読んでください。
여기 보세요.ヨギ ボセヨここを見てください。

으세요 と 세요、どっち？

「다」の前の文字を見てください。パッチムがあれば「으세요」、なければ「세요」をつけます。

앉 → 으세요ウセヨ パッチムあり（子音で終わる） 앉으세요アンジュセヨ읽으세요イルグセヨ
가 → 세요セヨ パッチムなし（母音で終わる） 안녕히 가세요アンニョンヒ カセヨ기다리세요キダリセヨ

形が かわる ことば

2つだけ少し違います。「듣다」はㄷがㄹに変わり、「살다」はㄹが落ちます。今は「들으세요」だけ、まるごと覚えれば大丈夫です。

듣 → 들으세요トゥルセヨ ㄷ が ㄹ に かわる 잘 들으세요チャル トゥルセヨ음악을 들으세요ウマグル トゥルセヨ
살 → 사세요サセヨ ㄹ が おちる 살다 → 사세요サセヨ놀다 → 노세요ノセヨ

正しい言葉を選ぼう

「다」の前の文字にパッチムがあるかを見て、正しいほうをタップしてください。

ここに座ってください。（앉다） 여기 앉으세요./앉세요.ヨギ …

明日学校に来てください。（오다） 내일 학교에 오세요./오으세요.ネイル ハッキョエ …
