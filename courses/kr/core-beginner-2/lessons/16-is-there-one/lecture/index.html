있어요와 없어요 (있어요 と 없어요、どっち？)

소리로 고르는 게 아니에요. 그게 있으면 ‘있어요’, 그게 없으면 ‘없어요’예요. 물건도 사람도, 시간도 다 똑같아요.音で選ぶのではありません。それがあれば「있어요」、なければ「없어요」です。ものも人も、時間も全部同じです。

원어민 팁 (ネイティブのひとこと)
