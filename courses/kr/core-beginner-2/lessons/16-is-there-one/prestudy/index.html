Nありますか？ 名詞のうしろに있어요をつけるだけ。あるかどうかを聞きます。

今日のパターン

意味・使い方あります・いますそこにそれがあるかを聞くときに使います。

ありません

意味・使い方ありません있어요の相方で、안 있어요とは言いません。

여기 화장실 없어요.ヨギ ファジャンシル オプソヨ ここにトイレはありません。
아니요, 여기 없어요.アニヨ、ヨギ オプソヨいいえ、ここにはありません。
편의점은 없어요.ピョニジョムン オプソヨコンビニはありません。

있어요 と 없어요、どっち？

音で選ぶのではありません。それがあれば「있어요」、なければ「없어요」です。ものも人も、時間も全部同じです。

이 と 가、どっち？

前に習ったあのパッチムのルールです。最後の文字にパッチムがあれば「이」、なければ「가」です。

실 → 이イ パッチムあり（子音で終わる） 화장실이ファジャンシリ편의점이ピョニジョミ
이 → 가ガ パッチムなし（母音で終わる） 고양이가コヤンイガ카페가カペガ
