받침을 보고 ㄹ · 을 (パッチムを見て ㄹ・을)

받침이 없으면 ‘ㄹ 뿐만 아니라’, 있으면 ‘을 뿐만 아니라’예요. ‘뿐이다’와 붙이는 법이 똑같고 뒤만 달라요. 명사에는 ‘일 뿐만 아니라’를 붙여요.パッチムがなければ「ㄹ 뿐만 아니라」、あれば「을 뿐만 아니라」です。「뿐이다」とつけ方は同じで、後ろだけ違います。名詞には「일 뿐만 아니라」をつけます。

ㄹ 뿐만 아니라 받침 없음パッチムなし 예쁘다 → 예쁠 뿐만 아니라싸다 → 쌀 뿐만 아니라
을 뿐만 아니라 받침 있음パッチムあり 좋다 → 좋을 뿐만 아니라늦다 → 늦을 뿐만 아니라
일 뿐만 아니라 명사名詞 학생 → 학생일 뿐만 아니라친구 → 친구일 뿐만 아니라

동사면 는, 형용사면 (으)ㄴ (動詞なら 는、形容詞なら (으)ㄴ)

‘데다가’ 앞에는 관형사형이 와요. 동사면 ‘는 데다가’, 형용사면 ‘(으)ㄴ 데다가’예요. 명사끼리 쌓을 때는 ‘N에다가 N까지’로 말해요.「데다가」の前には連体形が来ます。動詞なら「는 데다가」、形容詞なら「(으)ㄴ 데다가」です。名詞どうしを重ねるときは「N에다가 N까지」と言います。

는 데다가 동사動詞 오다 → 오는 데다가막히다 → 막히는 데다가
(으)ㄴ 데다가 형용사形容詞 싸다 → 싼 데다가피곤하다 → 피곤한 데다가
N에다가 N까지 명사끼리名詞どうし 비에다가 → 바람까지일에다가 → 약속까지

둘 다 길어서, 말할 때는 앞 문장을 끊고 ‘게다가’ 한 마디로 잇는 일이 아주 많아요. 특히 안 좋은 일이 겹칠 때는 ‘설상가상으로’를 쓰면 훨씬 실감 나요.どちらも長いので、話すときは前の文を切って「게다가」のひとことでつなぐことがとても多いです。とくによくないことが重なるときは「설상가상으로」を使うとずっと実感が出ます。

위아래로 한 줄씩 읽어 주세요. 아래쪽이 실제 대화에서 훨씬 자주 들려요.
道が混んでいる上に雨まで降りました。 길이 막히는 데다가 비까지 왔어요. 길이 막혔어요. 게다가 비까지 왔어요.
疲れている上に仕事も多かったです。 피곤한 데다가 일도 많았어요. 피곤했어요. 설상가상으로 일도 많았고요.
