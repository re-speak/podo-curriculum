ゴール

今日のゴール

相手しか見えないと伝え、2人は相性がいいという思いを言葉にして、関係を確かめられるようになります。

気持ちが確かなときのことば

最終シーンに出てきた3つの表現です。確かになった気持ちと2人の関係をつなげて読んでみましょう。

확신이 들어.確信が持てる。
우리는 정말 잘 맞아.私たちは本当に相性がいい。
이제는 말할 수 있어.もう言える。
パート 1

N밖에 안 ~

まず、「ほかにはいない」と相手だけを選ぶ、強くてまっすぐな気持ちを伝えます。

シーンのひと言

意味・使い方もうその人しか見えない、と言うときに使います。

이제 너밖에 안 보여.今はもう、君しか見えない。
네 생각밖에 안 나.君のことしか考えられない。
나한테는 너밖에 없어.僕には君しかいない。

밖에 のつけ方

名詞に「밖에」をそのままつけ、そのあとは必ず否定表現にします。この表現は形が1つなので、1つのブロックで確認しましょう。

너→너밖에 안 보여名詞＋밖에＋否定너밖에 보여 ✕너밖에 안 보여 ✓

確信のことばを組み立てよう

4つのことばを順番に並べ、1つだけが残る気持ちを伝えましょう。

今は本当に君しか見えない。
너밖에이제안 보여정말
僕の目には今、ユジンしか見えない。
유진밖에내 눈에는안 보여지금
一日中、何度も君のことしか頭に浮かばない。
네 생각밖에하루 종일자꾸안 나
今、僕に必要な人は君しかいない。
나한테 필요한 사람은없어너밖에지금
パート 2

~(으)ㄴ/는 것 같아

次に、2人の相性について感じたことを、相手も受け取りやすい柔らかな判断として伝えます。

シーンのひと言

意味・使い方言い切らずに、そんな気がすると言います。

우리 진짜 잘 맞는 것 같아.僕たち、本当に相性がいいと思う。
우리가 점점 가까워지는 것 같아.僕たち、だんだん近づいている気がする。
유진도 지금 행복한 것 같아.ユジンも今、幸せそうだ。

動作と状態を分けよう

動作動詞の現在形には「는」、形容詞はパッチムがあれば「은」、なければ、またはㄹならㄴをつけます。辞書形全体からの変化を確認しましょう。

이해하다→이해하는 것 같아動作動詞＋는가까워지다 → 가까워지는 것 같아
좋다→좋은 것 같아形容詞・パッチムあり＋은같다 → 같은 것 같아
행복하다→행복한 것 같아形容詞・パッチムなし＋ㄴ비슷하다 → 비슷한 것 같아

는 と (으)ㄴ を選ぼう

辞書形が動作動詞か形容詞かを見て、正しく変化したほうをタップしてください。

私たち、だんだん近づいている気がする。우리가 점점 가까워진는 것 같아/가까워지는 것 같아.
ユジンも幸せそうだ。유진도 행복하는 것 같아/행복한 것 같아.
今日の雰囲気もよさそうだ。오늘 분위기도 좋은 것 같아/좋는 것 같아.
一緒にいると気楽なようだ。같이 있으면 편하는 것 같아/편한 것 같아.

2人の関係を組み立てよう

4つのことばを順番に並べ、2人についての判断をやわらかく伝えましょう。

私たち、本当に相性がいいと思う。
진짜우리것 같아잘 맞는
一緒にいると時間が早く過ぎる気がする。
시간이함께 있으면빨리 가는것 같아
ユジンも今、とても幸せそうだ。
지금아주 행복한유진도것 같아
私たちは考え方もかなり似ていると思う。
꽤 비슷한생각하는 방식도우리는것 같아
