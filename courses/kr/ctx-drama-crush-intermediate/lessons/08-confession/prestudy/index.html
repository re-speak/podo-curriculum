今日のゴール

相手の意向をたずねながら付き合おうと告白し、これから自分がどうすると約束できるようになります。

告白のことば

シーンに出てきた3つの表現です。気持ちを伝え、関係をたずね、これからを約束してみましょう。

오늘 꼭 고백할 거야.今日、必ず告白する。
나랑 사귈래?僕と付き合う？
앞으로 더 잘할게.これからもっと大切にするよ。
パート 1

~(으)ㄹ래?

まず、自分の希望を押しつけず、「付き合う気持ちはある？」と相手の意向をたずねます。

シーンのひと言

意味・使い方付き合う気があるかを、まっすぐ聞くときに使います。

나랑 사귈래?僕と付き合う？
내 옆에 있을래?僕のそばにいる？
나랑 같이 갈래?僕と一緒に行く？

을래 と ㄹ래

動詞の辞書形から「다」を取ります。ㄹ以外のパッチムがあれば「을래」、パッチムがなければ「ㄹ래」、ㄹパッチムはそのまま残して「래」をつけます。

먹다→먹을래?パッチムあり・ㄹ以外있다 → 있을래?
가다→갈래?パッチムなしはㄹ래사귀다 → 사귈래?
놀다→놀래?ㄹパッチムはそのまま만들다 → 만들래?

을래 と ㄹ래を選ぼう

動詞の辞書形とパッチムを見て、相手の意向をたずねる自然なほうをタップしてください。

一緒に食べる？같이 먹을래/먹래?
僕と付き合う？나랑 사귀을래/사귈래?
もう少し遊ぶ？조금 더 놀래/놀을래?
これ、一緒に作る？이거 같이 만들래/만들을래?

気持ちをたずねる質問を組み立てよう

4つのことばを順番に並べ、相手の返事を待つ質問として読んでみましょう。

ユジン、これから僕と付き合う？
사귈래유진아나랑앞으로
今日、僕ともう少し一緒にいる？
조금 더나랑같이 있을래오늘
このあと、一緒に家まで歩く？
집까지이따가걸을래같이
今週末、2人でまた会う？
또이번 주말에만날래우리 둘이
パート 2

~(으)ㄹ게

相手の答えを聞いたら、今度は自分がこれから必ずすることを約束します。

シーンのひと言

意味・使い方これからこうする、と約束するときに使います。

앞으로 너한테만 잘할게.これからは君だけを大切にするよ。
네 말 끝까지 들을게.君の話を最後まで聞くよ。
약속 꼭 지킬게.約束は必ず守るよ。

을게 と ㄹ게

動詞の辞書形から「다」を取ります。ㄹ以外のパッチムがあれば「을게」、パッチムがなければ「ㄹ게」、ㄹパッチムはそのまま残して「게」をつけます。

먹다→먹을게パッチムあり・ㄹ以外듣다 → 들을게
가다→갈게パッチムなしはㄹ게연락하다 → 연락할게
만들다→만들게ㄹパッチムはそのまま놀다 → 놀게

을게 と ㄹ게を選ぼう

動詞の辞書形とパッチムを見て、約束を作る自然なほうをタップしてください。

君の話を最後まで聞くよ。네 말 끝까지 들을게/듣게.
僕から先に連絡するよ。내가 먼저 연락할게/연락하을게.
これ、僕が作るよ。이거 내가 만들을게/만들게.
ここで待つよ。여기서 기다릴게/기다리을게.

約束を組み立てよう

4つのことばを順番に並べ、相手に責任を持つ約束として読んでみましょう。
