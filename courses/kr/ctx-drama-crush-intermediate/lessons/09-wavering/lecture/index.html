으면과 면 (으면 と 면)

동사의 기본형에서 다를 떼요. ㄹ을 제외한 받침이 있으면 ‘으면’, 받침이 없거나 ㄹ이면 ‘면’을 붙이고 ‘안 되다’를 이어요.動詞の辞書形から「다」を取ります。ㄹ以外のパッチムがあれば「으면」、パッチムがないかㄹなら「면」をつけ、「안 되다」を続けます。

숨다→숨으면 안 돼받침 있음 · ㄹ 제외パッチムあり・ㄹ以外먹다 → 먹으면 안 돼
피하다→피하면 안 돼받침 없음 → 면パッチムなしは면이러다 → 이러면 안 돼
울다→울면 안 돼ㄹ 받침 + 면ㄹパッチムは면만들다 → 만들면 안 돼

았나 봐와 었나 봐 (았나 봐 と 었나 봐)

과거형에서 마지막 모음이 ㅏ·ㅗ면 ‘았나 봐’, 나머지는 ‘었나 봐’를 써요. ‘하다’는 ‘했나 봐’가 돼요.過去形で最後の母音がㅏ・ㅗなら「았나 봐」、それ以外は「었나 봐」を使います。「하다」は「했나 봐」になります。

좋아하다→좋아했나 봐하다 → 했나 봐하다 は 했나 봐기대하다 → 기대했나 봐
기다리다→기다렸나 봐그 외 → 었나 봐それ以外は었나 봐흔들리다 → 흔들렸나 봐
가다→갔나 봐ㅏ · ㅗ → 았나 봐ㅏ・ㅗは았나 봐보다 → 봤나 봐
