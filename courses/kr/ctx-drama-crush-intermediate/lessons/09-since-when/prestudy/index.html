今日のゴール

自分の気持ちにあとから気づいて伝え、その気持ちが始まった時を示し、相手にも聞き返せるようになります。

気持ちの始まりをたずねることば

シーンに出てきた3つの表現です。胸にしまっていた気持ちを話し、その始まりをお互いに確かめながら読んでみましょう。

언제부터였어?いつからだった？
사실은 나도 그랬어.実は、私もそうだった。
그때부터였어.そのころからだった。
パート 1

~았/었나 봐

まず、ずっと自分の中にあった気持ちを、今やっと見つけたように言葉にします。

シーンのひと言

意味・使い方時間がたってから自分の気持ちや行動に気づいたときに使います。自分の感情を他人事のように一歩離れて発見する言い方です。

사실 나도 너 좋아했나 봐.実は、私も君のことが好きだったみたい。
나도 어제 많이 긴장했나 봐.私も昨日、かなり緊張していたみたい。
계속 네 연락을 기다렸나 봐.ずっと君からの連絡を待っていたみたい。

過去形につなげよう

まず過去形を作り、「나 봐」をつけます。ㅏかㅗなら「았나 봐」、それ以外なら「었나 봐」、「하다」は「했나 봐」になります。

알다→알았나 봐語幹の母音がㅏ・ㅗ좋다 → 좋았나 봐
기다리다→기다렸나 봐それ以外の母音웃다 → 웃었나 봐
좋아하다→좋아했나 봐하다は했나 봐긴장하다 → 긴장했나 봐

過去の形を選ぼう

動詞の母音を見て、あとから気づいた気持ちに合う過去の形をタップしてください。

そのとき、もう君の気持ちが分かっていたみたい。그때 이미 네 마음을 알았나 봐/었나 봐.
ずっと君からの連絡を待っていたみたい。계속 네 연락을 기다리았나 봐/기다렸나 봐.
君を見るたびに笑っていたみたい。너를 볼 때마다 웃았나 봐/었나 봐.
私も君のことが好きだったみたい。나도 너를 좋아했나 봐/좋아하았나 봐.

気持ちを一文にしよう

4つのかたまりを順番に並べ、今やっと気づいた気持ちとして言ってみましょう。

実は、私もずっと前から君のことが好きだったみたい。
오래전부터좋아했나 봐사실나도 너를
昨日は、告白する前に私もかなり緊張していたみたい。
나도 많이어제는긴장했나 봐고백하기 전에
友達だと思いながらも、私はずっと君からの連絡を待っていたみたい。
네 연락을친구라고 생각하면서도기다렸나 봐나는 계속
君が笑うたびに、思わず気分がよくなっていたみたい。
기분이네가 웃을 때마다좋아졌나 봐나도 모르게
パート 2

~(으)ㄹ 때

次は、その気持ちがもう始まっていたころまで、2人の時間をさかのぼります。

シーンのひと言

意味・使い方ある行動や状態が続いている時を示すときに使います。「때부터」をつけると、その時点から始まったという意味になります。

친구일 때부터 그랬던 것 같아.友達だったころから、そうだった気がする。
네가 웃을 때 기분이 좋았어.君が笑うとき、うれしかった。
둘이 걸을 때 시간이 빨리 갔어.2人で歩くとき、時間が早く過ぎた。

形を分けよう

動詞は「다」を取り、ㄹ以外のパッチムがあれば「을 때」、パッチムがなければ「ㄹ 때」をつけます。ㄹパッチムはそのまま残し、名詞には「일 때」をつけます。

웃다→웃을 때パッチムあり・ㄹ以外먹다 → 먹을 때
만나다→만날 때パッチムなしはㄹ 때기다리다 → 기다릴 때
놀다→놀 때ㄹパッチムはそのまま걸다 → 걸 때
친구→친구일 때名詞には일 때학생 → 학생일 때

合う「とき」の形を選ぼう

動詞と名詞の形を見て、自然な「とき」の表現をタップしてください。

時間があるとき、連絡して。시간이 있을 때/ㄹ 때, 연락해.
初めて会うとき、少し緊張した。처음 만나을 때/ㄹ 때, 조금 긴장했어.
一緒に遊ぶとき、いつも楽しかった。같이 놀을 때/놀 때, 항상 즐거웠어.
友達だったころから、そうだった気がする。친구일 때부터/을 때부터, 그랬던 것 같아.

気持ちの始まりを組み立てよう

4つのかたまりを順番に並べ、あのころの気持ちまでつなげて言ってみましょう。

友達だったころから、私はもう君のことが好きだったみたい。
나는 이미친구일 때부터좋아했나 봐너를
君が笑うたびに、思わず何度もつられて笑った。
자꾸네가 웃을 때마다따라 웃었어나도 모르게
2人で家に帰るとき、私はいつも時間が惜しかった。
나는 항상시간이둘이 집에 갈 때아쉬웠어
君からの連絡を待つとき、私はもうかなり胸がときめいていた。
많이네 연락을 기다릴 때설렜어나는 이미
