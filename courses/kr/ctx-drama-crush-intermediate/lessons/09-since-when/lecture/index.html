언제부터

付き合うことを決めた翌日。向かい合って座り、2人は「いつから好きだったの？」と照れながら確かめ合います。

나あなたの役유진気持ちの始まりを確かめる恋人

パート 1

~았/었나 봐

まず、ずっと自分の中にあった気持ちを、今やっと見つけたように言葉にします。

장면 속 한마디 (シーンのひと言)

뜻과 쓰임 意味・使い方지나고 나서야 내 마음이나 행동을 알아차렸을 때 써요. 내 감정을 남의 일처럼 한 걸음 떨어져 발견하는 말투예요.時間がたってから自分の気持ちや行動に気づいたときに使います。自分の感情を他人事のように一歩離れて発見する言い方です。

확신을 강하게 선언하기보다, 이제야 자기 마음을 알아차린 듯 부드럽게 읽어 주세요.
사실 나도 너 좋아했나 봐.実は、私も君のことが好きだったみたい。
나도 어제 많이 긴장했나 봐.私も昨日、かなり緊張していたみたい。

그때 이미 네 마음을 알았나 봐.そのとき、もう君の気持ちが分かっていたみたい。

았나 봐 · 었나 봐 · 했나 봐 (過去形につなげよう)

먼저 과거형을 만들고 ‘나 봐’를 붙여요. ㅏ나 ㅗ면 ‘았나 봐’, 그 밖이면 ‘었나 봐’, ‘하다’는 ‘했나 봐’가 돼요.まず過去形を作り、「나 봐」をつけます。ㅏかㅗなら「았나 봐」、それ以外なら「었나 봐」、「하다」は「했나 봐」になります。

알다→알았나 봐ㅏ · ㅗ → 았나 봐語幹の母音がㅏ・ㅗ좋다 → 좋았나 봐
기다리다→기다렸나 봐그 외 → 었나 봐それ以外の母音웃다 → 웃었나 봐
좋아하다→좋아했나 봐하다 → 했나 봐하다は했나 봐긴장하다 → 긴장했나 봐

과거 모양 고르기 (過去の形を選ぼう)

동사의 모음을 보고, 뒤늦게 알아차린 마음에 맞는 과거 모양을 눌러 보세요.動詞の母音を見て、あとから気づいた気持ちに合う過去の形をタップしてください。

そのとき、もう君の気持ちが分かっていたみたい。그때 이미 네 마음을 알았나 봐/었나 봐.
ずっと君からの連絡を待っていたみたい。계속 네 연락을 기다리았나 봐/기다렸나 봐.
君を見るたびに笑っていたみたい。너를 볼 때마다 웃았나 봐/었나 봐.
私も君のことが好きだったみたい。나도 너를 좋아했나 봐/좋아하았나 봐.

パート 2

~(으)ㄹ 때

次は、その気持ちがもう始まっていたころまで、2人の時間をさかのぼります。

장면 속 한마디 (シーンのひと言)

뜻과 쓰임 意味・使い方어떤 행동이나 상태가 이어지는 때를 짚을 때 써요. ‘때부터’를 붙이면 그 시점에서 시작됐다는 뜻이 돼요.ある行動や状態が続いている時を示すときに使います。「때부터」をつけると、その時点から始まったという意味になります。

친구였던 기간 전체를 떠올리듯 ‘친구일 때부터’를 한 덩어리로 이어 읽어 주세요.
친구일 때부터 그랬던 것 같아.友達だったころから、そうだった気がする。
네가 웃을 때 기분이 좋았어.君が笑うとき、うれしかった。
둘이 걸을 때 시간이 빨리 갔어.2人で歩くとき、時間が早く過ぎた。

마음이 시작된 순간을 떠올리며, 네 문장을 한 줄씩 읽어 볼까요?気持ちが始まった瞬間を思い出しながら、4つの文を一つずつ読んでみましょうか？

친구일 때부터 그랬던 것 같아.友達だったころから、そうだった気がする。
네가 웃을 때 기분이 좋았어.君が笑うとき、うれしかった。
둘이 걸을 때 시간이 빨리 갔어.2人で歩くとき、時間が早く過ぎた。
네 연락을 기다릴 때 이미 설렜어.君からの連絡を待つとき、もう胸がときめいていた。

을 때 · ㄹ 때 · 일 때 (形を分けよう)

동사는 ‘다’를 떼고, ㄹ을 제외한 받침이 있으면 ‘을 때’, 받침이 없으면 ‘ㄹ 때’를 붙여요. ㄹ 받침은 그대로 두고, 명사는 ‘일 때’를 붙여요.動詞は「다」を取り、ㄹ以外のパッチムがあれば「을 때」、パッチムがなければ「ㄹ 때」をつけます。ㄹパッチムはそのまま残し、名詞には「일 때」をつけます。

웃다→웃을 때받침 있음 · ㄹ 제외パッチムあり・ㄹ以外먹다 → 먹을 때
만나다→만날 때받침 없음 → ㄹ 때パッチムなしはㄹ 때기다리다 → 기다릴 때
놀다→놀 때ㄹ 받침은 그대로ㄹパッチムはそのまま걸다 → 걸 때
친구→친구일 때명사 + 일 때名詞には일 때학생 → 학생일 때

맞는 때 표현 고르기 (合う「とき」の形を選ぼう)

동사와 명사의 모양을 보고, 자연스러운 ‘때’ 표현을 눌러 보세요.動詞と名詞の形を見て、自然な「とき」の表現をタップしてください。

時間があるとき、連絡して。시간이 있을 때/ㄹ 때, 연락해.
初めて会うとき、少し緊張した。처음 만나을 때/ㄹ 때, 조금 긴장했어.
一緒に遊ぶとき、いつも楽しかった。같이 놀을 때/놀 때, 항상 즐거웠어.
友達だったころから、そうだった気がする。친구일 때부터/을 때부터, 그랬던 것 같아.

그때를 채워요 (あのときをうめよう)

빈칸에 알맞은 ‘때’ 표현을 넣고, 마음이 시작된 시점까지 말해 보세요.空欄に合う「とき」の表現を入れ、気持ちが始まった時点まで言ってみましょう。

언제부터 좋아했어요? (いつから好き？)

좋아하는 취미나 음식, 사람이 떠오르면 언제부터 좋아했는지 ‘~(으)ㄹ 때부터’로 말해 보세요.好きな趣味や食べ物、人を思い浮かべ、いつから好きだったのか「〜(으)ㄹ 때부터」で話してみましょう。

학생이 부담 없는 주제를 직접 고르게 하고, 시작 시점이 들리도록 문장을 적어 주세요.

‘사실’은 본심을 바로 꺼낼 때 편해요. ‘사실은’은 앞에서 하지 못한 말이나 예상과 다른 속마음을 조심스럽게 열 때 잘 어울려요.「사실」は本音をそのまま切り出すときに自然です。「사실은」は、それまで言えなかったことや予想と違う本音を慎重に切り出すときによく合います。

둘 다 맞는 표현이에요. 숨겨 둔 이야기를 열어 보이는 느낌이 필요한지로 고르게 해 주세요.
