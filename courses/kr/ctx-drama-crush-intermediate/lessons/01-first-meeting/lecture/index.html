ㄴ 적과 은 적 (ㄴ적 と 은적、どっち？)

동사에서 다를 떼고, 남은 글자를 봐 주세요. 받침이 있으면 ‘은 적’, 없으면 ‘ㄴ 적’이에요.動詞から「다」を取って、残った文字を見てください。パッチムがあれば「은 적」、なければ「ㄴ 적」です。

먹 → 은 적 받침 있음パッチムあり（子音で終わる） 먹다 → 먹은 적읽다 → 읽은 적
보 → ㄴ 적 받침 없음パッチムなし（母音で終わる） 보다 → 본 적가다 → 간 적

ㄴ과 은 고르기 (ㄴ と 은 を選ぼう)

받침을 보고, 맞는 쪽을 눌러 보세요.パッチムを見て、正しいほうをタップしてください。

あのカフェに行ったことがあります。 그 카페에 가은/ㄴ 적 있어요.
読んだことがあります。 읽ㄴ/은 적 있어요.
会ったことがあります。 만나ㄴ/은 적 있어요.

아도와 어도 (아도 と 어도、どっち？)

동사에서 다를 떼고, 마지막 모음을 봐 주세요. ㅏ나 ㅗ면 ‘아도’, 나머지는 다 ‘어도’예요.動詞から「다」を取って、最後の母音を見てください。ㅏかㅗなら「아도」、それ以外は全部「어도」です。

하다는 해도, 보다는 봐도로 줄어든다고 알려 주세요.
앉 / 놀 → 아도 ㅏ · ㅗ最後の母音が ㅏ か ㅗ 앉다 → 앉아도놀다 → 놀아도
먹 / 찍 → 어도 그 외ㅓ ㅜ ㅡ ㅣ … それ以外の母音 먹다 → 먹어도찍다 → 찍어도

원어민 팁 (ネイティブのひとこと)

‘돼요?’는 편한 사이에서 바로 허락을 물어요. ‘될까요?’는 처음 보는 사람에게 조금 더 조심스럽게 물을 때 써요.「돼요?」は気楽な相手にそのまま許可を聞きます。「될까요?」は初対面の人に、もう少し控えめに聞くときに使います。

첫 문장은 편하게, 두 번째는 목소리를 조금 낮춰 조심스럽게 읽어 주세요.
