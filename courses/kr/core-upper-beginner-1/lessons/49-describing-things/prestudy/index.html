今日のゴール

名前がわからなくても大丈夫。どんなものかを説明すればいいんです。今日習うのがそれです。

今日はものを説明します。今日使う単語、これも漢字から来ています。

パート 1

예쁜 옷イェップン オッ

「きれいな服」。形容詞を名詞の前に置きます。日本語と同じ順番なので、変えるのは形だけです。

今日のパターン

意味・使い方~な+名詞どんなものかを前につけて、ひとつに絞って指すときに使います。

저기 예쁜 옷을 샀어요.チョギ イェップン オスル サッソヨ あそこできれいな服を買いました。
이건 작은 가방이에요.イゴン チャグン カバンイエヨこれは小さいかばんです。
저는 긴 우산을 찾아요.チョヌン キン ウサヌル チャジャヨ私は長い傘を探しています。

ㄴ と 은、どっち？

形容詞の最後の文字を見てください。パッチムがなければㄴだけのせ、あれば은をつけます。ㄹパッチムはㄹが落ちてㄴが入ります。

쁘→ㄴン パッチムなし 예쁘 → 예쁜イェップン크 → 큰クン
작→은ウン パッチムあり 작 → 작은チャグン좋 → 좋은チョウン
길→긴キン ㄹ パッチムは ㄹ が落ちる 길다 → 긴キン멀다 → 먼モン

正しい言い方を選ぼう

形容詞の最後の文字のパッチムを見て、正しいほうをタップしてください。

きれいな服を買いました。 예쁜/예쁘은 옷을 샀어요.… オスル サッソヨ
小さいかばんを探しています。 작ㄴ/작은 가방을 찾아요.… カバンウル チャジャヨ
長い傘です。 길은/긴 우산이에요.… ウサニエヨ
いいカフェを知っています。 좋은/좋ㄴ 카페를 알아요.… カペルル アラヨ

パート 2

먹는 음식モンヌン ウムシク

今度は動詞です。パッチムを見なくてすみます — 動詞はぜんぶ는ひとつ。ここで初めて、動詞と形容詞の区別が要ります。

今日のパターン

意味・使い方~する+名詞今していることでものや人を説明するときに使います。

제가 자주 먹는 음식이에요.チェガ チャジュ モンヌン ウムシギエヨ 私がよく食べる料理です。
제가 자주 가는 카페예요.チェガ チャジュ カヌン カペエヨ私がよく行くカフェです。
저기 사는 사람이에요.チョギ サヌン サラミエヨあそこに住んでいる人です。

動詞は 는 ひとつ

動詞はパッチムがあってもなくても는です。ただ1つ、ㄹパッチムだけㄹが落ちます。そして「있다」・「없다」は形容詞のように見えますが는を使います。

는ヌン 받침 있든 없든 — 動詞は すべて 먹 → 먹는モンヌン가 → 가는カヌン
살→사는サヌン ㄹ パッチムは ㄹ が落ちる 살다 → 사는サヌン알다 → 아는アヌン

正しい言い方を選ぼう

前のことばが動詞か形容詞かを見て、正しいほうをタップしてください。「맛있다」は形容詞のように見えても는です。

私がよく食べる料理です。 제가 자주 먹는/먹은 음식이에요.チェガ チャジュ … ウムシギエヨ
きれいな服です。 예쁘는/예쁜 옷이에요.… オシエヨ
あそこに住んでいる人です。 저기 살는/사는 사람이에요.チョギ … サラミエヨ
本当においしいキムチです。 진짜 맛있는/맛있은 김치예요.チンチャ … キムチエヨ
