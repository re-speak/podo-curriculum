今日のゴール

これまではどんなものかを説明しましたよね？今日はいつのものか。昨日したこと、明日すること。

もう知っている単語

今日は昨日したことと明日することを言います。今日使う単語、これも漢字から来ています。

パート 1

어제 먹은 음식オジェ モグン ウムシク

「昨日食べた料理」。動詞のうしろに-(으)ㄴをつけると、終わったことになります。形は形容詞と同じ、意味だけが過去です。

今日のパターン

意味・使い方~した+名詞もう終わったことでものや人を説明するときに使います。

어제 먹은 음식이에요.オジェ モグン ウムシギエヨ 昨日食べた料理です。
아까 본 영화가 재미있었어요.アッカ ポン ヨンファガ チェミイッソッソヨさっき見た映画が面白かったです。
제가 만든 김밥이에요.チェガ マンドゥン キムパビエヨ私が作ったキンパです。

ㄴ と 은、どっち？

形容詞のルールと形は同じです。パッチムがなければㄴ、あれば은、ㄹパッチムはㄹが落ちてㄴが入ります。違うのは意味 — 動詞につくと過去です。

보→ㄴン パッチムなし 보 → 본ポン사 → 산サン
먹→은ウン パッチムあり 먹 → 먹은モグン읽 → 읽은イルグン
만들→만든マンドゥン ㄹ パッチムは ㄹ が落ちる 만들다 → 만든マンドゥン놀다 → 논ノン

正しい言い方を選ぼう

上にある日本語を見てください。昨日のことなら「은」、いつもすることなら「는」です。

昨日食べた料理です。 어제 먹는/먹은 음식이에요.オジェ … ウムシギエヨ
私がよく食べる料理です。 제가 자주 먹은/먹는 음식이에요.チェガ チャジュ … ウムシギエヨ
私が作ったキンパです。 제가 만들은/만든 김밥이에요.チェガ … キムパビエヨ
先週買ったかばんです。 지난주에 산/사은 가방이에요.チナンジュエ … カバンイエヨ

パート 2

내일 먹을 음식ネイル モグル ウムシク

「明日食べる料理」。まだしていないこと、これからすること。形はパート1の ㄴ が ㄹ に変わるだけです。

今日のパターン

意味・使い方~する予定の+名詞まだしていないこと、これからすることでものを説明するときに使います。

ㄹ と 을、どっち？

パート1のㄴのところにㄹが入ると思ってください。パッチムがなければㄹ、あれば을。ㄹパッチムはㄹひとつで終わります。

하→ㄹル パッチムなし 하 → 할ハル보 → 볼ポル
먹→을ウル パッチムあり 먹 → 먹을モグル읽 → 읽을イルグル
만들→만들マンドゥル ㄹ パッチムは ㄹ ひとつ 만들다 → 만들 거マンドゥル コ놀다 → 놀 거ノル コ

パート 3

은 · 는 · 을ウン · ヌン · ウル

3つがそろいました。먹은 · 먹는 · 먹을 — 昨日・いつも・明日。同じ動詞、同じ名詞、変わるのは真ん中の一文字だけです。
