던 は ひとつだけ

ここはパッチムを見る必要がありません。辞書の形から「다」だけ取って「던」をつけるだけです。ㄹパッチムもそのまま残ります。

던トン 動詞は すべて、パッチムを見ない 가다 → 가던カドン먹다 → 먹던モクトン살다 → 살던サルドン

正しい言い方を選ぼう

上にある日本語を見てください。今もしているなら「는」、昔していて今はしていないなら「던」です。

았던 と 었던、どっち？

「았어요」・「었어요」を選んだルールそのままです。前の文字の母音がㅏかㅗなら「았던」、それ以外は「었던」。「하다」は「했던」です。

살→았던アットン 母音が ㅏ か ㅗ 살다 → 살았던サラットン보다 → 봤던プァットン
먹→었던オットン それ以外の母音 먹다 → 먹었던モゴットン듣다 → 들었던トゥロットン
하→했던ヘットン 하다 動詞 공부하다 → 공부했던コンブヘットン다니다 → 다녔던タニョットン
