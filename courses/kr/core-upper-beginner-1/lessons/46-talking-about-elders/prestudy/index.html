으세요 と 세요、どっち？

動詞の最後の文字を見てください。パッチムがあれば「으세요」、なければ「세요」です。ㄹパッチムだけ違います — ㄹが落ちて「세요」が来ます。

읽 → 으세요ウセヨ パッチムあり 읽으세요イルグセヨ앉으세요アンジュセヨ
하 → 세요セヨ パッチムなし 좋아하세요チョアハセヨ가세요カセヨ
살 → 사세요サセヨ ㄹ パッチムは ㄹ が落ちる 살다 → 사세요サセヨ알다 → 아세요アセヨ

께서 と 께서는、どっち？
