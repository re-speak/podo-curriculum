今回は、体調を伝えるときによく使う4つの表現を、そのまま覚えましょう。

아프다 → 아픈데アプダ → アプンデ痛いのですが
나다 → 나는데ナダ → ナヌンデ出ているのですが
안 좋다 → 안 좋은데アン チョタ → アン チョウンデよくないのですが
하다 → 하는데ハダ → ハヌンデしているのですが
