ㄴ 적과 은 적 (ㄴ적 と 은적、どっち？)

동사에서 다를 떼고, 남은 글자를 봐 주세요. 받침이 있으면 은 적, 없으면 ㄴ 적이에요.動詞から「다」を取って、残った文字を見てください。パッチムがあれば은 적、なければㄴ 적です。

먹 → 은 적 받침 있음パッチムあり（子音で終わる） 먹다 → 먹은 적읽다 → 읽은 적
보 → ㄴ 적 받침 없음パッチムなし（母音で終わる） 보다 → 본 적가다 → 간 적

먹 / 찍 → 어도 그 외ㅓ ㅜ ㅡ ㅣ … それ以外の母音 먹다 → 먹어도찍다 → 찍어도
