으니까 と 니까、どっち？

最後の文字のパッチムを見てください。パッチムがあれば「으니까」、なければ「니까」です。ㄹパッチムはㄹが落ちて「니까」が来ます。

없→으니까ウニッカ パッチムあり 없 → 없으니까オプスニッカ늦었 → 늦었으니까ヌジョッスニッカ
오→니까ニッカ パッチムなし 오 → 오니까オニッカ바쁘 → 바쁘니까パップニッカ
멀→머니까モニッカ ㄹ パッチムは ㄹ が落ちる 멀다 → 머니까モニッカ살다 → 사니까サニッカ

니까 と 아/어서、どっち？

うしろを見てください。「〜してください」「〜しましょう」のようにすすめる言い方が来ると「아/어서」は使えません。そこは「니까」です。

パート 2

「〜するのはどうですか？」。-는がそのまま入ります。押しつけずにすすめる、いちばん柔らかい言い方です。

今日のパターン

意味・使い方~するのはどうですか相手にやわらかくすすめるときに使います。

는 게 어때요 は ひとつだけ

ここはパッチムを見る必要がありません。動詞-는そのままです。ㄹパッチムだけㄹが落ちます — 「만들다」は「만드는」です。

만들→만드는 게マンドゥヌン ゲ ㄹ パッチムは ㄹ が落ちる 만들다 → 만드는 게マンドゥヌン ゲ살다 → 사는 게サヌン ゲ

正しい言い方を選ぼう

動詞に「는」をつけるところです。「만들다」のようにㄹパッチムならㄹが落ちます。
