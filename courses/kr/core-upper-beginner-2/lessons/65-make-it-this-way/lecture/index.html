받침을 안 봐요 — 게만 붙여요 (パッチムを見ません — 게をつけるだけ)

이 강의에서 제일 쉬운 규칙이에요. 형용사에서 ‘다’만 떼고 ‘게’를 붙이면 끝이에요. 받침이 있든 없든, ‘하다’로 끝나든, 전부 똑같아요.この講座でいちばん簡単なルールです。形容詞から「다」を取って「게」をつけるだけです。パッチムがあってもなくても、「하다」で終わっても、全部同じです。

게ゲ 받침 있음パッチムあり 맛있다 → 맛있게マシッケ짧다 → 짧게ッチャルケ
하게ハゲ 하다 형용사하다形容詞 따뜻하다 → 따뜻하게ッタットゥタゲ조용하다 → 조용하게チョヨンハゲ

가게에서는 ‘안’보다 ‘덜’을 훨씬 많이 써요. ‘안 맵게’는 아예 빼 달라는 거고, ‘덜 맵게’는 조금만 줄여 달라는 거예요. ‘덜’이 부탁을 훨씬 부드럽게 만들어 줘요.お店では「안」より「덜」のほうがずっとよく使われます。「안 맵게」はまったく抜いてほしいということで、「덜 맵게」は少しだけ減らしてほしいということです。「덜」がお願いをぐっとやわらかくします。
