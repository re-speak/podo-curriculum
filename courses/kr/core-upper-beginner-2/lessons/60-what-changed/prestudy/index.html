今日のゴール

変わったことを話します。前はそうではなかったのに今はそうなった、それを言う2つの方法です。

もう知っている単語

今日は昔と今をくらべます。今日使う単語、これも漢字から来ています。

偶然→우연히ウヨニ

パート 1

-아/어지다アオジダ

「〜くなる」。形容詞につけて、状態が変わったことを言います。前はそうではなかった、という含みがあります。

今日のパターン

意味・使い方~くなる形容詞につけて、状態が変わったことを言います。

요즘 날씨가 많이 따뜻해졌어요.ヨジュム ナルッシガ マニ ッタットゥテジョッソヨ 最近天気がとても暖かくなりました。

밤에는 날씨가 갑자기 추워졌어요.パメヌン ナルッシガ カプチャギ チュウォジョッソヨ夜は天気が急に寒くなりました。

아・어・해 — またあのルール

ここも「아/어」を選ぶルールです。形容詞を「아/어요」に変えるときと同じにして、うしろに「졌어요」をつけるだけです。「예뻐요」なら「예뻐졌어요」、「추워요」なら「추워졌어요」。

아졌어요アジョッソヨ ㅏ・ㅗ の母音 좋다 → 좋아졌어요チョアジョッソヨ많다 → 많아졌어요マナジョッソヨ
어졌어요オジョッソヨ それ以外の母音 예쁘다 → 예뻐졌어요イェッポジョッソヨ춥다 → 추워졌어요チュウォジョッソヨ
해졌어요ヘジョッソヨ 하다形容詞 따뜻하다 → 따뜻해졌어요ッタットゥテジョッソヨ편하다 → 편해졌어요ピョネジョッソヨ

前の形容詞の母音を見て、「아/어/해」の中から正しいほうをタップしてください。

パート 2

-게 되다ゲ トェダ

「〜することになる」「〜するようになる」。動詞につけます。自分で決めたというより、そうなった、という含みがあります。

今日のパターン

意味・使い方~することになる・~するようになる動詞につけます。

저는 한국어를 좋아하게 됐어요.チョヌン ハングゴルル チョアハゲ トェッソヨ 私は韓国語が好きになりました。
작년부터 한국에 살게 됐어요.チャンニョンブト ハングゲ サルゲ トェッソヨ去年から韓国に住むことになりました。
이제 매운 것도 먹게 됐어요.イジェ メウン ゴット モクケ トェッソヨもう辛いものも食べられるようになりました。

形容詞なら 아/어지다、動詞なら 게 되다

パッチムは見ません。ここで分かれるのは、そのことばが形容詞か動詞かです。あの区別が今日もまた働きます。「게 되다」はパッチムに関係なくいつも同じです。

아/어지다アオジダ 形容詞 — 状態が変わる 좋다 → 좋아졌어요チョアジョッソヨ따뜻하다 → 따뜻해졌어요ッタットゥテジョッソヨ
게 되다ゲ トェダ 動詞 — そうなる 알다 → 알게 됐어요アルゲ トェッソヨ살다 → 살게 됐어요サルゲ トェッソヨ
