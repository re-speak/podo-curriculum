아/어 は まま

新しく覚えることはありません。「아/어 주세요」の「주세요」のところを「주시겠어요」に変えるだけです。前の「아/어」の選び方は何も変わりません。

아 주시겠어요ア ジュシゲッソヨ ㅏ・ㅗ の母音 보다 → 봐 주시겠어요プァ ジュシゲッソヨ앉다 → 앉아 주시겠어요アンジャ ジュシゲッソヨ
어 주시겠어요オ ジュシゲッソヨ それ以外の母音 찍다 → 찍어 주시겠어요ッチゴ ジュシゲッソヨ열다 → 열어 주시겠어요ヨロ ジュシゲッソヨ
