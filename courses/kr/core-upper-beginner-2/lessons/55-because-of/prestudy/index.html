때문에 の前は 名詞だけ

パッチムは見ません。かわりに前に助詞をつけてはいけません。「비가 때문에」・「비를 때문에」はありません。ただ「비 때문에」です。

パート 2

N(으)로ウロ / ロ

「〜で」。乗り物に使った(으)로が、そのまま原因にも使えます。형は変わらず、意味だけが増えます。

今日のパターン

意味・使い方~で버스로のように手段に使いましたよね？

감기로 결석했어요.カムギロ キョルソケッソヨ 風邪で欠席しました。
사고로 길이 막혔어요.サゴロ キリ マキョッソヨ事故で道が混みました。
일로 바빠서 못 갔어요.イルロ パッパソ モッ カッソヨ仕事で忙しくて行けませんでした。

으로 と 로、どっち？

ルールそのままです。パッチムがあれば「으로」、なければ「로」。ただしㄹパッチムだけは「로」です — 「일로」・「서울로」のように。

풍→으로ウロ パッチムあり 태풍 → 태풍으로テプンウロ사건 → 사건으로サッコヌロ
기→로ロ パッチムなし 감기 → 감기로カムギロ사고 → 사고로サゴロ
일→로ロ ㄹ パッチムは 으 が つかない 일 → 일로イルロ서울 → 서울로ソウルロ
