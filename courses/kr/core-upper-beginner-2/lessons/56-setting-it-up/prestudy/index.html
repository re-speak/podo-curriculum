パート 1

-는데ヌンデ

「〜なんですが」。本題の前に状況をひと言おきます。反対をつなぐこともありますが、日本語の「けど」よりずっと軽いです。

今日のパターン

意味・使い方~なんですが本題を出す前に背景をおくときに使います。

어제 영화 봤는데 진짜 재미있었어요.オジェ ヨンファ プァンヌンデ チンチャ チェミイッソッソヨ 昨日映画を見たんですが、本当に面白かったです。

이 카페 좋은데 좀 시끄러워요.イ カペ チョウンデ チョム シックロウォヨこのカフェいいんですが、ちょっとうるさいです。

動詞なら 는데、形容詞なら ㄴ데

ここはパッチムではなく品詞を見ます。動詞は「는」、形容詞は「은/ㄴ」でしたよね？そのルールがそのまま来ます。そして過去は品詞に関係なく「았/었는데」です。

는데ヌンデ 動詞 — 今していること 먹다 → 먹는데モンヌンデ가다 → 가는데カヌンデ
(으)ㄴ데ウンデ / ンデ 形容詞 — どんなか 좋다 → 좋은데チョウンデ춥다 → 추운데チュウンデ
았/었는데アンヌンデ / オンヌンデ 過去 — 品詞に関係なく 보다 → 봤는데プァンヌンデ먹다 → 먹었는데モゴンヌンデ

パート 2

-(으)ㄴ/는데요ウンデヨ / ヌンデヨ

「〜なんですが…」で文を止めます。最後まで言わないことで、相手に察してもらう。韓国語でいちばん角の立たない言い方です。

今日のパターン

意味・使い方~なんですが…うしろの言葉を言わずに残して、相手に察してもらいます。

저기요, 좀 추운데요…チョギヨ、チョム チュウンデヨ あの、ちょっと寒いんですが…
이거 좀 비싼데요…イゴ チョム ピッサンデヨこれちょっと高いんですが…
지금 기다리고 있는데요…チグム キダリゴ インヌンデヨ今待っているんですが…

데요 は 데 に 요 だけ

新しいルールではありません。パート1の「는데」・「(으)ㄴ데」のうしろに「요」をつけて、そこで止めるだけです。選び方は同じです。

는데요ヌンデヨ 動詞・過去 먹다 → 먹는데요モンヌンデヨ있다 → 있는데요インヌンデヨ
(으)ㄴ데요ウンデヨ / ンデヨ 形容詞 춥다 → 추운데요チュウンデヨ비싸다 → 비싼데요ピッサンデヨ

正しい言い方を選ぼう

パート1と同じ方法です。動詞なら「는데요」、形容詞なら「(으)ㄴ데요」です。
