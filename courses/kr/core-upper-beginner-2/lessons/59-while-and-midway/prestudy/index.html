今日のゴール

2つをつなぐ言い方です。1つは同時にすること、もう1つは途中でほかのことに変わることです。

もう知っている単語

今日は一日の習慣の話をします。今日使う単語、これも漢字から来ています。

「〜しながら」。2つのことを同時にします。大事な条件が1つ — 前とうしろの人が同じでなければいけません。

パッチムを見て 으면서・면서

ㄹパッチムはすでにㄹがあるので「으」を取りません。「듣다」だけが違います — ㄷがㄹに変わって「들으면서」になります。

으면서ウミョンソ パッチムあり 먹다 → 먹으면서モグミョンソ읽다 → 읽으면서イルグミョンソ
면서ミョンソ パッチムなし 보다 → 보면서ポミョンソ마시다 → 마시면서マシミョンソ
면서ミョンソ ㄹパッチム — 으なし 만들다 → 만들면서マンドゥルミョンソ놀다 → 놀면서ノルミョンソ

正しい言い方を選ぼう

前の動詞にパッチムがあるかを見て、正しいほうをタップしてください。「듣다」は「들으면서」であることだけ覚えてください。

パート 2

-다가タガ

「〜していて」「〜する途中で」。していたことが途中で切れて、別のことが始まります。ながらとは違って、2つは重なりません。

今日のパターン

意味・使い方~していて・~する途中でしていたことが途中で切れて、別のことが始まります。

어제 저는 공부하다가 잠들었어요.オジェ チョヌン コンブハダガ チャムドゥロッソヨ 昨日私は勉強していて寝てしまいました。
집에 가다가 친구를 만났어요.チベ カダガ チングルル マンナッソヨ家に帰る途中で友だちに会いました。
책을 읽다가 그냥 잤어요.チェグル イクタガ クニャン チャッソヨ本を読んでいてそのまま寝ました。

パッチムに関係なく 다가

パート1の「(으)면서」はパッチムを見ました。でも「다가」は見ません。動詞から「다」を取って「다가」をつけるだけです。3つとも同じく「다가」です。

다가タガ パッチムなし 가다 → 가다가カダガ보다 → 보다가ポダガ
다가タガ パッチムあり 먹다 → 먹다가モクタガ읽다 → 읽다가イクタガ
다가タガ ㄹパッチム 놀다 → 놀다가ノルダガ만들다 → 만들다가マンドゥルダガ

正しい言い方を選ぼう

今度は形ではなく意味です。2つを同時にするなら「면서」、していたことをやめて別のことをするなら「다가」です。日本語をよく読んでみてください。
