아 · 어 · 해 — 와 같아요 (아・어・해 — 同じ)

‘아/어졌어요’하고 앞부분이 똑같아요. 형용사를 ‘아/어요’로 바꾸고, ‘졌어요’ 대신 ‘보여요’를 붙이면 돼요. ‘좋아요’면 ‘좋아 보여요’, ‘어려워요’면 ‘어려워 보여요’.「아/어졌어요」と前の部分がまったく同じです。形容詞を「아/어요」に変えて、「졌어요」のかわりに「보여요」をつけるだけです。「좋아요」なら「좋아 보여요」、「어려워요」なら「어려워 보여요」。

원어민 팁 (ネイティブのひとこと)

한국 사람은 자기 의견도 ‘것 같아요’로 말해요. ‘좋아요’라고 딱 잘라 말하면 좀 세게 들려서, ‘좋은 것 같아요’로 한 칸 물러서요. 뜻은 거의 같아요.韓国の人は自分の意見も「것 같아요」で言います。「좋아요」と言い切ると少し強く聞こえるので、「좋은 것 같아요」と一歩ひきます。意味はほとんど同じです。
