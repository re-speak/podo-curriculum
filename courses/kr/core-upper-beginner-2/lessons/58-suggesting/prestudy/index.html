받침 보고 을래요 · ㄹ래요 (パッチムを見て 을래요・ㄹ래요)

받침이 있으면 ‘을래요’, 없으면 ‘ㄹ래요’예요. ㄹ 받침은 이미 ㄹ이 있으니까 ‘을’을 안 받아요. ‘(으)ㄹ 거예요’하고 똑같은 규칙이에요.パッチムがあれば「을래요」、なければ「ㄹ래요」です。ㄹパッチムはすでにㄹがあるので「을」を取りません。「(으)ㄹ 거예요」とまったく同じルールです。

을래요ウルレヨ 받침 있음パッチムあり 먹다 → 먹을래요モグルレヨ앉다 → 앉을래요アンジュルレヨ
ㄹ래요ルレヨ 받침 없음パッチムなし 보다 → 볼래요ポルレヨ가다 → 갈래요カルレヨ
래요レヨ ㄹ 받침 — 을 없이ㄹパッチム — 을なし 만들다 → 만들래요マンドゥルレヨ놀다 → 놀래요ノルレヨ
