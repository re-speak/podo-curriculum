パート 1

~(으)ㄹ 생각은 하지도 마

まず、言い訳が始まる前に、その意図ごとはっきり止めます。

始める前に止めよう

意味・使い方始めることすら許さない、と先に止めるときに使います。

핑계 댈 생각은 하지도 마.言い訳しようなんて考えないで。
책임을 피할 생각은 하지도 마.責任から逃れようなんて考えないで。
사실을 숨길 생각은 하지도 마.事実を隠そうなんて考えないで。

을 생각 と ㄹ 생각

動詞から「다」を取り、「ㄹ」以外のパッチムがあれば「을」をつけます。パッチムがなければㄹをつけ、ㄹパッチムはそのまま残します。

핑계를 대다 → 핑계 댈 생각은 하지도 마言い訳をする → 言い訳しようなんて考えないで
먹→먹을 생각パッチムあり・ㄹ以外덮다 → 덮을 생각
하→피할 생각パッチムなしはㄹをつける피하다 → 피할 생각
열→열 생각ㄹパッチムはそのまま열다 → 열 생각

을 と ㄹ を選ぼう

動詞のパッチムを見て、「생각」の前に置く正しい形をタップしてください。

事実を隠そうなんて考えないで。사실을 숨기ㄹ/을 생각은 하지도 마.
ミスを隠そうなんて考えないで。실수를 덮ㄹ/을 생각은 하지도 마.
条件を変えようなんて考えないで。조건을 바꾸을/ㄹ 생각은 하지도 마.
私のファイルを開こうなんて考えないで。내 파일을 열ㄹ/을 생각은 하지도 마.

パート 2

~지도 않고

次は、当然するべき確認さえしなかった事実を突きます。

省いた過程を指摘しよう

意味・使い方私に聞きもしなかった、と問いつめるときに使います。

나한테 묻지도 않고 마음대로 결정한 거야?私に聞きもせず、勝手に決めたの？
내용을 확인하지도 않고 서명했어?内容を確認もせず署名したの？
나한테 알리지도 않고 진행했어?私に知らせもせず進めたの？

지도 않고 のつけ方

動詞から「다」を取り、「지도 않고」をつけます。動詞が変わっても、今日学ぶ形は変わりません。

묻다→묻지도 않고動詞＋もしないまま확인하다 → 확인하지도 않고알리다 → 알리지도 않고
