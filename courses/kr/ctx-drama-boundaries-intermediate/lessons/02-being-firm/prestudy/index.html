今日のゴール

これ以上我慢する理由はないと一線を引き、自分で処理することだと相手の介入を止められるようになります。

関係ない

「重要ではない」より強い表現です。判断するとき、その条件は除くという意味です。

결과와 상관없어.結果とは関係ない。
누가 먼저 했는지는 상관없어.誰が先にやったかは関係ない。
좋은 의도였는지는 상관없어.善意だったかどうかは関係ない。

같은 실수를 덮어 줄 이유가 없어.同じミスをかばってあげる理由はない。

을 이유 と ㄹ 이유

動詞から「다」を取り、「ㄹ」以外のパッチムがあれば「을」をつけます。パッチムがなければㄹをつけ、ㄹパッチムはそのまま残します。

참→을 이유パッチムあり・ㄹ以外참다 → 참을 이유믿다 → 믿을 이유
리→ㄹ 이유パッチムなしはㄹをつける기다리다 → 기다릴 이유
들→들 이유ㄹパッチムはそのまま들다 → 들 이유

을 と ㄹ を選ぼう

動詞のパッチムとㄹを見て、正しいほうをタップしてください。

我慢する理由はない。참을/ㄹ 이유가 없어.
待つ理由はない。기다리ㄹ/을 이유가 없어.
信じる理由はない。믿ㄹ/을 이유가 없어.
先延ばしする理由はない。미루을/ㄹ 이유가 없어.

을＋名詞 と ㄹ＋名詞

「ㄹ」以外のパッチムには「을」をつけます。パッチムがなければㄹをつけ、ㄹパッチムはそのまま残してから名詞を置きます。

맡→맡을 문제パッチムあり・ㄹ以外맡다 → 맡을 문제읽다 → 읽을 부분
하→할 + 명사パッチムなしはㄹをつける하다 → 할 문제
들→들 + 명사ㄹパッチムはそのまま만들다 → 만들 생각
