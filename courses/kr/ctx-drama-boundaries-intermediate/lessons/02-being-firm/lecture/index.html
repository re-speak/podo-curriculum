을 이유와 ㄹ 이유 (을 이유 と ㄹ 이유)

동사에서 ‘다’를 떼고, ‘ㄹ’을 제외한 받침이 있으면 ‘을’을 붙여요. 받침이 없으면 ㄹ을 붙이고, ㄹ 받침은 그대로 둬요.動詞から「다」を取り、「ㄹ」以外のパッチムがあれば「을」をつけます。パッチムがなければㄹをつけ、ㄹパッチムはそのまま残します。

참→을 이유받침 있음 · ㄹ 제외パッチムあり・ㄹ以外참다 → 참을 이유믿다 → 믿을 이유
리→ㄹ 이유받침 없음 → ㄹパッチムなしはㄹをつける기다리다 → 기다릴 이유
들→들 이유ㄹ 받침은 그대로ㄹパッチムはそのまま들다 → 들 이유

을 명사와 ㄹ 명사 (을＋名詞 と ㄹ＋名詞)

‘ㄹ’을 제외한 받침에는 ‘을’을 붙여요. 받침이 없으면 ㄹ을 붙이고, ㄹ 받침은 그대로 둔 뒤 명사를 놓아요.「ㄹ」以外のパッチムには「을」をつけます。パッチムがなければㄹをつけ、ㄹパッチムはそのまま残してから名詞を置きます。

들→들 + 명사ㄹ 받침은 그대로ㄹパッチムはそのまま만들다 → 만들 생각
