今日のゴール

提案を丁寧かつ明確に断り、自分が引き受ける必要のない条件に一線を引けるようになります。

わざわざ

「できない」のではなく、選べるならそうする理由がない、という意味です。不要な手間や譲歩を断るときに使います。

내가 굳이 해야 해?私がわざわざやる必要がある？
굳이 오늘 결정할 필요는 없어.わざわざ今日決める必要はない。
굳이 내 이름을 넣을 이유가 없어.わざわざ私の名前を入れる理由はない。
パート 1

~기(가) 힘들다

まず、「嫌だ」とぶつけず、受け入れにくいという判断で断ります。

判断として断ろう

意味・使い方いやだとは言わずに、やわらかく断るときに使います。

미안하지만 그 제안은 받아들이기 힘들어.悪いけど、その提案は受け入れにくい。
내 이름을 빌려주기 힘들어.私の名前を貸すのは難しい。
지금 바로 결정하기 힘들어.今すぐ決めるのは難しい。

기가 힘들다 のつけ方

動詞から「다」を取り、「기가 힘들다」をつけます。「가」はよく省略され、「기 힘들다」とも言います。

받아들이다→받아들이기 힘들다動詞＋するのは難しい빌려주다 → 빌려주기 힘들다동의하다 → 동의하기 힘들다

断りのセリフを作ろう

4つのことばを順番に並べて、感情ではなく判断として断ってみましょう。

悪いけど、今の条件ではその提案を受け入れにくい。
그 제안을미안하지만받아들이기 힘들어지금 조건으로는
責任が伴うから、私の名前を貸すのは難しい。
내 이름을빌려주기 힘들어책임이생기니까
資料が足りないから、この件について今日すぐ決定を下すのは難しい。
오늘 바로자료가 부족해서결정을 내리기 힘들어이 사안에 대해
私だけが損をする条件には、簡単には同意しにくい。
쉽게동의하기 힘들어나만 손해 보는조건에는
パート 2

~(으)ㄹ 필요는 없다

次は、「そこまでする義務はない」と必要性そのものに線を引きます。

不要な譲歩を止めよう

意味・使い方そこまでする理由はない、と線を引きます。

내가 굳이 그렇게까지 할 필요는 없잖아.私がわざわざそこまでする必要はないでしょ。
오늘 바로 결정할 필요는 없어.今日すぐ決める必要はない。
내 이름을 빌려줄 필요는 없어.私の名前を貸す必要はない。

을 필요 と ㄹ 필요

動詞から「다」を取り、「ㄹ」以外のパッチムがあれば「을」をつけます。パッチムがなければㄹをつけ、ㄹパッチムはそのまま残します。

그렇게까지 하다 → 그렇게까지 할 필요는 없다そこまでする → そこまでする必要はない
믿→믿을 필요パッチムあり・ㄹ以外맡다 → 맡을 필요
하→할 필요パッチムなしはㄹをつける결정하다 → 결정할 필요
열→열 필요ㄹパッチムはそのまま열다 → 열 필요

을 と ㄹ を選ぼう

動詞のパッチムを見て、「필요」の前に置く正しい形をタップしてください。

その説明を信じる必要はない。그 설명을 믿ㄹ/을 필요는 없어.
今日決める必要はない。오늘 결정하을/ㄹ 필요는 없어.
返事を急ぐ必要はない。대답을 서두르을/ㄹ 필요는 없어.
その責任を引き受ける必要はない。그 책임을 맡을/ㄹ 필요는 없어.

一線を引くセリフを作ろう

4つのことばを順番に並べて、不要な手間や譲歩を断ってみましょう。

私がわざわざそこまで責任を負う必要はないでしょ。
내가 굳이필요는 없잖아그렇게까지책임질
情報が足りないのに、今日すぐ決める必要はない。
오늘 바로정보가 부족한데필요는 없어결정할
私が損をする条件を、無理に受け入れる必要はない。
받아들일필요는 없어내가 손해 보는 조건을억지로
責任が生じるなら、私の名前を貸す必要はない。
내 이름을책임이 생긴다면필요는 없어빌려줄
