을 필요와 ㄹ 필요 (을 필요 と ㄹ 필요)

동사에서 ‘다’를 떼고, ‘ㄹ’을 제외한 받침이 있으면 ‘을’을 붙여요. 받침이 없으면 ㄹ을 붙이고, ㄹ 받침은 그대로 둬요.動詞から「다」を取り、「ㄹ」以外のパッチムがあれば「을」をつけます。パッチムがなければㄹをつけ、ㄹパッチムはそのまま残します。

그렇게까지 하다 → 그렇게까지 할 필요는 없다そこまでする → そこまでする必要はない
믿→믿을 필요받침 있음 · ㄹ 제외パッチムあり・ㄹ以外맡다 → 맡을 필요
하→할 필요받침 없음 → ㄹパッチムなしはㄹをつける결정하다 → 결정할 필요
열→열 필요ㄹ 받침은 그대로ㄹパッチムはそのまま열다 → 열 필요
