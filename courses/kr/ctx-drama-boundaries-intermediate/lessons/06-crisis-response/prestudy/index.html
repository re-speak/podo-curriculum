今日のゴール

今は責任を押し付け合っている場合ではないと整理し、今の流れが続けば事態が悪化すると警告できるようになります。

危機を収拾する言葉

相手の非だけでなく、状況と次の行動も一緒に伝えてみましょう。

남 탓하다人のせいにする
상황을 수습하다事態を収拾する
일이 커지다事態が大きくなる
パート 1

~(으)ㄹ 때가 아니다

責任争いを止め、今の優先順位をはっきりさせます。

今すべきことではないと伝えよう

意味・使い方今はその場合じゃない、と順番を変えます。

지금 남 탓할 때가 아니야.今は人のせいにしている場合じゃない。
지금 서로 싸울 때가 아니야.今はお互いに争っている場合じゃない。
아직 포기할 때가 아니야.まだ諦めるときじゃない。

動詞と 때가 아니다 をつなごう

動詞の辞書形を最後まで確認してから「다」を取ります。パッチムがあれば「을」、なければ「ㄹ」をつけます。ㄹパッチムはそのままです。

남 탓하다 → 남 탓할 때가 아니다人のせいにする → 人のせいにしている場合ではない
숨다→숨을 때가 아니다パッチムあり
미루다→미룰 때가 아니다パッチムなし
울다→울 때가 아니다ㄹパッチム

을 때 と ㄹ 때 を選ぼう

辞書形のパッチムを見て、自然な形をタップしてください。

今は隠れている場合じゃない。숨ㄹ/숨을 때가 아니야.
今は先延ばしにしている場合じゃない。미루을/미룰 때가 아니야.
今は泣いている場合じゃない。울을/울 때가 아니야.
今は人のせいにしている場合じゃない。남 탓할/하을 때가 아니야.

状況を整理するセリフを作ろう

4つのことばを順番に並べ、今止めるべき行動をはっきり伝えましょう。

今は人のせいにしている場合じゃない。
때가지금남 탓할아니야
今はお互いに責任を押し付け合っている場合じゃない。
책임을 미룰아니야지금 서로때가
今は記事の内容を推測している場合じゃない。
때가 아니야기사 내용을지금추측할
まだ諦めるときじゃない。
포기할아직때가 아니야여기서
パート 2

이러다(가) ~겠어

目の前の流れを見て、この先に起こりそうな危険を警告します。

流れを見てその場で警告しよう

意味・使い方このままだともっと大きくなる、と警告するときに使います。

이러다가 일 더 커지겠어.このままだと、事態がもっと大きくなりそう。
이러다가 기사 더 퍼지겠어.このままだと記事がもっと広まりそう。
이러다가 대응이 늦어지겠어.このままだと対応が遅れそう。

今の流れと予想される結果をつなごう

「이러다가」の後ろに、今の流れから起こる結果を置き、その結果の動詞・形容詞に「겠어」をつけます。会話では「이러다」のように「가」をよく省略します。

이러다가 + 일이 더 커지다 → 이러다가 일 더 커지겠어このまま進む + 事態が大きくなる → このままだと事態がもっと大きくなりそう
이러다(가)+현재 흐름今見えている状況
일이 커지다→일이 커지겠어予想される結果

危険を警告する文を作ろう

4つのことばを順番に並べ、今の流れが招く結果を警告しましょう。

このままだと、事態がもっと大きくなりそう。
더이러다가커지겠어일
このままだと、記事が全部広まりそう。
기사가퍼지겠어다이러다가
このままだと、対応がもっと遅れそう。
더늦어지겠어대응이이러다가
このままだと、収拾する機会まで逃しそう。
놓치겠어수습할이러다가기회까지
パート 3

위기를 멈추고 움직이기

責任争いを止め、悪化する前に最初の行動を決めます。

危機の場面をもう一度

二人のせりふを続けて読んでみましょう。最初のセリフは議論を止め、次のセリフは行動を促します。
