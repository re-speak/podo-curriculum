동사와 때가 아니다 잇기 (動詞と 때가 아니다 をつなごう)

동사의 기본형을 온전히 확인한 뒤 ‘다’를 떼어요. 받침이 있으면 ‘을’, 받침이 없으면 ‘ㄹ’을 붙여요. ㄹ 받침은 그대로 두어요.動詞の辞書形を最後まで確認してから「다」を取ります。パッチムがあれば「을」、なければ「ㄹ」をつけます。ㄹパッチムはそのままです。

남 탓하다 → 남 탓할 때가 아니다人のせいにする → 人のせいにしている場合ではない
숨다→숨을 때가 아니다받침 → 을 때가 아니다パッチムあり
미루다→미룰 때가 아니다받침 없음 → ㄹ 때가 아니다パッチムなし
울다→울 때가 아니다ㄹ 받침 → 때가 아니다ㄹパッチム

원어민 팁 (ネイティブのひとこと)

‘이대로면’은 상태가 그대로일 때의 조건을 차분히 말해요. ‘이러다가는’ 움직이는 흐름이 좋지 않은 결과로 이어질 것 같아 더 급하게 경고하는 느낌이에요.「이대로면」は、状態がこのままならという条件を落ち着いて述べます。「이러다가는」、進行中の流れが悪い結果につながりそうで、より切迫した警告に聞こえます。

첫 문장은 상황을 분석하듯, 두 번째는 눈앞에서 문제가 커지는 것을 보고 막듯 읽어 주세요.
상태가 그대로일 때의 조건状態が変わらない場合の条件이대로면 오늘 안에 못 끝내.このままなら今日中に終わらない。
흐름을 보는 방식 流れの捉え方
나빠지는 흐름을 급히 경고悪化する流れを急いで警告이러다가는 기사 더 퍼지겠어.このままだと記事がもっと広まりそう。
