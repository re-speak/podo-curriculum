今日のワンシーン

バスの中で母からの電話を受けます。母が自分の言い方を認め、理解を求めることばを聞き、「나」の役で受け止めましょう。

엄마
그리고… 아까 밥 먹으면서 엄마가 한 말 있잖아.それから…さっきご飯を食べながら、お母さんが言ったことあるでしょ。
나
응. 왜?うん。どうしたの？
엄마
아까는 엄마가 좀 심했지?さっきはお母さん、ちょっと言いすぎたよね？
나
아니야. 나도 좀 그랬어.ううん。私もちょっと悪かった。

今日のゴール

母が自分の言い方がきつかったと先に認め、つらかったとしても母の気持ちを理解してほしいと頼む言い方を聞き取れます。

先に仲直りするときのことば

母が以前のことばを振り返り、気持ちを説明する3つの表現です。

말이 좀 심했어.言い方が少しきつかった。
엄마 마음을 이해해 줘.母さんの気持ちを理解して。
아까 한 말 있잖아.さっき言ったことあるでしょ。
パート 1

~았/었지?

まず、過ぎた自分の行動を振り返り、相手にもそうだったと確認する母のことばを聞き取ります。

先に非を認めることば

意味・使い方言いすぎたよね、と自分から認めるときに使います。

아까는 엄마가 좀 심했지?さっきはお母さん、ちょっと言いすぎたよね？
엄마가 너무 화냈지?お母さん、怒りすぎたよね？
내 말이 많이 속상했지?私のことばで、とてもつらかったよね？

았지 と 었지

辞書形の最後の母音がㅏ・ㅗなら「았지」、それ以外は「었지」をつけます。「하다」は「했지」になります。

심하다→심했지?하다は했지미안하다 → 미안했지?
화나다→화났지?ㅏ・ㅗは았지가다 → 갔지?
힘들다→힘들었지?その他は었지먹다 → 먹었지?

았지 と 었지を選ぼう

辞書形と母音を見て、正しい過去の確認をタップしましょう。

母さん、怒りすぎたよね？엄마가 너무 화냈지/화내았지?
昨日行ったよね？어제 가었지/갔지?
ちゃんと食べたよね？밥 잘 먹었지/먹았지?
つらかったよね？많이 힘들었지/힘들았지?

母の認めることばを組み立てよう

4つのかたまりを並べ、母が何を先に認めるのか確認しましょう。

さっきは母さん、少し言いすぎたよね？
엄마가아까는좀심했지
母さんがさっき、あまりに怒りすぎたよね？
아까엄마가너무화냈지
母さんのことばで、あなたはとてもつらかったよね？
너도엄마 말 때문에많이속상했지
食卓の雰囲気がさっきからずっと気まずかったよね？
아까부터밥상 분위기가계속어색했지
パート 2

~았/었어도

次に、「そうだったとしても」と相手の感情を認めたうえで、理解を求める母のことばを聞き取ります。

相手の気持ちを認めて頼むことば

意味・使い方つらかっただろうけど、それでも分かってほしいと頼みます。

속상했어도 네가 이해해 줘.つらかったとしても、お母さんの気持ちをわかってね。
화났어도 엄마 말 좀 들어 줘.腹が立ったとしても、母さんの話を聞いて。
서운했어도 엄마 마음은 알아줘.傷ついたとしても、母さんの気持ちはわかって。

았어도 と 었어도

辞書形の最後の母音がㅏ・ㅗなら「았어도」、それ以外は「었어도」をつけます。「하다」は「했어도」になります。

속상하다→속상했어도하다は했어도미안하다 → 미안했어도
화나다→화났어도ㅏ・ㅗは았어도놀라다 → 놀랐어도
힘들다→힘들었어도その他は었어도먹다 → 먹었어도

았어도 と 었어도を選ぼう

辞書形と母音を見て、正しい譲歩表現をタップしましょう。

つらかったとしても、母さんの気持ちをわかってね。속상했어도/속상았어도 이해해 줘.
腹が立ったとしても話を聞いて。화났어도/화나었어도 말은 들어 줘.
食べたとしても、もう少し食べて。밥을 먹았어도/먹었어도 조금 더 먹어.
つらかったとしても連絡して。힘들았어도/힘들었어도 연락해.

理解を求めることばを組み立てよう

4つのかたまりを並べ、母が認めた感情とお願いを確認しましょう。

つらかったとしても、母さんの気持ちをわかってね。
네가속상했어도엄마를이해해 줘
腹が立ったとしても、母さんの話を少し聞いて。
엄마 말화났어도좀들어 줘
傷ついたとしても、母さんの気持ちだけはわかって。
엄마서운했어도마음만은알아줘
驚いたとしても、今は母さんのことをわかってね。
지금은놀랐어도엄마를이해해 줘
