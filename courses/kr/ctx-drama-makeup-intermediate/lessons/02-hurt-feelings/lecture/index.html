을 수와 ㄹ 수 (을 수 と ㄹ 수)

동사에서 다를 떼고, ㄹ을 제외한 받침이 있으면 을을 붙여요. 받침이 없으면 ㄹ을 붙이고, ㄹ 받침은 그대로 둔 뒤 ‘수가 있어?’를 붙여요.動詞から「다」を取り、ㄹ以外のパッチムがあれば을をつけます。パッチムがなければㄹをつけ、ㄹパッチムはそのまま残してから「수가 있어?」をつけます。

믿→을 수가 있어?받침 있음 · ㄹ 제외パッチムあり・ㄹ以外믿다 → 믿을 수가 있어?잊다 → 잊을 수가 있어?
가→ㄹ 수가 있어?받침 없음 → ㄹパッチムなしはㄹをつける가다 → 갈 수가 있어?하다 → 할 수가 있어?
알→수가 있어?ㄹ 받침은 그대로ㄹパッチムはそのまま알다 → 알 수가 있어?만들다 → 만들 수가 있어?

을과 ㄹ 고르기 (을 と ㄹ を選ぼう)

ㄹ 받침은 그대로 두고, 여기서는 나머지 동사의 두 갈래를 연습해요.ㄹパッチムはそのままにして、ここでは残りの動詞の2つの形を練習します。

아서와 어서, 그리고 해서 (아서・어서・해서)

동사나 형용사에서 ‘다’를 떼고, 마지막 모음이 ㅏ나 ㅗ면 ‘아서’, 그 외에는 ‘어서’를 붙여요. ‘하다’는 ‘해서’가 되고, 모음이 만나면 줄어들기도 해요.動詞や形容詞から「다」を取り、最後の母音がㅏかㅗなら「아서」、それ以外なら「어서」をつけます。「하다」は「해서」になり、母音が重なると縮まることもあります。

참→아서ㅏ · ㅗ最後の母音がㅏかㅗ참다 → 참아서좋다 → 좋아서
먹→어서그 외それ以外の母音먹다 → 먹어서기다리다 → 기다려서
하→해서하다 → 해서하다は해서になる서운하다 → 서운해서답답하다 → 답답해서

아서와 어서 고르기 (아서 と 어서 を選ぼう)

‘하다’는 ‘해서’로 만들고, 여기서는 ㅏ·ㅗ와 그 외의 두 갈래를 연습해요.「하다」は「해서」にして、ここではㅏ・ㅗとそれ以外の2つの形を練習します。

원어민 팁 (ネイティブのひとこと)

행동 자체가 믿기지 않아 따질 때는 ‘어떻게 이럴 수가 있어?’라고 해요. 이유를 먼저 듣고 싶다면 ‘왜 그랬어?’라고 물으면 비난이 조금 줄어요.行動そのものが信じられず責めるときは「어떻게 이럴 수가 있어?」と言います。まず理由を聞きたいなら「왜 그랬어?」と尋ねると、責める響きが少し弱まります。

두 문장 모두 반말로 유지하고, 첫 문장은 상처를 눌러서, 두 번째는 답을 기다리는 억양으로 읽어 주세요.
행동 자체를 믿기 어려울 때行動そのものが信じがたいとき어떻게 나한테 이럴 수가 있어?どうして私にこんなことができるの？
