오해

疑いは誤解でした。でも、強くぶつけた言葉の意味まで誤解されたままです。今度は言い訳ではなく、本当の意図を伝えます。

나あなたの役 지훈ジフン・付き合って2年

오늘의 장면 (今日のワンシーン)

지훈이 “그럼 무슨 뜻인데”라고 물었어요. 제가 지훈 할 테니, 오해를 풀려고 애쓰는 나의 대사를 읽어 볼까요?ジフンが「じゃあ、どういう意味なの」と聞きました。私がジフンをやるので、誤解を解こうとする「私」のセリフを読んでみましょうか？

전 화 마지막 질문에서 바로 이어져요. 변명처럼 빠르게 읽지 말고, 설명할 기회를 달라는 마음을 담아 주세요.

지훈

목표

오늘의 목표 (今日のゴール)

상대가 받아들인 뜻이 내 의도와 다르다고 바로잡고, 자기 이야기를 끝까지 들어 달라고 부탁해 봐요.相手が受け取った意味は自分の意図と違うと訂正し、話を最後まで聞いてほしいと頼んでみましょう。

그런 뜻으로 말한 거 아니야.そんな意味で言ったんじゃない。
내 말 끝까지 좀 들어 줄래?私の話を最後まで聞いてくれる？

오해하다 (誤解する)

상대의 말이나 행동을 실제 뜻과 다르게 받아들일 때 써요. ‘오해를 풀다’는 잘못 이해한 내용을 바로잡는다는 뜻이에요.相手の言葉や行動を、本当の意味とは違って受け取るときに使います。「오해를 풀다」は、間違って理解した内容を解くという意味です。

오해하다와 오해를 풀다를 한 쌍으로 익혀 주세요.
내 말을 오해한 것 같아.私の言葉を誤解したみたい。
그런 뜻이 아니라고 설명해서 오해를 풀었어.そんな意味ではないと説明して、誤解を解いた。
오해가 더 커지기 전에 말하자.誤解がもっと大きくなる前に話そう。

은 거와 ㄴ 거 붙이기 (은 거・ㄴ 거のつけ方)

받침이 있으면 ‘은 거’, 받침이 없으면 ‘ㄴ 거’를 붙여요. 어간이 ㄹ 받침이면 ㄹ을 빼고 ‘ㄴ 거’를 붙여요.パッチムがあれば「은 거」、なければ「ㄴ 거」をつけます。語幹がㄹパッチムなら、ㄹを取って「ㄴ 거」をつけます。

믿→은 거받침 있음パッチムあり믿다 → 믿은 거막다 → 막은 거
하→ㄴ 거받침 없음パッチムなし말하다 → 말한 거의심하다 → 의심한 거
들→ㄹ 탈락 + ㄴ 거ㄹ 받침ㄹを取る만들다 → 만든 거열다 → 연 거

은 거와 ㄴ 거 고르기 (은 거 と ㄴ 거)

여기서는 받침 유무에 따라 달라지는 두 갈래를 연습해요. ㄹ 받침은 다음 활동에서 따로 확인해요.ここではパッチムの有無で変わる2つの形を練習します。ㄹパッチムは次の活動で別に確認します。

そんな意味で言ったんじゃない。그런 뜻으로 말하은 거/말한 거 아니야.
わざと君の話を遮ったんじゃない。일부러 네 말을 막ㄴ 거/막은 거 아니야.
君の気持ちを無視したんじゃない。네 마음을 무시하은 거/무시한 거 아니야.
約束を忘れたんじゃない。약속을 잊은 거/잊ㄴ 거 아니야.

아 줄래와 어 줄래 붙이기 (아 줄래・어 줄래のつけ方)

마지막 모음이 ㅏ나 ㅗ면 ‘아 줄래’, 그 외에는 ‘어 줄래’를 붙여요. ‘하다’는 ‘해 줄래’가 되고, ‘듣다’는 ㄷ이 ㄹ로 바뀌어 ‘들어 줄래’가 돼요.最後の母音がㅏかㅗなら「아 줄래」、それ以外なら「어 줄래」をつけます。「하다」は「해 줄래」になり、「듣다」はㄷがㄹに変わって「들어 줄래」になります。

잡→아 줄래?ㅏ · ㅗ最後の母音がㅏかㅗ잡다 → 잡아 줄래?보다 → 봐 줄래?
읽→어 줄래?그 외それ以外の母音읽다 → 읽어 줄래?기다리다 → 기다려 줄래?
하→해 줄래?하다 → 해 줄래?하다は해 줄래?になる생각하다 → 생각해 줄래?설명하다 → 설명해 줄래?
듣→들어 줄래?듣다의 ㄷ → ㄹ듣다はㄷがㄹに変わる듣다 → 들어 줄래?

아 줄래와 어 줄래 고르기 (아 줄래 と 어 줄래)

‘하다’는 ‘해 줄래’, ‘듣다’는 ‘들어 줄래’로 만들고, 여기서는 나머지 동사의 두 갈래를 연습해요.「하다」は「해 줄래」、「듣다」は「들어 줄래」にして、ここでは残りの動詞の2つの形を練習します。

私の手を握ってくれる？내 손을 잡아 줄래?/잡어 줄래?
このメッセージを読んでくれる？이 메시지를 읽어 줄래?/읽아 줄래?
もう少し待ってくれる？조금만 더 기다리아 줄래?/기다려 줄래?
私の顔を見てくれる？내 얼굴을 보어 줄래?/봐 줄래?

원어민 팁 (ネイティブのひとこと)

‘그런 뜻으로 말한 거 아니야’는 오해를 바로잡지만, 감정이 뜨거울 때는 변명처럼 들릴 수도 있어요. 먼저 ‘그렇게 들렸다면 미안해’라고 영향에 공감한 뒤 설명하면 더 부드러워요.「그런 뜻으로 말한 거 아니야」は誤解を訂正しますが、感情が高ぶっているときは言い訳のように聞こえることもあります。先に「그렇게 들렸다면 미안해」と言って、相手への影響に共感してから説明すると、よりやわらかくなります。

두 문장 모두 같은 반말로 유지해요. 오른쪽은 잘못을 전부 인정하는 말이 아니라, 그렇게 들린 영향에 먼저 공감하는 말이에요.
의도를 바로잡을 때意図を訂正するとき그런 뜻으로 말한 거 아니야.そんな意味で言ったんじゃない。
상대의 감정부터 볼 때 相手の気持ちを先に受け止める
영향에 먼저 공감할 때伝わった影響に先に共感するとき그렇게 들렸다면 미안해.そう聞こえたなら、ごめん。

제6화 맛보기 (第6話・ちょっとだけ)
