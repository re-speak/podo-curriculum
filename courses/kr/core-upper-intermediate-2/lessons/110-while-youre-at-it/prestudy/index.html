パート 1

-는 김에

「〜するついでに」。もともとやろうとしていたことがあって、その機会に別のことも足す、という言い方です。

今日のパターン

意味・使い方~するついでにもともとやろうとしていたことが先にないといけません。

우체국에 가는 김에 커피 좀 사다 줘. 郵便局に行くついでにコーヒー買ってきて。
온 김에 밥이라도 먹고 가세요.来たついでにごはんでも食べていってください。
말 나온 김에 지금 정할까요?話が出たついでに今決めましょうか。

今やることなら 는、すでにやったなら (으)ㄴ

「김」の前には連体形が来ます。今やろうとしていることなら「는 김에」、すでにやったことなら「(으)ㄴ 김에」です。「말 나온 김에」はまるごと覚えておくと会議ですぐ使えます。

는 김에 今やろうとしていること 가다 → 가는 김에청소하다 → 청소하는 김에
(으)ㄴ 김에 すでにやったこと 오다 → 온 김에시작하다 → 시작한 김에
말 나온 김에 まるごと使うかたまり 말 나온 김에 → 지금 정할까요?온 김에 → 밥이라도 먹고 가세요

正しい言い方を選ぼう

日本語の時制を見てください。

郵便局に行くついでにコーヒー買ってきて。 우체국에 가는 김에/간 김에 커피 좀 사다 줘.
来たついでにごはんでも食べていってください。 오는 김에/온 김에 밥이라도 먹고 가세요.
話が出たついでに今決めましょうか。 말 나오는 김에/말 나온 김에 지금 정할까요?
掃除するついでに引き出しも整理しました。 청소하는 김에/청소한 김에 서랍도 정리했어요.

パート 2

-(으)ㄹ 겸

「〜も兼ねて」。目的が二つあって、一度に済ませるという言い方です。二つ並べて「〜(으)ㄹ 겸 〜(으)ㄹ 겸」と重ねて使います。

今日のパターン

意味・使い方~を兼ねて目的が二つあるとき、並べて置くことばです。

얼굴도 볼 겸 밥도 먹을 겸 만났어요. 顔も見るのと食事も兼ねて会いました。
운동도 할 겸 걸어서 왔어요.運動も兼ねて歩いて来ました。
바람도 쐴 겸 나왔어요.風に当たるのも兼ねて出てきました。

パッチムを見て ㄹ・을

パッチムがなければ「ㄹ 겸」、あれば「을 겸」です。目的が二つなら「ㄹ 겸 ㄹ 겸」と並べて置きます。前に「도」をつけると、どちらも目的だということがはっきりします。

ㄹ 겸 パッチムなし 보다 → 볼 겸하다 → 할 겸
을 겸 パッチムあり 먹다 → 먹을 겸배우다 → 배울 겸
겸 · 겸 目的を二つ並べて 볼 겸 → 먹을 겸 만났어요배울 겸 → 여행할 겸 왔어요

正しい言い方を選ぼう

日本語をよく見てください。

顔も見るのと食事も兼ねて会いました。 얼굴도 볼 겸/보는 김에 밥도 먹을 겸 만났어요.
郵便局に行くついでにコーヒー買ってきて。 우체국에 갈 겸/가는 김에 커피 좀 사다 줘.
運動も兼ねて歩いて来ました。 운동도 하을 겸/할 겸 걸어서 왔어요.
韓国語も習うのと兼ねて来ました。 한국말도 배울 겸/배우ㄹ 겸 왔어요.

パート 3

하는 김에 하나 더

この課でコースは終わりです。「김에」はもともとの用事にもう一つ足すこと、「겸」は目的を二つ並べること。どちらも一度で二つ済ませる、韓国語らしい言い方です。
