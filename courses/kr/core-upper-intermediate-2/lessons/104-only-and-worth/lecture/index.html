명사면 일, 동사면 ㄹ · 을 (名詞なら 일、動詞なら ㄹ・을)

명사에는 ‘일 뿐이다’를 붙여요. 이미 끝난 일이면 ‘았/었을 뿐이다’가 되고요 — ‘텐데’와 같은 길이에요.名詞には「일 뿐이다」をつけます。すでに終わったことなら「았/었을 뿐이다」になります — 「텐데」と同じ道です。

ㄹ · 을 뿐이다 동사 · 형용사動詞・形容詞 피곤하다 → 피곤할 뿐이에요좋다 → 좋을 뿐이에요
았/었을 뿐이다 이미 끝난 일すでに終わったこと 물어보다 → 물어봤을 뿐이에요돕다 → 도왔을 뿐이에요

받침을 보고 ㄹ · 을 (パッチムを見て ㄹ・을)

붙이는 법은 ‘만큼’과 같지만 하는 일이 달라요 — ‘만큼’은 정도, ‘만하다’는 가치예요. ‘그럴 만하다’는 통째로 외워 두면 공감할 때 바로 쓸 수 있어요.つけ方は「만큼」と同じですが働きが違います — 「만큼」は程度、「만하다」は価値です。「그럴 만하다」はまるごと覚えておくと、共感するときにすぐ使えます。

ㄹ 만하다 받침 없음パッチムなし 보다 → 볼 만해요가다 → 가 볼 만해요
을 만하다 받침 있음パッチムあり 읽다 → 읽을 만해요먹다 → 먹을 만해요
그럴 만하다 공감할 때共感するとき 그럴 만해요 → 이해가 돼요그럴 만하네요 → 그럴 수 있죠
