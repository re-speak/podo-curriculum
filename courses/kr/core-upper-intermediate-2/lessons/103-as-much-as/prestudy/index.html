관형형으로 뜻이 갈려요 (連体形で意味が分かれます)

‘만큼’ 앞에 뭐가 오느냐로 뜻이 달라져요. 과거는 ‘ㄴ 만큼’, 현재는 ‘는 만큼’ — 둘 다 비례예요. ‘ㄹ 만큼’은 비유고요. 관형형 만드는 법은 그대로예요.「만큼」の前に何が来るかで意味が変わります。過去は「ㄴ 만큼」、現在は「는 만큼」 — どちらも比例です。「ㄹ 만큼」はたとえです。連体形の作り方はこれまでどおりです。

ㄴ 만큼 이미 한 일すでにしたこと 노력하다 → 노력한 만큼내다 → 낸 만큼
는 만큼 지금 하는 일今していること 알다 → 아는 만큼일하다 → 일하는 만큼
ㄹ 만큼 비유たとえ 나다 → 눈물이 날 만큼죽다 → 죽을 만큼

원어민 팁 (ネイティブのひとこと)

‘-는 대로’에는 뜻이 하나 더 있어요. ‘도착하는 대로 연락할게요’처럼 쓰면 ‘도착하자마자’가 돼요. ‘-자마자’와 뜻이 거의 같은데, ‘-는 대로’ 쪽이 약속하는 자리에서 더 자주 들려요.「-는 대로」にはもうひとつ意味があります。「도착하는 대로 연락할게요」のように使うと「着いたらすぐ」になります。「-자마자」とほぼ同じ意味ですが、「-는 대로」のほうが約束する場面でよく聞きます。

위아래로 한 줄씩 읽어 주세요. 뜻은 같고, 아래쪽이 조금 더 어른스럽게 들려요.
着いたらすぐ連絡します。 도착하자마자 연락할게요. 도착하는 대로 연락할게요.
終わったらすぐ行きます。 끝나자마자 갈게요. 끝나는 대로 갈게요.
