パート 1

-(으)ㄹ 수밖에 없다

「〜するしかありません」。ほかに選ぶ道がなくて、そうするよりない、というときに使います。

今日のパターン

意味・使い方~するしかない「その方法のほかにはない」ということばです。

지금은 기다릴 수밖에 없어요. 今は待つしかありません。
차가 끊겨서 걸을 수밖에 없었어요.終電がなくて歩くしかありませんでした。
비가 와서 취소할 수밖에 없었어요.雨が降って中止するしかありませんでした。

パッチムを見て ㄹ・을

「-(으)ㄹ 수 있다」を作るときとまったく同じ道です。「어쩔 수 없이」はまるごと覚えておくと、前にすぐつけられます。

ㄹ 수밖에 없다 パッチムなし 기다리다 → 기다릴 수밖에 없어요취소하다 → 취소할 수밖에 없어요
을 수밖에 없다 パッチムあり 걷다 → 걸을 수밖에 없어요믿다 → 믿을 수밖에 없어요
어쩔 수 없이 前に置くことば 어쩔 수 없이 → 택시를 탔어요방법이 없어서 → 기다렸어요

正しい言い方を選ぼう

パッチムを見て「ㄹ」か「을」かを選んでください。「걷다」はパッチムが変わる語です。

今は待つしかありません。 지금은 기다릴 수밖에 없어요/기다리을 수밖에 없어요.
終電がなくて歩くしかありませんでした。 차가 끊겨서 걷을 수밖에 없었어요/걸을 수밖에 없었어요.
雨が降って中止するしかありませんでした。 비가 와서 취소할 수밖에 없었어요/취소하을 수밖에 없었어요.
席がなくて立って行くしかありませんでした。 표가 없어서 서서 갈 수밖에 없었어요/서서 가을 수밖에 없었어요.

文を組み立てよう

今度は単語を順番に並べて、文を完成させてみましょうか。完成した文は声に出して言ってみましょう。

結果が出るまではただ待つしかありません。
그냥 결과가 기다릴 수밖에 없어요 나올 때까지는
昨日は終電がなくて家まで歩くしかありませんでした。
걸을 수밖에 없었어요 차가 끊겨서 어제는 집까지
雨が降って約束を結局中止するしかありませんでした。
약속을 취소할 수밖에 없었어요 비가 와서 결국
席がなくて仕方なく最後まで立って行くしかありませんでした。
끝까지 표가 없어서 서서 갈 수밖에 없었어요 어쩔 수 없이
パート 2

N밖에 없다

「〜しかありません」。名詞につけて、それ一つきりだと言います。「만」と似ていますが、後ろが必ず否定になります。

今日のパターン

意味・使い方~しかない名詞に直接つけて「それ一つきり」と言います。

냉장고에 물밖에 없어요. 冷蔵庫に水しかありません。
지금 천 원밖에 없어요.今千ウォンしかありません。
저는 한국말밖에 못해요.私は韓国語しかできません。

밖에 の後ろには必ず否定

名詞に直接つけます。ただし後ろは必ず否定でなければなりません — 「없다」「못」「안」のどれかが必ず来ます。「만」と並べて見ると確かです。「만」は肯定、「밖에」は否定です。

밖에 + 없다 それだけ 물 → 물밖에 없어요천 원 → 천 원밖에 없어요
밖에 + 못 · 안 それしかできない 한국말 → 한국말밖에 못해요세 시간 → 세 시간밖에 못 잤어요
만 + 긍정 逆のほう 물만 → 있어요물밖에 → 없어요

正しい言い方を選ぼう

日本語をよく見てください。

冷蔵庫に水しかありません。 냉장고에 물밖에 없어요/물만 없어요.
冷蔵庫に水だけあります。 냉장고에 물밖에 있어요/물만 있어요.
今、千ウォンしかありません。 지금 천 원밖에 없어요/천 원만 없어요.
昨日は三時間しか寝られませんでした。 어제는 세 시간밖에 못 잤어요/세 시간밖에 잤어요.

文を組み立てよう

今度は単語を順番に並べて、文を完成させてみましょうか。完成した文は声に出して言ってみましょう。

財布に今、現金が千ウォンしかありません。
천 원밖에 없어요 지금 지갑에 현금이
私は外国語の中でまだ韓国語しかできません。
외국어 중에 한국말밖에 못해요 저는 아직
昨日は忙しくて三時間しか寝られませんでした。
세 시간밖에 어제는 못 잤어요 바빠서
パート 3

그 방법밖에 없음

動詞のあとなら「〜するしかない」、名詞のあとなら「〜しかない」。どちらも後ろが否定になるところは同じです。
