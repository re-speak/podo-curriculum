받침을 보고 ㄹ · 을 (パッチムを見て ㄹ・을)

‘-(으)ㄹ 수 있다’를 만들 때와 똑같은 길이에요. ‘어쩔 수 없이’는 통째로 외워 두면 앞에 바로 붙일 수 있어요.「-(으)ㄹ 수 있다」を作るときとまったく同じ道です。「어쩔 수 없이」はまるごと覚えておくと、前にすぐつけられます。

ㄹ 수밖에 없다 받침 없음パッチムなし 기다리다 → 기다릴 수밖에 없어요취소하다 → 취소할 수밖에 없어요
을 수밖에 없다 받침 있음パッチムあり 걷다 → 걸을 수밖에 없어요믿다 → 믿을 수밖에 없어요

밖에 뒤에는 반드시 부정 (밖에 の後ろには必ず否定)

명사에 바로 붙여요. 대신 뒤가 반드시 부정이어야 해요 — ‘없다’, ‘못’, ‘안’ 중 하나가 꼭 와요. ‘만’과 나란히 놓고 보면 확실해요. ‘만’은 긍정이고, ‘밖에’는 부정이에요.名詞に直接つけます。ただし後ろは必ず否定でなければなりません — 「없다」「못」「안」のどれかが必ず来ます。「만」と並べて見ると確かです。「만」は肯定、「밖에」は否定です。

밖에 + 없다 그것뿐それだけ 물 → 물밖에 없어요천 원 → 천 원밖에 없어요
밖에 + 못 · 안 그것밖에 못 함それしかできない 한국말 → 한국말밖에 못해요세 시간 → 세 시간밖에 못 잤어요
만 + 긍정 반대쪽逆のほう 물만 → 있어요물밖에 → 없어요

원어민 팁 (ネイティブのひとこと)

‘밖에 없다’ 앞에 한 마디만 붙이면 답답한 마음이 훨씬 잘 들려요. 어쩔 수 없을 때는 ‘어쩔 수 없이’, 방법을 다 찾아본 뒤라면 ‘방법이 없어서’를 앞에 놓아 보세요.「밖에 없다」の前にひとこと足すだけで、もどかしい気持ちがずっとよく伝わります。どうしようもないときは「어쩔 수 없이」、方法を探しつくしたあとなら「방법이 없어서」を前に置いてみてください。

위아래로 한 줄씩 읽어 주세요. 아래쪽이 실제 대화에서 훨씬 자주 들려요.
歩くしかありませんでした。 걸을 수밖에 없었어요. 어쩔 수 없이 걸을 수밖에 없었어요.
待つしかありません。 기다릴 수밖에 없어요. 방법이 없어서 기다릴 수밖에 없어요.
