척 앞에는 관형사형 (척 の前には連体形)

‘척’ 앞에는 관형사형이 그대로 와요. 이미 끝난 일이면 동사도 ‘(으)ㄴ 척하다’가 돼요 — ‘못 들은 척’.「척」の前には連体形がそのまま来ます。すでに終わったことなら動詞も「(으)ㄴ 척하다」になります — 「못 들은 척」。

는 척하다 동사動詞 모르다 → 모르는 척해요알다 → 아는 척해요
(으)ㄴ 척하다 형용사 · 끝난 일形容詞・終わったこと 바쁘다 → 바쁜 척해요못 듣다 → 못 들은 척해요
인 척하다 명사名詞 학생 → 학생인 척해요전문가 → 전문가인 척해요

원어민 팁 (ネイティブのひとこと)

‘척하다’는 ‘하다’를 떼고 명사처럼 쓰는 일이 아주 많아요. ‘아는 척’, ‘못 들은 척’ 하고 짧게 끊으면 훨씬 입말답고, 뒤에 다른 동사를 바로 이을 수 있어요.「척하다」は「하다」を落として名詞のように使うことがとても多いです。「아는 척」「못 들은 척」と短く切ると、ずっと話しことばらしくなり、後ろに別の動詞をすぐつなげられます。

위아래로 한 줄씩 읽어 주세요. 아래쪽이 실제 대화에서 훨씬 자주 들려요.
知ったかぶりをしないでください。 아는 척하지 마세요. 아는 척 좀 하지 마.
聞こえないふりをして行きました。 못 들은 척하고 갔어요. 못 들은 척 그냥 갔어요.
