받침을 보고 ㄹ · 을 (パッチムを見て ㄹ・을)

친구 사이에서는 ‘그랬다’를 떼고 ‘가져올걸’ 하고 짧게 끝내요. 이때는 붙여 쓰고, 끝을 내려 읽어야 후회로 들려요.友だち同士では「그랬다」を落として「가져올걸」と短く終わらせます。このときはくっつけて書き、語尾を下げて読むと後悔に聞こえます。

ㄹ 걸 그랬다 받침 없음パッチムなし 가져오다 → 가져올 걸 그랬어요타다 → 탈 걸 그랬어요
을 걸 그랬다 받침 있음パッチムあり 읽다 → 읽을 걸 그랬어요먹다 → 먹을 걸 그랬어요
ㄹ걸 반말 · 혼잣말タメ口・独り言 가져올 걸 그랬어 → 가져올걸탈 걸 그랬어 → 탈걸

았 · 었 · 했어야 했다 (았・었・했어야 했다)

고르는 법은 과거형을 만들 때와 똑같아요. 하지 말았어야 할 일은 ‘-지 말았어야 했다’로 뒤집어요.選び方は過去形を作るときとまったく同じです。してはいけなかったことは「-지 말았어야 했다」でひっくり返します。

았어야 했다 ㅏ · ㅗ 모음ㅏ・ㅗ の母音 자다 → 잤어야 했어요챙기다 → 챙겼어야 했어요
었어야 했다 그 밖의 모음それ以外の母音 먹다 → 먹었어야 했어요듣다 → 들었어야 했어요
지 말았어야 했다 안 했어야 할 일すべきでなかったこと 말하다 → 말하지 말았어야 했어요가다 → 가지 말았어야 했어요

원어민 팁 (ネイティブのひとこと)

후회하는 말은 끝까지 다 말하지 않을 때가 더 자연스러워요. ‘했어야 했어요’를 ‘했어야 했는데’로 바꿔 말끝을 흐리면, 아쉬움이 그대로 남아 있는 느낌이 들어요. 앞에 ‘그러게요’를 붙이면 상대 말에 수긍하는 뜻까지 얹혀요.後悔のことばは最後まで言い切らないほうが自然なことがあります。「했어야 했어요」を「했어야 했는데」に変えて言いさすと、残念さがそのまま残っている感じになります。前に「그러게요」をつけると、相手のことばに同意する意味まで乗ります。
