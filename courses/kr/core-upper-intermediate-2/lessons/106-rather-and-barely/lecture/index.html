동사면 는, 형용사면 (으)ㄴ (動詞なら 는、形容詞なら (으)ㄴ)

‘편’ 앞에는 관형사형이 와요. 동사면 ‘는 편이다’, 형용사면 ‘(으)ㄴ 편이다’예요. 부정은 앞에 ‘안’을 놓고 뒤는 그대로 ‘는 편이다’로 둬요.「편」の前には連体形が来ます。動詞なら「는 편이다」、形容詞なら「(으)ㄴ 편이다」です。否定は前に「안」を置いて、後ろはそのまま「는 편이다」にします。

는 편이다 동사動詞 먹다 → 먹는 편이에요자다 → 자는 편이에요
(으)ㄴ 편이다 형용사形容詞 크다 → 큰 편이에요많다 → 많은 편이에요
안 ~는 편이다 부정否定 안 먹다 → 안 먹는 편이에요안 자다 → 안 자는 편이에요

원어민 팁 (ネイティブのひとこと)

‘것 같다’와 오늘 ‘편이다’는 둘 다 단정을 피해요. 다른 건 무엇을 피하느냐예요 — ‘것 같다’는 사실이 맞는지 자신이 없을 때, ‘편이다’는 사실은 아는데 딱 잘라 말하기가 부담스러울 때예요. 자기 이야기에는 ‘편이다’가 훨씬 자연스러워요.「것 같다」と今日の「편이다」はどちらも言い切りを避けます。違うのは何を避けるかで、「것 같다」は事実かどうか自信がないとき、「편이다」は事実は分かっているけれど言い切るのが重いときです。自分の話には「편이다」のほうがずっと自然です。

위아래로 한 줄씩 읽어 주세요. 자기 취향을 말할 때는 아래쪽이 훨씬 자연스러워요.
私は辛いものが好きです。 매운 거 좋아해요. 매운 거 좋아하는 편이에요.
