パート 1

N 덕분에

「〜のおかげで」。よい結果の原因を相手に返します。때문에が中立か悪いほうなら、덕분에は感謝そのものです。

今日のパターン

意味・使い方~のおかげでよい結果の手柄を相手に返します。

선생님 덕분에 합격했어요. 先生のおかげで合格しました。
도와준 덕분에 빨리 끝났어요.手伝ってくれたおかげで早く終わりました。
다 여러분 덕분이에요.全部みなさんのおかげです。

名詞ならそのまま、動詞なら過去の連体形

名詞のうしろには何もつけず「덕분에」だけ置きます。動詞なら「(으)ㄴ」が前に来ます — もうしてくれたことだからです。文の終わりでは「덕분이에요」で終えます。

N 덕분에 名詞 — そのままつく 선생님 → 선생님 덕분에친구 → 친구 덕분에
(으)ㄴ 덕분에 動詞 — 過去の連体形 도와주다 → 도와준 덕분에가르치다 → 가르친 덕분에
덕분이에요 文の終わりで 여러분 → 여러분 덕분이에요선생님 → 선생님 덕분이에요

正しい言い方を選ぼう

ありがたいことなら「덕분에」、よくないことなら「때문에」です。

先生のおかげで合格しました。 선생님 덕분에/때문에 합격했어요.
雨のせいで行けませんでした。 비 덕분에/때문에 못 갔어요.
手伝ってくれたおかげで早く終わりました。 도와 주는 덕분에/준 덕분에 빨리 끝났어요.
友だちのおかげで元気に過ごしました。 친구 덕분에/덕분으로 잘 지냈어요.

文を組み立てよう

今度は単語を順番に並べて、文を完成させてみましょうか。完成した文は声に出して言ってみましょう。

先生のおかげで試験に合格しました。
시험에 선생님 합격했어요 덕분에
友だちのおかげで韓国で元気に過ごしました。
잘 지냈어요 덕분에 친구 한국에서
手伝ってくれたおかげで仕事が早く終わりました。
일이 끝났어요 도와준 덕분에 빨리
今日うまくいったのは全部みなさんのおかげです。
다 오늘 잘된 건 여러분 덕분이에요
パート 2

-아/어서 그런지

「〜だからか」。理由をひとつ挙げますが、断言はしません。-것 같다と同じで、まちがっている余地をわざと残す言い方です。

今日のパターン

意味・使い方~だからか理由を1つ挙げはしますが断言はしません。

피곤해서 그런지 계속 졸려요. 疲れているからかずっと眠いです。
날씨가 추워서 그런지 사람이 없어요.天気が寒いからか人がいません。
사람이 많아서 그런지 좀 시끄러워요.人が多いからかちょっとうるさいです。

아・어・해 — まま

「아/어서」のうしろに「그런지」をつけるだけです。「아/어」の選び方は何も変わりません。そして「아/어서」の前に「았/었」をつけないのもままです。

아서 그런지 ㅏ・ㅗ の母音 많다 → 많아서 그런지자다 → 자서 그런지
어서 그런지 それ以外の母音 춥다 → 추워서 그런지늦다 → 늦어서 그런지
해서 그런지 하다動詞・形容詞 피곤하다 → 피곤해서 그런지긴장하다 → 긴장해서 그런지

正しい言い方を選ぼう

前のことばの母音を見て「아/어/해」の中から選んでください。前に「았/었」はつきません。

疲れているからかずっと眠いです。 피곤해서 그런지/피곤하서 그런지 계속 졸려요.
天気が寒いからか人がいません。 날씨가 춥어서 그런지/추워서 그런지 사람이 없어요.
人が多いからかちょっとうるさいです。 사람이 많어서 그런지/많아서 그런지 좀 시끄러워요.
遅く寝たからか頭が痛いです。 늦게 잤어서 그런지/자서 그런지 머리가 아파요.

文を組み立てよう

今度は単語を順番に並べて、文を完成させてみましょうか。完成した文は声に出して言ってみましょう。

疲れているからか今日はずっと眠いです。
계속 피곤해서 그런지 졸려요 오늘은
天気が寒いからか今日は人がいません。
사람이 없어요 추워서 그런지 날씨가 오늘은
人が多いからかここはちょっとうるさいです。
많아서 그런지 좀 시끄러워요 사람이 여기는
遅く寝たからか今日は頭が痛いです。
오늘은 늦게 자서 그런지 머리가 아파요
パート 3

고맙다고, 아마 그래서

2つがそろいました。よい結果は-덕분에で相手に返し、はっきりしない理由は-아/어서 그런지で一歩ひく。どちらも相手との距離をちょうどよくする道具です。
