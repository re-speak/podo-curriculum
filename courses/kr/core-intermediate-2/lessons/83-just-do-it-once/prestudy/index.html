ゴール

今日のゴール

「기」を今日も使います。それさえすれば必ずそうなる、それだけでも十分だ、という言い方です。

もう知っている単語

漢字語は中級でもっと力を発揮します。音が日本語と似ているので、はじめて見る単語も見当がつきます。

無條件→무조건
氣分→기분
音盤→음반
パート 1

-기만 하면

「〜しさえすれば」。それひとつだけで結果が決まります。すすめるとき、韓国語でいちばん強い言い方のひとつです。

今日のパターン

意味・使い方~しさえすれば기に만 하면をつけたものです。

한 번 보기만 하면 무조건 빠져요. 一度見さえすれば絶対にはまります。
가기만 하면 바로 알 수 있어요.行きさえすればすぐわかります。
이거 한 번 먹기만 하면 계속 생각나요.これを一度食べさえすればずっと思い出します。

기 に 만 하면 をつけます

新しいルールではありません。「기」のうしろに「만 하면」をつけるだけです。パッチムも見ないし、前に連体形も来ません。「다」を取って「기만 하면」です。

기만 하면 パッチムなし 보다 → 보기만 하면가다 → 가기만 하면
기만 하면 パッチムあり 먹다 → 먹기만 하면듣다 → 듣기만 하면

正しい言い方を選ぼう

「기」の前には連体形は来ません。「다」を取ってすぐ「기만 하면」です。

一度見さえすれば絶対にはまります。 한 번 보는 기만 하면/보기만 하면 무조건 빠져요.
行きさえすればすぐわかります。 갈기만 하면/가기만 하면 바로 알 수 있어요.
これを一度食べさえすればずっと思い出します。 이거 한 번 먹기만 하면/먹은기만 하면 계속 생각나요.
一度聞きさえすればすぐ覚えられます。 한 번 들기만 하면/듣기만 하면 바로 외워져요.

文を組み立てよう

今度は単語を順番に並べて、文を完成させてみましょうか。完成した文は声に出して言ってみましょう。

一度見さえすれば絶対にはまります。
무조건 한 번 빠져요 보기만 하면
一度行きさえすればすぐわかります。
알 수 있어요 가기만 하면 한 번 바로
これを一度食べさえすればずっと思い出します。
한 번 계속 생각나요 이거 먹기만 하면
一度聞きさえすればすぐ覚えられます。
바로 한 번 듣기만 하면 외워져요
パート 2

-기만 해도

「〜するだけでも」。今度は「それだけで十分」です。하면が条件なら、해도は最低限これだけで、という言い方です。

今日のパターン

意味・使い方~するだけでも하면が「そうすればこうなる」という条件なら、해도は「それだけでも十分だ」です。

듣기만 해도 기분이 좋아져요. 聞くだけでも気分がよくなります。
보기만 해도 배가 불러요.見るだけでもおなかがいっぱいになります。
생각하기만 해도 웃음이 나요.考えるだけでも笑いが出ます。

하면 は条件、해도 はそれで十分

つけ方はパート1と同じです。最後だけちがいます。「하면」は「そうすればこうなる」と条件をつけ、「해도」は「それだけでもいい」と敷居を下げます。

기만 하면 パート1・条件 듣다 → 듣기만 하면 외워져요가다 → 가기만 하면 알아요
기만 해도 パート2・それで十分 듣다 → 듣기만 해도 좋아져요보다 → 보기만 해도 배불러요

正しい言い方を選ぼう

「기」の前には連体形は来ませんし、「해도」のところに「했어도」は来ません。

聞くだけでも気分がよくなります。 듣기만 해도/듣는 기만 해도 기분이 좋아져요.
見るだけでもおなかがいっぱいになります。 보기만 했어도/보기만 해도 배가 불러요.
考えるだけでも笑いが出ます。 생각한기만 해도/생각하기만 해도 웃음이 나요.
そばにいるだけでも力が出ます。 옆에 있는기만 해도/있기만 해도 힘이 나요.

文を組み立てよう

今度は単語を順番に並べて、文を完成させてみましょうか。完成した文は声に出して言ってみましょう。

この歌は聞くだけでも気分がよくなります。
기분이 이 노래는 좋아져요 듣기만 해도
この写真は見るだけでも本当におなかがいっぱいになります。
배가 불러요 보기만 해도 이 사진은 진짜
そのときを考えるだけでも笑いが出ます。
생각하기만 해도 나요 그때를 웃음이
友だちがそばにいるだけでも力が出ます。
있기만 해도 친구가 옆에 힘이 나요
パート 3

그것만 하면

2つがそろいました。条件を強く言うなら-기만 하면、それだけで十分と言うなら-기만 해도。どちらもすすめるときの言い方です。

会話を読もう

ハナとハルカが音楽の話をします。

ハナ
하루카 씨, 요즘 무슨 노래 들어요?ハルカさん、最近どんな歌を聞いていますか？
ハルカ
이 밴드요. 한 번 듣기만 하면 무조건 빠져요.このバンドです。一度聞きさえすれば絶対にはまります。
ハナ
그래요? 어떤 느낌인데요?そうですか？どんな感じなんですか？
ハルカ
가사가 좋아요. 듣기만 해도 기분이 좋아져요.歌詞がいいです。聞くだけでも気分がよくなります。
ハナ
그럼 저도 한번 들어 볼게요.では私も一度聞いてみます。
ハルカ
네! 이거 한 곡만 듣기만 하면 바로 아실 거예요.はい！この一曲だけ聞きさえすればすぐわかると思います。
