오늘의 목표 (今日のゴール)

앞에서 만든 ‘기’를 오늘도 써요. 그것만 하면 반드시 그렇게 된다, 그것만으로도 충분하다는 말이에요.「기」を今日も使います。それさえすれば必ずそうなる、それだけでも十分だ、という言い方です。

가기만 하면 바로 알 수 있어요.行きさえすればすぐわかります

기에 만 하면을 붙여요 ( 기 に 만 하면 をつけます)

새 규칙이 아니에요. 앞에서 만든 ‘기’ 뒤에 ‘만 하면’을 붙이면 끝이에요. 받침도 안 보고, 앞에 관형사형도 안 와요. ‘다’만 떼고 ‘기만 하면’이에요.新しいルールではありません。「기」のうしろに「만 하면」をつけるだけです。パッチムも見ないし、前に連体形も来ません。「다」を取って「기만 하면」です。

기만 하면 받침 없음パッチムなし 보다 → 보기만 하면가다 → 가기만 하면
기만 하면 받침 있음パッチムあり 먹다 → 먹기만 하면듣다 → 듣기만 하면

알맞은 말 고르기 (正しい言い方を選ぼう)

‘기’ 앞에는 관형사형이 안 와요. ‘다’만 떼고 바로 ‘기만 하면’이에요.「기」の前には連体形は来ません。「다」を取ってすぐ「기만 하면」です。

一度見さえすれば絶対にはまります。 한 번 보는 기만 하면/보기만 하면 무조건 빠져요.

パート 2

-기만 해도

「〜するだけでも」。今度は「それだけで十分」です。하면が条件なら、해도は最低限これだけで、という言い方です。

오늘의 패턴 (今日のパターン)

뜻과 쓰임 意味・使い方~するだけでも스루다케데모하면이 '그러면 이렇게 된다'는 조건이라면, 해도는 '그것만으로도 충분하다'예요.하면が「そうすればこうなる」という条件なら、해도は「それだけでも十分だ」です。

하면은 조건, 해도는 그것으로 충분 (하면 は条件、해도 はそれで十分)

붙는 방법은 파트1하고 똑같아요. 마지막만 달라요. ‘하면’은 '그러면 이렇게 된다'고 조건을 걸고, ‘해도’는 '그것만으로도 된다'고 문턱을 낮춰요.つけ方はパート1と同じです。最後だけちがいます。「하면」は「そうすればこうなる」と条件をつけ、「해도」は「それだけでもいい」と敷居を下げます。

기만 하면 파트 1 · 조건パート1・条件 듣다 → 듣기만 하면 외워져요가다 → 가기만 하면 알아요
기만 해도 파트 2 · 그것으로 충분パート2・それで十分 듣다 → 듣기만 해도 좋아져요보다 → 보기만 해도 배불러요

알맞은 말 고르기 (正しい言い方を選ぼう)

‘기’ 앞에는 관형사형이 안 오고, ‘해도’ 자리에 ‘했어도’가 오지 않아요.「기」の前には連体形は来ませんし、「해도」のところに「했어도」は来ません。

聞くだけでも気分がよくなります。 듣기만 해도/듣는 기만 해도 기분이 좋아져요.
見るだけでもおなかがいっぱいになります。 보기만 했어도/보기만 해도 배가 불러요.
考えるだけでも笑いが出ます。 생각한기만 해도/생각하기만 해도 웃음이 나요.
そばにいるだけでも力が出ます。 옆에 있는기만 해도/있기만 해도 힘이 나요.
