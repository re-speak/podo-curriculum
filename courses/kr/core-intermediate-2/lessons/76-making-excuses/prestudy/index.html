ゴール

今日のゴール

言い訳です。自分がよそ見をしてできなかったのか、どうしようもないことが起きてできなかったのか、分けて話します。

もう知っている単語

漢字語は中級でもっと力を発揮します。音が日本語と似ているので、はじめて見る単語も見当がつきます。

宿題→숙제
事故→사고
返納→반납
パート 1

-느라고

「〜していて」。自分がそれをやっていたせいで、別のことができませんでした。うしろには必ずよくない結果が来ます。

今日のパターン

意味・使い方~していて自分がそれをやっていて別のことができなかった、という意味です。

게임을 하느라고 숙제를 못 했어요. ゲームをしていて宿題ができませんでした。
밥을 먹느라고 전화를 못 받았어요.ごはんを食べていて電話に出られませんでした。
친구랑 노느라고 시간을 다 썼어요.友だちと遊んでいて時間を全部使いました。

パッチムも時制も見ません、ㄹ だけ別

動詞から「다」を取って「느라고」をつけるだけです。パッチムがあってもなくても同じで、前に「았/었」をつけません。1つだけちがいます — ㄹパッチムはㄹが落ちます。

느라고 パッチムなし 하다 → 하느라고자다 → 자느라고
느라고 パッチムあり 먹다 → 먹느라고찾다 → 찾느라고
느라고 ㄹパッチム — ㄹ が落ちる 놀다 → 노느라고만들다 → 만드느라고

正しい言い方を選ぼう

「느라고」の前には「았/었」はつきません。ㄹパッチムはㄹが落ちることだけ別に覚えてください。

ゲームをしていて宿題ができませんでした。 게임을 했느라고/하느라고 숙제를 못 했어요.
ごはんを食べていて電話に出られませんでした。 밥을 먹었느라고/먹느라고 전화를 못 받았어요.
友だちと遊んでいて時間を全部使いました。 친구랑 놀느라고/노느라고 시간을 다 썼어요.
仕事をしていて昼ごはんも食べられませんでした。 일하느라고/일하는라고 점심도 못 먹었어요.

文を組み立てよう

ごはんを食べていて電話に出られませんでした。
못 받았어요 먹느라고 밥을 전화를
友だちと遊んでいて時間を全部使いました。

점심도 일하느라고 오늘 못 먹었어요
パート 2

-는 바람에

「〜したせいで」。今度は自分のせいではありません。思いがけないことが起きて、そのせいでうまくいかなかったときです。

今日のパターン

意味・使い方~したせいで今度は自分のせいではありません。

비가 오는 바람에 늦었어요. 雨が降ったせいで遅れました。
차가 막히는 바람에 못 갔어요.道が混んだせいで行けませんでした。
갑자기 배탈이 나는 바람에 집에 왔어요.急におなかを壊したせいで家に帰りました。

だれがしたことかで分かれます

本当のちがいは前に来るのがだれかです。自分がしたことなら「느라고」、自分以外が起こしたことなら「는 바람에」です。

느라고 パート1・自分がしたこと 게임을 하다 → 게임을 하느라고일하다 → 일하느라고
는 바람에 パート2・自分以外のこと 비가 오다 → 비가 오는 바람에차가 막히다 → 차가 막히는 바람에

正しい言い方を選ぼう

前に来るのが自分がしたことか、自分以外が起こしたことかを見てください。雨や車は自分がさせたものではありません。

雨が降ったせいで遅れました。 비가 오는 바람에/오느라고 늦었어요.
道が混んだせいで行けませんでした。 차가 막히는 바람에/막히느라고 못 갔어요.
急におなかを壊したせいで家に帰りました。 갑자기 배탈이 나는 바람에/나느라고 집에 왔어요.
雪が降ったせいで道が全部混みました。 눈이 오다 바람에/오는 바람에 길이 다 막혔어요.

文を組み立てよう

今度は単語を順番に並べて、文を完成させてみましょうか。完成した文は声に出して言ってみましょう。

雨が降ったせいで三十分遅れました。
삼십 분 비가 늦었어요 오는 바람에
道が混んだせいで約束に行けませんでした。
못 갔어요 막히는 바람에 차가 약속에
急におなかを壊したせいで家に帰りました。
배탈이 집에 왔어요 갑자기 나는 바람에
雪が降ったせいで道が全部混みました。
길이 눈이 오는 바람에 다 막혔어요
パート 3

핑계 대기

2つがそろいました。自分がよそ見をしていたなら-느라고、思いがけないことが起きたなら-는 바람에。どちらもうしろはよくない結果で、命令や勧誘は続けられません。

会話を読もう

ハナとハルカが昨日の約束の話をします。

ハナ
하루카 씨, 어제 왜 안 왔어요?ハルカさん、昨日なぜ来なかったんですか？
ハルカ
죄송해요. 차가 막히는 바람에 못 갔어요.すみません。道が混んだせいで行けませんでした。
ハナ
연락이라도 주시지 그랬어요.連絡だけでもくださればよかったのに。
ハルカ
그게, 운전하느라고 전화를 못 받았어요.それが、運転していて電話に出られませんでした。
ハナ
아, 그럼 어쩔 수 없었네요.あ、ではどうしようもなかったですね。
ハルカ
네. 하필 그날 눈까지 오는 바람에 두 시간 걸렸어요.はい。よりによってその日は雪まで降ったせいで二時間かかりました。
