パッチムを見て 으려면・려면

「(으)ㄹ래요」、「(으)라고」と分かれ方が同じです。パッチムがあれば「으려면」、なければ「려면」、ㄹパッチムは「으」を取りません。

으려면 パッチムあり 먹다 → 먹으려면읽다 → 읽으려면
려면 パッチムなし 잘하다 → 잘하려면사다 → 사려면
려면 ㄹパッチム — 으なし 살다 → 살려면만들다 → 만들려면

パート 2

-아/어야

「〜してこそ」「〜しないと」。これがそろわないと次が起きません。必ず必要な前提を言う形です。

今日のパターン

意味・使い方~してこそ・~しないとこれがあってはじめて次ができるという意味です。

표가 있어야 들어갈 수 있어요. チケットがあってこそ入れます。
예약을 해야 자리가 있어요.予約をしてこそ席があります。
돈을 받아야 보내 드려요.お金を受け取ってこそお送りします。

아・어・해 — またあのルール

「아/어야」そのままです。動詞を「아/어요」に変えて、「요」のところに「야」を入れるだけです。新しく覚えることはありません。

아야 ㅏ・ㅗ の母音 받다 → 받아야사다 → 사야
어야 それ以外の母音 있다 → 있어야먹다 → 먹어야
해야 하다動詞 예약하다 → 예약해야신청하다 → 신청해야

正しい言い方を選ぼう

前の動詞の母音を見て「아/어/해」の中から正しいほうをタップしてください。

チケットがあってこそ入れます。 표가 있아야/있어야 들어갈 수 있어요.
予約をしてこそ席があります。 예약을 하야/해야 자리가 있어요.
お金を受け取ってこそお送りします。 돈을 받어야/받아야 보내 드려요.
これを食べてこそ早く治ります。 이걸 먹어야/먹아야 빨리 나아요.
