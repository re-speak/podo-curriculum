ゴール

今日のゴール

自分が直接見て、それでそうした、という言い方です。理由が複数あるとき1つだけ挙げる方法も一緒に習います。

もう知っている単語

漢字語は中級でもっと力を発揮します。音が日本語と似ているので、はじめて見る単語も見当がつきます。

パート 1

-길래

「〜だったので」。自分が直接見て、感じて、それでこうした。うしろには必ず自分がした行動が来ます。

今日のパターン

意味・使い方~だったので自分が直接見たり感じたりしたことが理由です。

날씨가 춥길래 코트를 입었어요. 天気が寒かったのでコートを着ました。
맛있길래 하나 더 샀어요.おいしかったのでもう一つ買いました。
사람이 많길래 그냥 나왔어요.人が多かったのでそのまま出てきました。

そのままつきます、으 は入りません

パッチムを見ません。「다」を取って「길래」をつけるだけです。「으」は絶対に入りません。文章では「기에」を使いますが、オンラインの文章でとてもよく見かけるので、見慣れておくといいです。

길래 パッチムなし 부르다 → 부르길래가다 → 가길래
길래 パッチムあり 춥다 → 춥길래맛있다 → 맛있길래
기에 文章で使うほう 춥다 → 춥기에좋다 → 좋기에

正しい言い方を選ぼう

「길래」の前には「으」は入りません。最後の行は文章で使う形です。

天気が寒かったのでコートを着ました。 날씨가 춥길래/춥으길래 코트를 입었어요.
おいしかったのでもう一つ買いました。 맛있으길래/맛있길래 하나 더 샀어요.
人が多かったのでそのまま出てきました。 사람이 많길래/많으길래 그냥 나왔어요.
この本がよかったのでおすすめします。 이 책이 좋길에/좋기에 추천합니다.

文を組み立てよう

今度は単語を順番に並べて、文を完成させてみましょうか。完成した文は声に出して言ってみましょう。

天気が寒かったのでコートを着ました。
코트를 날씨가 입었어요 춥길래
おいしかったのでもう一つ買いました。
샀어요 맛있길래 너무 하나 더
人が多かったのでそのまま出てきました。
많길래 나왔어요 사람이 그냥
友だちが呼んだのですぐ出かけました。
바로 친구가 부르길래 나갔어요
パート 2

-고 해서

「〜だったりして」。理由がいくつもあるとき、代表をひとつだけ挙げて、あとは言わずに済ませます。とても韓国語らしい省き方です。

今日のパターン

意味・使い方~だったりして理由がいくつもあるとき、代表を1つだけ挙げて残りは言いません。

비도 오고 해서 그냥 집에 있었어요. 雨も降っていたりして、ただ家にいました。
시간도 없고 해서 안 갔어요.時間もなかったりして行きませんでした。
배도 고프고 해서 먼저 먹었어요.おなかもすいていたりして先に食べました。

고 の前には時制がつきません

「다」を取って「고 해서」をつけるだけです。過ぎたことでも前はそのままにして、うしろの文だけ過去にします。前に「도」を一緒に入れるとずっと自然です。

고 해서 そのままつく 오다 → 오고 해서없다 → 없고 해서
도 ~고 해서 도を一緒に入れると 비 → 비도 오고 해서시간 → 시간도 없고 해서

正しい言い方を選ぼう

「고」の前には「았/었」はつきません。過ぎたことでも前のことばはそのままです。

雨も降っていたりして、ただ家にいました。 비도 오고 해서/왔고 해서 그냥 집에 있었어요.
時間もなかったりして行きませんでした。 시간도 없어고 해서/없고 해서 안 갔어요.
おなかもすいていたりして先に食べました。 배도 고프고 해서/고파고 해서 먼저 먹었어요.
疲れてもいたりして早く寝ました。 피곤하기도 했고 해서/하고 해서 일찍 잤어요.

文を組み立てよう

今度は単語を順番に並べて、文を完成させてみましょうか。完成した文は声に出して言ってみましょう。

雨も降っていたりして、ただ家にいました。
그냥 비도 집에 있었어요 오고 해서
時間もなかったりして昨日は行きませんでした。
안 갔어요 없고 해서 시간도 어제는
おなかもすいていたりして先に食べました。
고프고 해서 먼저 먹었어요 배도 저
疲れてもいたりして昨日は早く寝ました。
어제는 피곤하기도 하고 해서 일찍 잤어요
パート 3

보고 나서 그래서

2つがそろいました。直接見たことが理由なら-길래、理由がいくつもあって代表だけ挙げるなら-고 해서。どちらも「なぜそうしたか」をやわらかく説明します。

네, 어제 시장에 갔는데 싸길래 샀어요.はい、昨日市場に行ったんですが、安かったので買いました。
ハナ
잘 어울려요. 시장에 자주 가세요?よく似合っています。市場によく行かれますか？

가끔요. 집도 가깝고 해서 산책하러 가요.たまに。家も近かったりして、散歩しに行きます。
