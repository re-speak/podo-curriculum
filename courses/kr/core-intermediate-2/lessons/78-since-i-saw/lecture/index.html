그냥 붙어요, 으는 안 들어가요 (そのままつきます、으 は入りません)

받침을 안 봐요. ‘다’만 떼고 ‘길래’를 붙이면 끝이에요. ‘으’는 절대 안 들어가요. 글에서는 ‘기에’를 쓰는데, 온라인 글에서 아주 자주 보이니까 눈에 익혀 두면 좋아요.パッチムを見ません。「다」を取って「길래」をつけるだけです。「으」は絶対に入りません。文章では「기에」を使いますが、オンラインの文章でとてもよく見かけるので、見慣れておくといいです。

길래 받침 없음パッチムなし 부르다 → 부르길래가다 → 가길래
길래 받침 있음パッチムあり 춥다 → 춥길래맛있다 → 맛있길래
기에 글에서 쓰는 짝文章で使うほう 춥다 → 춥기에좋다 → 좋기에

알맞은 말 고르기 (正しい言い方を選ぼう)

‘길래’ 앞에는 ‘으’가 안 들어가요. 마지막 줄은 글에서 쓰는 모양이에요.「길래」の前には「으」は入りません。最後の行は文章で使う形です。

天気が寒かったのでコートを着ました。 날씨가 춥길래/춥으길래 코트를 입었어요.
おいしかったのでもう一つ買いました。 맛있으길래/맛있길래 하나 더 샀어요.
人が多かったのでそのまま出てきました。 사람이 많길래/많으길래 그냥 나왔어요.
この本がよかったのでおすすめします。 이 책이 좋길에/좋기에 추천합니다.

고 앞에는 시제가 안 붙어요 (고 の前には時制がつきません)

‘다’만 떼고 ‘고 해서’를 붙이면 끝이에요. 지난 일이어도 앞은 그대로 두고, 뒤의 문장에서만 과거로 만들어요. 앞에 ‘도’를 같이 넣으면 훨씬 자연스러워요.「다」を取って「고 해서」をつけるだけです。過ぎたことでも前はそのままにして、うしろの文だけ過去にします。前に「도」を一緒に入れるとずっと自然です。

고 해서 그냥 붙어요そのままつく 오다 → 오고 해서없다 → 없고 해서
도 ~고 해서 도를 같이 넣으면도を一緒に入れると 비 → 비도 오고 해서시간 → 시간도 없고 해서
