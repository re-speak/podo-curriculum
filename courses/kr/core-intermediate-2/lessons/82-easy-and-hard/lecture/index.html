다만 떼고 기를 붙여요 (다 を取って 기 をつけます)

받침을 안 봐요. 동사에서 ‘다’만 떼고 ‘기’를 붙이면 '하는 것'이 돼요. 관형사형이 아니에요 — ‘사는 기’나 ‘산 기’ 같은 말은 없어요. ‘가’는 넣어도 빼도 뜻이 같아요.パッチムを見ません。動詞から「다」を取って「기」をつければ「すること」になります。連体形ではありません — 「사는 기」や「산 기」のようなことばはありません。「가」は入れても抜いても意味は同じです。

기가 쉽다 · 어렵다 할 만한지やりやすいかどうか 살다 → 살기가 어려워요읽다 → 읽기가 쉬워요
기가 힘들다 · 편하다 몸이 어떤지体がどうか 하다 → 하기가 힘들어요가다 → 가기가 편해요
기 ~ 가는 빼도 돼요가は抜いてもよい 가다 → 가기 편해요살다 → 살기 어려워요

붙는 방법은 파트1하고 똑같아요. 다른 건 누구 이야기냐예요 — ‘기 싫다’는 말하는 사람의 마음이고, ‘기 좋다’는 그 장소나 물건이 그러기에 알맞다는 말이에요.つけ方はパート1と同じです。ちがうのはだれの話かです — 「기 싫다」は話す人の気持ちで、「기 좋다」はその場所やものがそれに向いているという話です。

기 싫다 내 마음自分の気持ち 말하다 → 말하기 싫어요나가다 → 나가기 싫어요
