아 · 어 · 해 — 또 그 규칙 (아・어・해 — またあのルール)

새 규칙이 아니에요. 동사를 ‘아/어요’로 바꿀 때 하던 그대로 하고, 뒤에 ‘오다’를 붙이면 돼요. ‘아/어지다’, ‘아/어 보이다’하고 앞부분이 전부 같아요.新しいルールではありません。動詞を「아/어요」に変えるときと同じにして、うしろに「오다」をつけるだけです。「아/어지다」、「아/어 보이다」と前の部分が全部同じです。

아 왔어요 ㅏ · ㅗ 모음ㅏ・ㅗ の母音 살다 → 살아 왔어요참다 → 참아 왔어요
어 왔어요 그 밖의 모음それ以外の母音 지키다 → 지켜 왔어요배우다 → 배워 왔어요
해 왔어요 하다 동사하다動詞 일하다 → 일해 왔어요공부하다 → 공부해 왔어요

동사면 는 중, 명사면 그냥 중 (動詞なら 는 중、名詞ならそのまま 중)

동사에는 ‘는’이 붙고, 명사에는 아무것도 안 붙어요. 그리고 문장 중간에 끼울 때는 ‘이에요’ 자리에 ‘에’를 넣어요 — ‘는 중에’가 돼요.動詞には「는」がつき、名詞には何もつきません。そして文の途中に入れるときは「이에요」のところに「에」を入れます — 「는 중에」になります。

는 중이에요 동사 — 는이 붙어요動詞 — 는がつく 배우다 → 배우는 중이에요먹다 → 먹는 중이에요
N 중이에요 명사 — 그냥 붙어요名詞 — そのままつく 회의 → 회의 중이에요공사 → 공사 중이에요
는 중에 문장 중간에 끼울 때文の途中に入れるとき 회의하다 → 회의하는 중에먹다 → 먹는 중에
