그 약속을 지금까지 지켜 왔어요.その約束を今まで守ってきました。

아・어・해 — またあのルール

新しいルールではありません。動詞を「아/어요」に変えるときと同じにして、うしろに「오다」をつけるだけです。「아/어지다」、「아/어 보이다」と前の部分が全部同じです。

아 왔어요 ㅏ・ㅗ の母音 살다 → 살아 왔어요참다 → 참아 왔어요
어 왔어요 それ以外の母音 지키다 → 지켜 왔어요배우다 → 배워 왔어요
해 왔어요 하다動詞 일하다 → 일해 왔어요공부하다 → 공부해 왔어요

正しい言い方を選ぼう

前の動詞の母音を見て、「아/어/해」の中から正しいほうをタップしてください。

十年間この仕事をやってきました。 십 년 동안 이 일을 해 왔어요/하 왔어요.
韓国で長く暮らしてきました。 한국에서 오래 살어 왔어요/살아 왔어요.
ずっと韓国語を習ってきました。 계속 한국어를 배웠 왔어요/배워 왔어요.
その約束を今まで守ってきました。 그 약속을 지금까지 지켜 왔어요/지킴 왔어요.

パート 2

-는 중이다

「〜している最中です」。今まさに進行の真ん中にいます。パート1が来た道なら、こちらは立っている場所です。

今日のパターン

意味・使い方~している最中です今まさに真ん中にいるという意味です。

지금도 계속 배우는 중이에요. 今も続けて習っている最中です。
부장님은 지금 회의 중이에요.部長は今、会議中です。
회의하는 중에 전화가 왔어요.会議している最中に電話が来ました。

動詞なら 는 중、名詞ならそのまま 중

動詞には「는」がつき、名詞には何もつきません。そして文の途中に入れるときは「이에요」のところに「에」を入れます — 「는 중에」になります。

는 중이에요 動詞 — 는がつく 배우다 → 배우는 중이에요먹다 → 먹는 중이에요
N 중이에요 名詞 — そのままつく 회의 → 회의 중이에요공사 → 공사 중이에요
는 중에 文の途中に入れるとき 회의하다 → 회의하는 중에먹다 → 먹는 중에

正しい言い方を選ぼう

動詞か名詞かを見てタップしてください。動詞には「는」がつき、名詞にはつきません。

今も続けて習っている最中です。 지금도 계속 배우는 중이에요/배운 중이에요.
今ごはんを食べている最中です。 지금 밥 먹은 중이에요/먹는 중이에요.
部長は今、会議中です。 부장님은 지금 회의 중이에요/회의는 중이에요.
会議している最中に電話が来ました。 회의하는 중에/회의하는 중이에 전화가 왔어요.
