받침 보고 으라고 · 라고 (パッチムを見て 으라고・라고)

‘(으)ㄹ래요’하고 갈리는 방법이 똑같아요. 받침이 있으면 ‘으라고’, 없으면 ‘라고’, ㄹ 받침은 ‘으’를 안 받아요.「(으)ㄹ래요」と分かれ方が同じです。パッチムがあれば「으라고」、なければ「라고」、ㄹパッチムは「으」を取りません。

으라고 받침 있음パッチムあり 읽다 → 읽으라고먹다 → 먹으라고
라고 받침 없음パッチムなし 오다 → 오라고기다리다 → 기다리라고
라고 ㄹ 받침 — 으 없이ㄹパッチム — 으なし 만들다 → 만들라고팔다 → 팔라고
