ゴール

今日のゴール

引用の2回目です。今日はだれが何をしろと言ったか、しようと言ったかを伝えます。

もう知っている単語

漢字語は中級でもっと力を発揮します。音が日本語と似ているので、はじめて見る単語も見当がつきます。

約束→약속
連絡→연락
準備→준비
パート 1

-(으)라고 하다

「〜しろと言いました」。命令を運びます。ここで気をつけること — 오세요をそのまま運ぶのではありません。引用では오라고になります。

今日のパターン

意味・使い方~しろと言いました命令を運びます。

엄마가 일찍 오라고 했어요. 母が早く来いと言いました。
선생님이 이거 읽으라고 하셨어요.先生がこれを読めとおっしゃいました。
친구가 좀 도와 달라고 했어요.友だちがちょっと手伝ってほしいと言いました。

パッチムを見て 으라고・라고

「(으)ㄹ래요」と分かれ方が同じです。パッチムがあれば「으라고」、なければ「라고」、ㄹパッチムは「으」を取りません。

으라고 パッチムあり 읽다 → 읽으라고먹다 → 먹으라고
라고 パッチムなし 오다 → 오라고기다리다 → 기다리라고
라고 ㄹパッチム — 으なし 만들다 → 만들라고팔다 → 팔라고

正しい言い方を選ぼう

前の動詞にパッチムがあるかを見てタップしてください。ㄹパッチムは「으」を取りません。

母が早く来いと言いました。 엄마가 일찍 오으라고/오라고 했어요.
先生がこれを読めとおっしゃいました。 선생님이 이거 읽으라고/읽라고 하셨어요.
ここでちょっと待てと言いました。 여기서 잠깐 기다리라고/기다릴라고 했어요.
これを作れと言いました。 이거 만들으라고/만들라고 했어요.

文を組み立てよう

今度は単語を順番に並べて、文を完成させてみましょうか。完成した文は声に出して言ってみましょう。

母が早く来いと言いました。
오라고 엄마가 했어요 일찍
先生がこれを読めとおっしゃいました。
하셨어요 이거 선생님이 읽으라고
ここでちょっと待てと言いました。
잠깐 했어요 여기서 기다리라고
友だちがちょっと手伝ってほしいと言いました。
도와 달라고 친구가 좀 했어요
パート 2

-자고 하다

「〜しようと言いました」。誘いを運びます。パート1はパッチムを見ましたが、こちらは見ません。動詞のうしろにそのままつきます。

今日のパターン

意味・使い方~しようと言いました一緒にしようという話を運びます。

친구가 밥 같이 먹자고 해요. 友だちがごはんを一緒に食べようと言います。
주말에 같이 가자고 했어요.週末に一緒に行こうと言いました。
이거 같이 만들자고 했어요.これを一緒に作ろうと言いました。

パート1は見て、パート2は見ない

同じ動詞2つを並べてみます。命令を運ぶときはパッチムを見て、勧誘を運ぶときは見ません。このちがいさえつかめば今日の分は終わりです。

(으)라고 パート1・命令 — パッチムを見る 먹다 → 먹으라고가다 → 가라고
자고 パート2・勧誘 — パッチムを見ない 먹다 → 먹자고가다 → 가자고

正しい言い方を選ぼう

「자고」の前には「으」は入りません。パッチムがあってもなくてもただ「자고」です。

友だちがごはんを一緒に食べようと言います。 친구가 밥 같이 먹자고/먹으자고 해요.
週末に一緒に行こうと言いました。 주말에 같이 갈자고/가자고 했어요.
映画を一緒に見ようと言います。 영화 같이 볼자고/보자고 해요.
これを一緒に作ろうと言いました。 이거 같이 만들으자고/만들자고 했어요.

文を組み立てよう

今度は単語を順番に並べて、文を完成させてみましょうか。完成した文は声に出して言ってみましょう。

友だちがごはんを一緒に食べようと言います。
같이 친구가 먹자고 해요 밥
友だちが週末に一緒に行こうと言いました。
가자고 했어요 주말에 친구가 같이
友だちが映画を一緒に見ようと言います。
영화 보자고 해요 친구가 같이
友だちがこれを一緒に作ろうと言いました。
같이 친구가 이거 만들자고 했어요
パート 3

시킨 말 옮기기

2つがそろいました。しろと言われたことは-(으)라고、しようと言われたことは-자고。-다고と合わせて、引用の三本柱のうち二本が立ちました。

ハナとハルカが夕食の約束の話をします。

ハナ
하루카 씨, 오늘 저녁에 시간 있어요?ハルカさん、今日の夕方に時間ありますか？

그렇구나. 몇 시에 만나요?そうなんですね。何時に会いますか？

일곱 시요. 친구가 늦지 않게 오라고 했어요.7時です。友だちが遅れないように来いと言いました。
ハナ
그럼 지금 나가야겠네요. 길이 막힐 텐데.じゃあ今出ないといけませんね。道が混むでしょうに。

맞아요. 아, 친구가 하나 씨도 같이 오라고 했는데 어때요?そうです。あ、友だちがハナさんも一緒に来いと言いましたが、どうですか？
