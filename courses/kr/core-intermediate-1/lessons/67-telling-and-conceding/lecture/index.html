같은 더, 다른 끝 (同じ 더、ちがう終わり)

‘더라고요’와 오늘의 ‘던데요’는 앞이 똑같아요. 둘 다 내가 직접 본 일이에요. 갈리는 건 뒤에 뭘 붙이느냐고, 그게 듣는 사람의 자리를 바꿔요.「더라고요」と今日の「던데요」は前が同じです。どちらも自分が直接見たことです。分かれるのはうしろに何をつけるかで、それが聞き手の立ち位置を変えます。

더 + 라고요 혼잣말처럼 전함ひとりごとのように伝える 좋다 → 좋더라고요맛있다 → 맛있더라고요
더 + ㄴ데요 오늘 — 반응을 기다림今日 — 反応を待つ 좋다 → 좋던데요맛있다 → 맛있던데요

시제는 하다 쪽에 붙어요 (時制は 하다 のほうにつきます)

받침도 품사도 안 봐요. ‘다’만 떼고 ‘기는’을 붙이면 끝이에요. 대신 조심할 게 하나 있어요 — 지난 일이어도 앞말은 그대로 두고, ‘했어요’는 뒤의 ‘하다’가 받아요.パッチムも品詞も見ません。「다」を取って「기는」をつけるだけです。ただ1つ気をつけることがあります — 過ぎたことでも前のことばはそのままで、「했어요」はうしろの「하다」が受けます。

기는 해요 지금 — 형용사도 동사도今 — 形容詞も動詞も 비싸다 → 비싸기는 해요가다 → 가기는 해요
기는 했어요 지난 일 — 뒤가 받는다過ぎたこと — うしろが受ける 맛있다 → 맛있기는 했어요좋다 → 좋기는 했어요
