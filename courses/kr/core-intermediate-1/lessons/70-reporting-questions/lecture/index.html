여긴 안 갈려요 — 셋 다 냐고 (ここは分かれません — 3つとも 냐고)

평서문에서는 동사에만 ‘ㄴ다/는다’가 붙었어요. 그런데 의문은 그런 게 없어요. 동사든 형용사든 그냥 ‘냐고’예요. 지난 일만 ‘았/었냐고’로 바뀌고요.平叙文では動詞にだけ「ㄴ다/는다」がつきました。でも疑問にはそれがありません。動詞でも形容詞でもただ「냐고」です。過ぎたことだけ「았/었냐고」に変わります。

냐고 동사 — 그대로動詞 — そのまま 가다 → 가냐고오다 → 오냐고
냐고 형용사 — 그대로形容詞 — そのまま 좋다 → 좋냐고맛있다 → 맛있냐고
았/었냐고 과거 — 품사와 상관없이過去 — 品詞に関係なく 가다 → 갔냐고먹다 → 먹었냐고

하라고와 하지 말라고 (しろ と するな)

같은 동사 하나로 앞뒤를 놓아 볼게요. 하라고 시키면 ‘(으)라고’, 하지 말라고 시키면 ‘지 말라고’예요. ‘지 말라고’ 쪽은 받침을 아예 안 봐요.同じ動詞1つで表と裏を並べてみます。しろと言うなら「(으)라고」、するなと言うなら「지 말라고」です。「지 말라고」のほうはパッチムをまったく見ません。

(으)라고 하라고 시킴しろと言う 오다 → 오라고먹다 → 먹으라고
지 말라고 오늘 · 하지 말라고 시킴今日・するなと言う 오다 → 오지 말라고먹다 → 먹지 말라고

원어민 팁 (ネイティブのひとこと)

말할 때 ‘지 말라고 했잖아’는 ‘지 말랬잖아’로 줄어요. ‘라고 하’가 통째로 ‘랬’로 뭉치는 거예요. 다음 과에서 이 줄이기를 제대로 배워요.話すとき「지 말라고 했잖아」は「지 말랬잖아」に縮まります。「라고 하」がまるごと「랬」にまとまるのです。次の課でこの縮め方をきちんと習います。

위아래로 한 줄씩 읽어 주세요. 아래쪽이 실제 대화에서 들리는 소리예요.
遅れるなと言ったじゃない。 늦지 말라고 했잖아. 늦지 말랬잖아.
するなと言ったじゃない。 하지 말라고 했잖아. 하지 말랬잖아.
——
