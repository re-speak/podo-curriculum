해요 から 야 돼요 へ

パッチムで選ぶのではありません。知っている「해요」の「요」だけを「야 돼요」に変えます。「하다」は「해야 돼요」です。

야 돼요ヤ トェヨ 〜아/어요 の 요 を 야 돼요 に 가요 → 가야 돼요カヤ トェヨ먹어요 → 먹어야 돼요モゴヤ トェヨ
해야 돼요ヘヤ トェヨ 해요 → 해야 돼요 확인해요 → 확인해야 돼요ファギネヤ トェヨ준비해요 → 준비해야 돼요チュンビヘヤ トェヨ

을 と ㄹ、どっち？

「-(으)ㄹ 수 있어요」のときと同じルールです。パッチムがあれば「을」、なければ「ㄹ」をつけます。

먹 → 을 필요 없어요ウル ピリョ オプソヨ パッチムあり（子音で終わる） 먹다 → 먹을 필요 없어요モグル ピリョ オプソヨ읽다 → 읽을 필요 없어요イルグル ピリョ オプソヨ
가 → ㄹ 필요 없어요ル ピリョ オプソヨ パッチムなし（母音で終わる） 가다 → 갈 필요 없어요カル ピリョ オプソヨ하다 → 할 필요 없어요ハル ピリョ オプソヨ
