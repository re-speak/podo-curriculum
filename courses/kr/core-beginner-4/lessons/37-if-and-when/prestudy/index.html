으면 と 면、どっち？

あのパッチムのルール、ここでも同じです。「다」を取って、最後の文字を見てください。パッチムがあれば「으면」、なければ「면」です。

있 → 으면ウミョン パッチムあり（子音で終わる） 있다 → 있으면イッスミョン좋다 → 좋으면チョウミョン
가 → 면ミョン パッチムなし（母音で終わる） 가다 → 가면カミョン오다 → 오면オミョン
