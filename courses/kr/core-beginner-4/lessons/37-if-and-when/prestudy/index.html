으면과 면 (으면 と 면、どっち？)

그 받침 규칙, 여기서도 똑같아요. ‘다’ 빼고 마지막 글자를 봐 주세요. 받침이 있으면 ‘으면’, 없으면 ‘면’이에요.あのパッチムのルール、ここでも同じです。「다」を取って、最後の文字を見てください。パッチムがあれば「으면」、なければ「면」です。

있 → 으면ウミョン 받침 있음パッチムあり（子音で終わる） 있다 → 있으면イッスミョン좋다 → 좋으면チョウミョン
가 → 면ミョン 받침 없음パッチムなし（母音で終わる） 가다 → 가면カミョン오다 → 오면オミョン
