으면과 면 (으면 と 면、どっち？)

하는 말 마지막 글자를 봐 주세요. 받침이 있으면 ‘으면’, 없으면 ‘면’이에요. 지난 시간에 배운 그 규칙 그대로예요.することばの最後の文字を見てください。パッチムがあれば「으면」、なければ「면」です。前回習ったあのルールのままです。

읽 → 으면 돼요ウミョン トェヨ 받침 있음パッチムあり（子音で終わる） 읽으면 돼요イルグミョン トェヨ앉으면 돼요アンジュミョン トェヨ
가 → 면 돼요ミョン トェヨ 받침 없음パッチムなし（母音で終わる） 가면 돼요カミョン トェヨ쓰면 돼요スミョン トェヨ
