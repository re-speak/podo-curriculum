으면 と 면、どっち？

することばの最後の文字を見てください。パッチムがあれば「으면」、なければ「면」です。前回習ったあのルールのままです。

읽 → 으면 돼요ウミョン トェヨ パッチムあり（子音で終わる） 읽으면 돼요イルグミョン トェヨ앉으면 돼요アンジュミョン トェヨ
가 → 면 돼요ミョン トェヨ パッチムなし（母音で終わる） 가면 돼요カミョン トェヨ쓰면 돼요スミョン トェヨ

안 が 入る 場所

「안」はそのことばのすぐ前に入れます。「안 와도 돼요」はしなくても大丈夫という意味で、「오면 안 돼요」はしないでという意味です。2つを続けて読みます。

와도 돼요ワド トェヨ 「〜てもいいです」（許可） 여기 앉아도 돼요ヨギ アンジャド トェヨ여기서 먹어도 돼요ヨギソ モゴド トェヨ
안 와도 돼요アン ワド トェヨ 「〜なくても大丈夫です」（しなくていい） 안 읽어도 돼요アン イルゴド トェヨ안 사도 돼요アン サド トェヨ
