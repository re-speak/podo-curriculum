아 보세요 と 어 보세요、どっち？

「아/어요」を習ったときのルールと同じです。前の文字の母音が「ㅏ」か「ㅗ」なら「아 보세요」、それ以外はぜんぶ「어 보세요」です。そして「하다」は「해 보세요」です。

살/놀 → 아 보세요ア ボセヨ 母音が ㅏ か ㅗ 살아 보세요サラ ボセヨ놀아 보세요ノラ ボセヨ
먹/읽 → 어 보세요オ ボセヨ それ以外の母音 먹어 보세요モゴ ボセヨ읽어 보세요イルゴ ボセヨ
