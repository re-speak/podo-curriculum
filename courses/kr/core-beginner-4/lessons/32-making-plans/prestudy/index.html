どっちをつける？

辞書形の「다」をとって、その前の文字を見てください。パッチムがなければ「ㄹ 거예요」、あれば「을 거예요」です。

가 → ㄹ 거예요ル ッコエヨ パッチムなし（母音で終わる） 가다 → 갈 거예요カル ッコエヨ만나다 → 만날 거예요マンナル ッコエヨ
먹 → 을 거예요ウル ッコエヨ パッチムあり（子音で終わる） 먹다 → 먹을 거예요モグル ッコエヨ읽다 → 읽을 거예요イルグル ッコエヨ
