요を取るだけ

タメ口はルールがひとつです。文のいちばん最後にある「요」だけ取ればいいんです。その前はひとつも変わりません。「먹어요」は「먹어」です。「먹」ではありません。

-아 / 어요アヨ / オヨ ふだんの言い方 — 요がつく 지금 집에 가요チグム チベ カヨ김치를 먹어요キムチルル モゴヨ
-아 / 어ア / オ 友だちに言うことば — 요を取るだけ 가요 → 가カヨ → カ먹어요 → 먹어モゴヨ → モゴ

이야 と 야、どっち？

「이에요」、「예요」を選ぶときと同じです。単語の最後の文字を見てください。パッチムがあれば「이야」、なければ「야」です。

생 → 이야イヤ パッチムあり（子音で終わる） 학생이야ハクセンイヤ가방이야カバンイヤ
피 → 야ヤ パッチムなし（母音で終わる） 커피야コピヤ친구야チングヤ
