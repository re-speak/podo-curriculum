네 글자, 그런데 규칙은 없어요 (四文字、でもルールはありません)

‘이’·‘히’·‘리’·‘기’ 넷 중 하나가 동사 안에 들어가요. 어느 동사에 뭐가 붙는지는 규칙이 없어서 단어로 외워야 해요. 대신 짝이 되는 동사와 같이 외우면 훨씬 쉬워요.「이」・「히」・「리」・「기」の4つのうち1つが動詞の中に入ります。どの動詞に何がつくかにルールはないので、単語として覚える必要があります。かわりに対になる動詞と一緒に覚えるとずっと楽です。

이 놓다 · 보다놓다・보다 놓다 → 놓이다보다 → 보이다
히 잡다 · 닫다잡다・닫다 잡다 → 잡히다닫다 → 닫히다
리 열다 · 듣다열다・듣다 열다 → 열리다듣다 → 들리다
기 끊다 · 안다끊다・안다 끊다 → 끊기다안다 → 안기다
