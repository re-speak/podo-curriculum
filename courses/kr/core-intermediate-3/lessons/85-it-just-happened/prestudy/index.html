ゴール

今日のゴール

今日から4回にわたって「だれがしたか」を扱います。今日は自然にそうなったことです。

もう知っている単語

漢字語は中級でもっと力を発揮します。音が日本語と似ているので、はじめて見る単語も見当がつきます。

警察→경찰
修理→수리
故障→고장
パート 1

이 · 히 · 리 · 기

「〜される」「〜になる」。だれかがやったのではなく、そうなった、という言い方です。動詞の中に이・히・리・기が入ります。

今日のパターン

意味・使い方~される・~になる自分がしたのではなく、そうなったのです。

창문이 갑자기 열렸어요. 窓が急に開きました。
도둑이 경찰에게 잡혔어요.泥棒が警察に捕まりました。
문이 저절로 닫혔어요.ドアがひとりでに閉まりました。

四文字、でもルールはありません

「이」・「히」・「리」・「기」の4つのうち1つが動詞の中に入ります。どの動詞に何がつくかにルールはないので、単語として覚える必要があります。かわりに対になる動詞と一緒に覚えるとずっと楽です。

이 놓다・보다 놓다 → 놓이다보다 → 보이다
히 잡다・닫다 잡다 → 잡히다닫다 → 닫히다
리 열다・듣다 열다 → 열리다듣다 → 들리다
기 끊다・안다 끊다 → 끊기다안다 → 안기다

正しい言い方を選ぼう

だれかがしたことか、自然にそうなったことかを見てください。助詞もヒントです — 「이/가」なら自然に、「을/를」ならだれかがしたことです。

窓が急に開きました。 창문이 갑자기 열렸어요/열었어요.
私が窓を開けました。 제가 창문을 열렸어요/열었어요.
泥棒が警察に捕まりました。 도둑이 경찰에게 잡았어요/잡혔어요.
ドアがひとりでに閉まりました。 문이 저절로 닫았어요/닫혔어요.

文を組み立てよう

今度は単語を順番に並べて、文を完成させてみましょうか。完成した文は声に出して言ってみましょう。

窓が急に開きました。
혼자 창문이 열렸어요 갑자기
泥棒がゆうべ警察に捕まりました。
잡혔어요 어젯밤에 도둑이 경찰에게
ドアがひとりでに閉まりました。
저절로 닫혔어요 문이 스르륵
電話が急に切れました。
갑자기 전화가 통화 중에 끊겼어요
パート 2

보이다 · 들리다

「見える」「聞こえる」。自分が見る・聞くのではなく、目や耳に入ってきます。毎日いちばん使う二つの피동사です。

今日のパターン

意味・使い方見える・聞こえる自分が見て聞くのではなく、自然に目と耳に入ってくるのです。

글씨가 잘 안 보여요. 字がよく見えません。
소리가 하나도 안 들려요.音がまったく聞こえません。
여기서는 바다가 보여요.ここからは海が見えます。

自分がすれば 보다、自然になら 보이다

同じことをどちら側から言うかです。自分が目を向けて見るなら「보다」、ただ目に入ってくるなら「보이다」です。助詞も一緒に変わります — 「을/를」が「이/가」になります。

보다 → 보이다 目に入ってくる 드라마를 보다 → 글씨가 보이다영화를 보다 → 바다가 보이다
듣다 → 들리다 耳に入ってくる 음악을 듣다 → 소리가 들리다얘기를 듣다 → 노랫소리가 들리다

正しい言い方を選ぼう

自分がすることなら「보다」・「듣다」、自然に入ってくるなら「보이다」・「들리다」です。助詞も一緒に見てください。

字がよく見えません。 글씨가 잘 안 봐요/보여요.
私は毎日ドラマを見ます。 저는 매일 드라마를 봐요/보여요.
音がまったく聞こえません。 소리가 하나도 안 들려요/들어요.
私は音楽をよく聞きます。 저는 음악을 자주 들어요/들려요.

文を組み立てよう

今度は単語を順番に並べて、文を完成させてみましょうか。完成した文は声に出して言ってみましょう。

字が小さくてよく見えません。
잘 글씨가 안 보여요 작아서
音がまったく聞こえません。
안 들려요 여기서는 소리가 하나도
ここからは海がよく見えます。
바다가 잘 보여요 여기서는 아주
外から歌声が聞こえます。
계속 밖에서 노랫소리가 들려요
パート 3

저절로 그렇게 된 것

2つがそろいました。だれかがやったのではなく、そうなった。この言い方ができると、自分のせいではないことをきちんと説明できます。

会話を読もう

ハナとハルカが部屋の話をします。

ハナ
하루카 씨, 방 괜찮아요? 오래된 집이라던데.ハルカさん、部屋大丈夫ですか？古い家だと聞きましたが。
ハルカ
괜찮아요. 근데 어제 창문이 갑자기 열렸어요.大丈夫です。でも昨日、窓が急に開きました。
ハナ
네? 무서웠겠어요.え？怖かったでしょうね。
ハルカ
좀요. 그리고 문도 저절로 닫혀요.ちょっと。それにドアもひとりでに閉まります。
ハナ
그건 고쳐 달라고 하세요.それは直してくれと言ってください。
ハルカ
네. 아, 그리고 밤에 옆집 소리가 다 들려요.はい。あ、それと夜に隣の家の音が全部聞こえます。
