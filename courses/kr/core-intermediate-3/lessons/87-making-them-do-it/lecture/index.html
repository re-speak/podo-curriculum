그래서 모양만 보고는 못 갈라요 — 문장을 봐야 해요. 대신 ‘우’·‘구’·‘추’는 사동에만 나와서, 이 셋이 보이면 무조건 사동이에요.だから形だけでは分けられません — 文を見る必要があります。かわりに「우」・「구」・「추」は使役にしか出ないので、この3つが見えたら必ず使役です。

우 · 구 · 추 사동에만 나와요使役にしか出ない 자다 → 재우다타다 → 태우다

게에 하다를 붙여요 ( 게 に 하다 をつけます)

새 규칙이 아니에요. 앞에서 만든 ‘게’ 뒤에 ‘하다’나 ‘만들다’를 붙이면 끝이에요. 받침도 안 보고 관형사형도 안 와요. ‘만들다’ 쪽이 조금 더 세게 들려요.新しいルールではありません。「게」のうしろに「하다」か「만들다」をつけるだけです。パッチムも見ないし連体形も来ません。「만들다」のほうが少し強く聞こえます。

게 하다 보통ふつう 웃다 → 웃게 하다기다리다 → 기다리게 하다
게 만들다 조금 더 세게少し強く 말하다 → 말하게 만들다울다 → 울게 만들다

알맞은 말 고르기 (正しい言い方を選ぼう)

‘게’ 앞에는 관형사형이 안 와요. ‘다’만 떼고 바로 ‘게’예요.「게」の前には連体形は来ません。「다」を取ってすぐ「게」です。

友だちを笑わせました。 친구를 웃게 했어요/웃는 게 했어요.
子どもを三十分も待たせました。 아이를 삼십 분이나 기다린 게 했어요/기다리게 했어요.

毎回言わせないで。 매번 말하는 게 만들지 마/말하게 만들지 마.

원어민 팁 (ネイティブのひとこと)

사동사가 있는 동사도 ‘게 하다’로 말할 수 있어요. 그런데 뜻이 조금 달라져요 — 사동사는 내가 직접 해 준 거고, ‘게 하다’는 그 사람이 하게 시킨 거예요.사동사がある動詞も「게 하다」で言えます。でも意味が少し変わります — 사동사は自分が直接してあげたこと、「게 하다」はその人にさせたことです。

위아래로 한 줄씩 읽어 주세요. 위는 내가 먹여 준 거고, 아래는 아이가 먹게 시킨 거예요.
子どもにごはんを食べさせました。 아이에게 밥을 먹였어요. 아이가 밥을 먹게 했어요.
子どもに服を着せました。 아이에게 옷을 입혔어요. 아이가 옷을 입게 했어요.
