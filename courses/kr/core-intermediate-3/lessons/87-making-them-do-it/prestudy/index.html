ゴール

今日のゴール

今度は反対です。前回が自然にそうなったことなら、今日は自分が人をそうさせることです。

もう知っている単語

漢字語は中級でもっと力を発揮します。音が日本語と似ているので、はじめて見る単語も見当がつきます。

無理→무리
親戚→친척
宿題→숙제
パート 1

이 · 히 · 리 · 기 · 우 · 구 · 추

「〜させる」。人に何かをさせます。ここで気をつけること — 前の四文字は피동사とまったく同じです。

今日のパターン

意味・使い方~させる自分が人をそうさせます。

엄마가 아이를 재웠어요. 母が子どもを寝かせました。
아이에게 옷을 입혀요.子どもに服を着せます。
제가 아이에게 밥을 먹였어요.私が子どもにごはんを食べさせました。

前の4つは同じ文字

だから形だけでは分けられません — 文を見る必要があります。かわりに「우」・「구」・「추」は使役にしか出ないので、この3つが見えたら必ず使役です。

이 · 히 · 리 · 기 同じ文字 먹다 → 먹이다입다 → 입히다
우 · 구 · 추 使役にしか出ない 자다 → 재우다타다 → 태우다
문장으로 갈라요 助詞と目的語を見る 피동 → 문이 열렸어요사동 → 아이를 재웠어요

正しい言い方を選ぼう

自分がしたのか、その人がしたのかを見てください。人をそうさせたなら사동사です。

母が子どもを寝かせました。 엄마가 아이를 재웠어요/잤어요.
子どもに服を着せます。 아이에게 옷을 입어요/입혀요.
私が子どもにごはんを食べさせました。 제가 아이에게 밥을 먹었어요/먹였어요.
友だちを笑わせました。 친구를 웃었어요/웃겼어요.

文を組み立てよう

今度は単語を順番に並べて、文を完成させてみましょうか。完成した文は声に出して言ってみましょう。

母が子どもを早く寝かせました。
일찍 엄마가 재웠어요 아이를
寒いから子どもに服を着せます。
입혀요 아이에게 추워서 옷을
私が子どもにごはんを食べさせました。
아이에게 다 먹였어요 제가 밥을
昨日友だちをたくさん笑わせました。
진짜 많이 어제 친구를 웃겼어요
パート 2

-게 하다

「〜させる」。사동사がない動詞はこちらで作ります。-게に하다をつけるだけなので、新しい形ではありません。

今日のパターン

意味・使い方~させる사동사がない動詞はこれで作ります。

친구를 웃게 했어요. 友だちを笑わせました。
아이를 삼십 분이나 기다리게 했어요.子どもを三十分も待たせました。
매번 말하게 만들지 마.毎回言わせないで。

게 に 하다 をつけます

新しいルールではありません。「게」のうしろに「하다」か「만들다」をつけるだけです。パッチムも見ないし連体形も来ません。「만들다」のほうが少し強く聞こえます。

게 하다 ふつう 웃다 → 웃게 하다기다리다 → 기다리게 하다
게 만들다 少し強く 말하다 → 말하게 만들다울다 → 울게 만들다

正しい言い方を選ぼう

「게」の前には連体形は来ません。「다」を取ってすぐ「게」です。

友だちを笑わせました。 친구를 웃게 했어요/웃는 게 했어요.
子どもを三十分も待たせました。 아이를 삼십 분이나 기다린 게 했어요/기다리게 했어요.
弟を無理やり行かせました。 동생을 억지로 갈게 했어요/가게 했어요.
毎回言わせないで。 매번 말하는 게 만들지 마/말하게 만들지 마.

文を組み立てよう

今度は単語を順番に並べて、文を完成させてみましょうか。完成した文は声に出して言ってみましょう。

昨日友だちをたくさん笑わせました。
많이 어제 웃게 했어요 친구를
子どもを三十分も待たせました。
기다리게 했어요 밖에서 아이를 삼십 분이나
弟を無理やり学校に行かせました。
억지로 가게 했어요 동생을 학교에
毎回同じことを言わせないで。
하게 매번 만들지 마 같은 말
パート 3

남을 하게 만들기

2つがそろいました。사동사がある動詞はそれを、ない動詞は-게 하다を。これで、だれがしたのかを言い分けられるようになりました。

会話を読もう

ハナとハルカが甥っ子の話をします。

ハナ
하루카 씨, 어제 조카 봤다면서요?ハルカさん、昨日甥っ子を見たそうですね？
ハルカ
네, 하루 종일요. 밥 먹이는 게 제일 힘들었어요.はい、一日中です。ごはんを食べさせるのがいちばん大変でした。
ハナ
안 먹으려고 하죠?食べようとしないでしょう？
ハルカ
네. 그래서 노래 불러서 웃게 했어요. 그랬더니 먹더라고요.はい。だから歌を歌って笑わせました。そうしたら食べたんですよ。
ハナ
머리 좋으시네요! 재우는 건요?頭いいですね！寝かせるほうは？
ハルカ
그건 더 힘들었어요. 두 시간 만에 겨우 재웠어요.それはもっと大変でした。二時間かけてやっと寝かせました。
