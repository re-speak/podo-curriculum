하다를 시키다로 바꿔요 (하다 を 시키다 に替えます)

규칙이 하나예요. ‘하다’로 끝나는 말에서 ‘하다’만 ‘시키다’로 바꾸면 끝이에요. 사동사는 단어마다 달랐는데, 이건 전부 똑같이 갈려서 훨씬 쉬워요.ルールは1つです。「하다」で終わることばの「하다」を「시키다」に替えるだけです。사동사は単語ごとにちがいましたが、これは全部同じように変わるのでずっと簡単です。

N 시키다 하다 → 시키다하다 → 시키다 공부하다 → 공부시키다청소하다 → 청소시키다
일을 시키다 명사만 남기고名詞だけ残して 일 → 일을 시키다예약 → 예약을 시키다

억울하면 당하다, 그냥이면 되다 (悔しければ 당하다、ただなら 되다)

갈리는 건 마음이에요. 나쁜 일을 겪었으면 ‘당하다’, 그냥 그렇게 됐으면 ‘되다’예요. 그래서 ‘취소당하다’와 ‘취소되다’는 느낌이 달라요.分かれるのは気持ちです。ひどい目に遭ったなら「당하다」、ただそうなったなら「되다」です。だから「취소당하다」と「취소되다」は感じがちがいます。

N 되다 그냥 그렇게 됨ただそうなる 취소 → 취소되다확인 → 확인되다
