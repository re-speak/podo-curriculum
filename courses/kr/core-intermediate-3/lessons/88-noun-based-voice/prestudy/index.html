ゴール

今日のゴール

受け身・使役の最後です。今までは動詞を変えましたが、今日は名詞のうしろを変えます。

もう知っている単語

漢字語は中級でもっと力を発揮します。音が日本語と似ているので、はじめて見る単語も見当がつきます。

部長→부장
詐欺→사기

パート 1

N 시키다

「〜させる」。하다で終わる名詞は、하다を시키다に替えるだけで使役になります。사동사より、ずっと簡単です。

今日のパターン

意味・使い方~させる하다で終わることばは、하다を시키다に替えるだけで使役になります。

부장님이 일을 시켰어요. 部長が仕事をさせました。
엄마가 동생을 공부시켰어요.母が弟を勉強させました。
아이한테 방을 청소시켰어요.子どもに部屋を掃除させました。

하다 を 시키다 に替えます

ルールは1つです。「하다」で終わることばの「하다」を「시키다」に替えるだけです。사동사は単語ごとにちがいましたが、これは全部同じように変わるのでずっと簡単です。

N 시키다 하다 → 시키다 공부하다 → 공부시키다청소하다 → 청소시키다
일을 시키다 名詞だけ残して 일 → 일을 시키다예약 → 예약을 시키다

正しい言い方を選ぼう

自分がしたのか人にさせたのかを見てください。させたなら「시키다」です。

部長が仕事をさせました。 부장님이 일을 시켰어요/했어요.
母が弟を勉強させました。 엄마가 동생을 공부시켰어요/공부했어요.
子どもに部屋を掃除させました。 아이한테 방을 청소시켰어요/청소했어요.
私が予約をしました。 제가 예약을 시켰어요/했어요.

文を組み立てよう

今度は単語を順番に並べて、文を完成させてみましょうか。完成した文は声に出して言ってみましょう。

部長が金曜日に仕事をさせました。
일을 부장님이 시켰어요 금요일에
母が弟を毎日勉強させました。
공부시켰어요 동생을 엄마가 매일
子どもに部屋を掃除させました。
방을 청소시켰어요 아이한테 혼자
友だちに予約をさせました。
예약을 친구한테 식당 시켰어요
パート 2

N 당하다 · N 되다

今度は受け身です。同じ名詞に당하다をつけると「ひどい目に遭う」、되다をつけると中立に「〜される」になります。

今日のパターン

意味・使い方~される今度は受け身です。

사기꾼에게 사기를 당했어요. 詐欺師に詐欺に遭いました。
회의가 갑자기 취소됐어요.会議が急にキャンセルされました。
예약이 자동으로 확인됐어요.予約が自動で確認されました。

悔しければ 당하다、ただなら 되다

分かれるのは気持ちです。ひどい目に遭ったなら「당하다」、ただそうなったなら「되다」です。だから「취소당하다」と「취소되다」は感じがちがいます。

N 당하다 悔しいこと 사기 → 사기를 당하다해고 → 해고를 당하다
N 되다 ただそうなる 취소 → 취소되다확인 → 확인되다

正しい言い方を選ぼう

悔しいことなら「당하다」、ただそうなったなら「되다」です。日本語をよく読んでください。

詐欺師に詐欺に遭いました。 사기꾼에게 사기를 당했어요/됐어요.
会議が急にキャンセルされました。 회의가 갑자기 취소됐어요/취소했어요.
友だちにネタバレをされました。 친구한테 스포를 했어요/당했어요.
予約が自動で確認されました。 예약이 자동으로 확인당했어요/확인됐어요.

文を組み立てよう

今度は単語を順番に並べて、文を完成させてみましょうか。完成した文は声に出して言ってみましょう。

去年、詐欺師に詐欺に遭いました。
사기를 작년에 당했어요 사기꾼에게
会議が今朝急にキャンセルされました。
취소됐어요 오늘 아침에 회의가 갑자기
友だちに映画のネタバレをされました。
영화 당했어요 친구한테 스포를
予約が自動で確認されました。
자동으로 예약이 어제 확인됐어요
パート 3

명사로 만드는 피동·사동

これで受け身と使役が四課そろいました。動詞は覚えるしかありませんが、名詞は시키다・당하다・되다をつけるだけ。こちらのほうがずっと数が多いです。
