주다를 드리다로 ( 주다 を 드리다 に)

새 규칙이 아니에요. 앞에서 만든 ‘아/어 주다’에서 ‘주다’만 ‘드리다’로 바꾸면 돼요. ‘아/어’를 고르는 법은 지금까지와 똑같아요.新しいルールではありません。「아/어 주다」の「주다」を「드리다」に替えるだけです。「아/어」の選び方は今までと同じです。

아 드릴게요 ㅏ · ㅗ 모음ㅏ・ㅗ の母音 받다 → 받아 드릴게요잡다 → 잡아 드릴게요

방향과 높임, 두 가지를 봐요 (方向と敬語、2つを見ます)

볼 게 두 가지예요. 첫째는 방향 — 내가 주면 ‘주다’, 내가 받으면 ‘받다’. 둘째는 상대 — 윗사람한테 주면 ‘드리다’, 윗사람이 나한테 주면 ‘주시다’예요.見るのは2つです。1つめは方向 — 自分があげるなら「주다」、自分がもらうなら「받다」。2つめは相手 — 目上にあげるなら「드리다」、目上が自分にくれるなら「주시다」です。

주다 · 받다 친구 사이友だち同士 내가 주면 → 친구한테 줬어요내가 받으면 → 친구한테 받았어요
드리다 윗사람한테 줄 때目上にあげるとき 선생님 → 선생님께 드렸어요부모님 → 부모님께 드렸어요
주시다 윗사람이 줄 때目上がくれるとき 선생님 → 선생님이 주셨어요부장님 → 부장님이 주셨어요
