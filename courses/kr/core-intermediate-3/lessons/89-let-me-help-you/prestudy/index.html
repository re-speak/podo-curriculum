今日のゴール

このコースの最後の課です。人を手伝うと申し出る言い方と、やりとりの言い方です。

もう知っている単語

漢字語は中級でもっと力を発揮します。音が日本語と似ているので、はじめて見る単語も見当がつきます。

案内→안내
膳物→선물
荷物→짐
パート 1

-아/어 드릴게요

「〜してさしあげます」。-아/어 주다を、相手を高めるほうに替えます。困っている人に声をかけるとき、これが第一声です。

今日のパターン

意味・使い方~してさしあげます아/어 주다の주다を드리다に替えたものです。

무거우시죠? 제가 들어 드릴게요. 重いでしょう？私が持ってさしあげます。
문 열어 드릴게요.ドアを開けてさしあげます。
제가 안내해 드릴게요.私がご案内します。

주다 を 드리다 に

新しいルールではありません。「아/어 주다」の「주다」を「드리다」に替えるだけです。「아/어」の選び方は今までと同じです。

아 드릴게요 ㅏ・ㅗ の母音 받다 → 받아 드릴게요잡다 → 잡아 드릴게요
어 드릴게요 それ以外の母音 들다 → 들어 드릴게요열다 → 열어 드릴게요
해 드릴게요 하다動詞 안내하다 → 안내해 드릴게요예약하다 → 예약해 드릴게요

正しい言い方を選ぼう

前の動詞の母音を見て「아/어/해」の中から選んでください。最後の行は相手が目上の人です。

私が持ってさしあげます。 제가 들아 드릴게요/들어 드릴게요.
ドアを開けてさしあげます。 문 열아 드릴게요/열어 드릴게요.
私がご案内します。 제가 안내하 드릴게요/안내해 드릴게요.
先生に手紙をさしあげました。 선생님께 편지를 드렸어요/줬어요.

文を組み立てよう

今度は単語を順番に並べて、文を完成させてみましょうか。完成した文は声に出して言ってみましょう。

重いでしょう？私が持ってさしあげます。
들어 무거우시죠 드릴게요 제가
私がドアを開けてさしあげます。
드릴게요 문을 제가 열어
私が入口までご案内します。
입구까지 드릴게요 제가 안내해
かばんをお持ちしましょうか？
받아 제가 가방 드릴까요
パート 2

주다 · 받다

「あげる」「もらう」。だれからだれへ動いたかで動詞が変わります。相手が目上なら드리다、目上からなら주시다です。

今日のパターン

意味・使い方~してあげる・~してもらうだれからだれへ動いたかで動詞が変わります。

친구가 저한테 선물을 줬어요. 友だちが私にプレゼントをくれました。
저는 친구한테 선물을 받았어요.私は友だちからプレゼントをもらいました。
선생님께 편지를 드렸어요.先生に手紙をさしあげました。

方向と敬語、2つを見ます

見るのは2つです。1つめは方向 — 自分があげるなら「주다」、自分がもらうなら「받다」。2つめは相手 — 目上にあげるなら「드리다」、目上が自分にくれるなら「주시다」です。

주다 · 받다 友だち同士 내가 주면 → 친구한테 줬어요내가 받으면 → 친구한테 받았어요
드리다 目上にあげるとき 선생님 → 선생님께 드렸어요부모님 → 부모님께 드렸어요
주시다 目上がくれるとき 선생님 → 선생님이 주셨어요부장님 → 부장님이 주셨어요

正しい言い方を選ぼう

だれがあげてだれがもらうか、そして目上かどうかを見てください。

私は友だちにプレゼントをあげました。 저는 친구한테 선물을 받았어요/줬어요.
私は友だちからプレゼントをもらいました。 저는 친구한테 선물을 줬어요/받았어요.
先生に手紙をさしあげました。 선생님께 편지를 드렸어요/줬어요.
先生が私に本をくださいました。 선생님이 저한테 책을 주셨어요/드렸어요.

文を組み立てよう

今度は単語を順番に並べて、文を完成させてみましょうか。完成した文は声に出して言ってみましょう。

私は昨日友だちにプレゼントをあげました。
친구한테 저는 선물을 줬어요 어제
私は友だちからプレゼントをもらいました。
선물을 받았어요 생일에 저는 친구한테
私は先生に手紙をさしあげました。
선생님께 드렸어요 저는 편지를
先生が私に本をくださいました。
좋은 책을 선생님이 저한테 주셨어요
パート 3

도와드리기

これでこのコースは終わりです。困っている人に声をかけるのは-아/어 드릴게요、やりとりを言うのは주다・받다。どちらも相手との距離をきちんと測る道具です。
