どっちが 変わる？

2つの文のうち、前の文だけが変わります。「먹다」、「마시다」のような辞書の形から「다」を取って「고」をつけるだけです。後ろの文は、習ったとおり「요」で終わります。

이나 と 나、どっち？

「은」・「는」と同じパッチムのルールです。前の単語の最後の文字を見てください。パッチムがあれば「이나」、なければ「나」です。

물 → 이나イナ パッチムあり（子音で終わる） 물이나ムリナ밥이나パビナ
피 → 나ナ パッチムなし（母音で終わる） 커피나コピナ차나チャナ
