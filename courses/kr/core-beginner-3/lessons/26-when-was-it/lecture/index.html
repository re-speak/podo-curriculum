에가 붙는 말 (에 が つく ことば)

‘어제’, ‘오늘’, ‘내일’은 일본어처럼 그냥 써요. 나머지 시간 말에는 다 ‘에’를 붙여요. 일본어에는 없어도 한국어에는 붙어요. ‘지난주에’, ‘작년에’처럼요.「어제」・「오늘」・「내일」は日本語と同じで、そのまま使います。ほかの時間のことばには全部「에」をつけます。日本語にはなくても、韓国語にはつきます。「지난주에」、「작년에」のように。
