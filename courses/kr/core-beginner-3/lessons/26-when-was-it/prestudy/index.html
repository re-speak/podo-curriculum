에 が つく ことば

「어제」・「오늘」・「내일」は日本語と同じで、そのまま使います。ほかの時間のことばには全部「에」をつけます。日本語にはなくても、韓国語にはつきます。「지난주에」、「작년에」のように。

~에エ 지난주 · 다음 주 · 주말 · 작년 · 아침 지난주에 갔어요チナンジュエ カッソヨ주말에 만났어요チュマレ マンナッソヨ
