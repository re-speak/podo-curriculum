해요 と 했어요

新しく覚えることはありません。「해요」から「요」を取って、そこに「ㅆ어요」を入れると、昨日の話になります。

-아/어요ア / オヨ 今の ことを 話すとき 마셔요マショヨ먹어요モゴヨ공부해요コンブヘヨ

まず「해요」を思い出してください。「먹어요」だから「먹었어요」です。正しいほうをタップしてください。

パート 2

이었어요 / 였어요イオッソヨ / ヨッソヨ

〜でした。名詞の過去。이에요・예요の에요が、そのまま었어요に変わります。

今日のパターン

意味・使い方~でした名詞の過去を言うときに使います。

저는 옛날에 가수였어요.チョヌン イェンナレ カスヨッソヨ 私は昔、歌手でした。
저는 대학생이었어요.チョヌン テハクセンイオッソヨ私は大学生でした。
제 친구는 회사원이었어요.チェ チングヌン フェサウォニオッソヨ私の友だちは会社員でした。

이었어요 と 였어요、どっち？

「이에요」、「예요」を選ぶときと同じです。単語の最後の文字にパッチムがあれば「이었어요」、なければ「였어요」です。

생 → 이었어요イオッソヨ パッチムあり（子音で終わる） 대학생이었어요テハクセンイオッソヨ회사원이었어요フェサウォニオッソヨ
수 → 였어요ヨッソヨ パッチムなし（母音で終わる） 가수였어요カスヨッソヨ친구였어요チングヨッソヨ
