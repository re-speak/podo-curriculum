이에요 と 입니다

「이에요」、「예요」はパッチムを見て選びましたよね？「입니다」は見なくていいです。パッチムがあってもなくても、全部「입니다」です。

입니다イムニダ かしこまった言い方 — パッチムに関係なく 1つ 학생입니다ハクセンイムニダ가수입니다カスイムニダ

パート 2

-ㅂ니다 / -습니다ムニダ / スムニダ

〜します・〜です。動きやようすを言うとき。どちらになるかは、最後の文字にパッチムがあるかどうかだけで決まります。

今日のパターン

意味・使い方~します動詞のフォーマルな形。

저는 매일 한국어를 공부합니다.チョヌン メイル ハングゴルル コンブハムニダ 私は毎日韓国語を勉強します。

저녁에 김치를 먹습니다.チョニョゲ キムチルル モクスムニダ夕方にキムチを食べます。

ㅂ니다 と 습니다、どっち？

「요」の前の文字を見てください。パッチムがなければ「ㅂ니다」、あれば「습니다」です。さっきのパッチムのルールが、ここでも同じように出てきます。

가 → -ㅂ니다ムニダ パッチムなし（母音で終わる） 가요 → 갑니다カヨ → カムニダ공부해요 → 공부합니다コンブヘヨ → コンブハムニダ
먹 → -습니다スムニダ パッチムあり（子音で終わる） 먹어요 → 먹습니다モゴヨ → モクスムニダ읽어요 → 읽습니다イルゴヨ → イクスムニダ
