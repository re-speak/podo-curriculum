ㅂ니다와 습니다 (ㅂ니다 と 습니다、どっち？)

‘요’ 앞에 있는 글자를 봐 주세요. 받침이 없으면 ‘ㅂ니다’, 있으면 ‘습니다’예요. 아까 그 받침 규칙이 여기서도 똑같이 나와요.「요」の前の文字を見てください。パッチムがなければ「ㅂ니다」、あれば「습니다」です。さっきのパッチムのルールが、ここでも同じように出てきます。

가 → -ㅂ니다ムニダ 받침 없음パッチムなし（母音で終わる） 가요 → 갑니다カヨ → カムニダ공부해요 → 공부합니다コンブヘヨ → コンブハムニダ
먹 → -습니다スムニダ 받침 있음パッチムあり（子音で終わる） 먹어요 → 먹습니다モゴヨ → モクスムニダ읽어요 → 읽습니다イルゴヨ → イクスムニダ
