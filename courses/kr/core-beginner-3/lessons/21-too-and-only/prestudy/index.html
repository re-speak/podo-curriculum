パート 1

〜も。「저도요」で もう使っていることばです。今日は それを 文の中に 入れます。

今日のパターン

意味・使い方~も前の人と同じものを選ぶときに使います。

저도 커피 주세요.チョド コピ チュセヨ 私もコーヒーください。
김치도 주세요.キムチド チュセヨキムチもください。
친구도 와요.チングド ワヨ友だちも来ます。

도 が 入る 場所

「도」は「은/는」、「을/를」の場所にそのまま入ります。「저는도」、「커피를도」のように2つ重ねては使いません。

저도チョド 「〜は」の 場所に 入る 친구는 → 친구도チングド선생님은 → 선생님도ソンセンニムド
커피도コピド 「〜を」の 場所に 入る 김치를 → 김치도キムチド녹차를 → 녹차도ノクチャド

도 の 場所を選ぼう

今度は上の日本語を見て、正しいほうをタップしてみましょうか。

私もコーヒーください。 저도 커피/저는 커피도 주세요.… チュセヨ
私はコーヒーもください。 저는 커피도/저도 커피 주세요.… チュセヨ
キムチもください。 김치를도/김치도 주세요.… チュセヨ
友だちも来ます。 친구는도/친구도 와요.… ワヨ

도 と 만、どっち？

「도」はほかにもあるという意味で、「만」はそれ1つだけという意味です。入る場所は同じです。2つを続けて読みます。

도ト 「〜も」ほかにも ある 저도 커피 주세요チョド コピ チュセヨ김치도 주세요キムチド チュセヨ
만マン 「〜だけ」ほかは いらない 저는 물만 주세요チョヌン ムルマン チュセヨ커피만 마셔요コピマン マショヨ
