도가 들어가는 자리 (도 が 入る 場所)

‘도’는 ‘은는’, ‘을를’ 자리에 그냥 들어가요. ‘저는도’, ‘커피를도’처럼 두 개를 겹쳐 쓰지 않아요.「도」は「은/는」、「을/를」の場所にそのまま入ります。「저는도」、「커피를도」のように2つ重ねては使いません。
