〜より。2つを比べることばです。日本語の「より」と、つく場所がそのまま同じです。

「보다」が つく ところ

「보다」は選ばないほうにつきます。選ぶほうには「이」か「가」をつけます。

제일 と 가장、どっち？

「제일」と「가장」は意味がまったく同じです。話すときは「제일」、文章やニュースでは「가장」をよく使います。2つを続けて読みます。
