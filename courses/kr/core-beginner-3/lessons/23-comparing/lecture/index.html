보다가 붙는 자리 (「보다」が つく ところ)

‘보다’는 고르지 않는 쪽에 붙어요. 고르는 쪽에는 ‘이’나 ‘가’를 붙여요.「보다」は選ばないほうにつきます。選ぶほうには「이」か「가」をつけます。

일본어 ‘より(요리)’하고 똑같은 자리라서, 순서만 조심하면 돼요.

제일과 가장 (제일 と 가장、どっち？)

‘제일’하고 ‘가장’은 뜻이 똑같아요. 말할 때는 ‘제일’, 글이나 뉴스에서는 ‘가장’을 더 많이 써요. 두 개를 이어서 읽을게요.「제일」と「가장」は意味がまったく同じです。話すときは「제일」、文章やニュースでは「가장」をよく使います。2つを続けて読みます。
