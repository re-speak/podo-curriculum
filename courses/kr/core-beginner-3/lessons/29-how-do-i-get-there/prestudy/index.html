〜で。日本語の「で」と同じ場所に入る助詞です。まずは、何で行くかを言えるようにします。

今日のパターン

意味・使い方~で何に乗って行くか、手段を言うときに使います。

로 と 으로、どっち？

単語の最後の文字を見てください。パッチムがないか、ㄹなら「로」、ほかのパッチムがあれば「으로」です。

스 / 철 → 로ロ パッチムなし、または ㄹ 버스로ポスロ지하철로チハチョルロ
손 → 으로ウロ ㄹ 以外の パッチムあり 손으로ソヌロ젓가락으로チョッカラグロ

로 と 으로 を選ぼう

最後の文字を見て、正しいほうをタップしてください。

歩いて

意味・使い方あるいて「걸어서」には「로」をつけません。

저는 걸어서 가요.チョヌン コロソ カヨ 私は歩いて行きます。
회사에 걸어서 가요.フェサエ コロソ カヨ会社に歩いて行きます。
집에 걸어서 왔어요.チベ コロソ ワッソヨ家に歩いて帰りました。

どうやって〜？ 動詞の前に置くひとことで、行き方も、やり方も聞けます。

今日のパターン

어디 と 어떻게、どっち？

パッチムで選ぶのではありません。場所を聞くなら「어디」、方法を聞くなら「어떻게」です。返ってくる答えが変わります。
