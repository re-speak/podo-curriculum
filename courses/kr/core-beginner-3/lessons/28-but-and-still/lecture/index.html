지만이 붙는 자리 (어려워요？ 어렵지만？)

‘지만’은 ‘요’ 자리에 붙이는 게 아니라, 사전에 있는 모양 ‘어렵다’, ‘맵다’에서 ‘다’만 빼고 붙여요. 그래서 ‘워’가 아니라 ㅂ이 그대로 있어요.「지만」は「요」の場所につけるのではなく、辞書にある形の「어렵다」、「맵다」から「다」だけを取ってつけます。だから「워」ではなく、ㅂがそのまま残ります。

아 · 어요アヨ / オヨ 문장을 끝낼 때文を 終わらせる 形（もう知っている） 어렵다 → 어려워요オリョウォヨ맵다 → 매워요メウォヨ
지만チマン 뒤에 말을 이을 때辞書形から 다 を取って、そのまま 어렵다 → 어렵지만オリョプチマン맵다 → 맵지만メプチマン
