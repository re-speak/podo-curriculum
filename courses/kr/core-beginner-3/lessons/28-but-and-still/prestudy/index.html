今日のパターン

意味・使い方~だけど前とうしろが反対のとき、1つの文でつなぎます。

한국어는 어렵지만 재미있어요.ハングゴヌン オリョプチマン チェミイッソヨ 韓国語は難しいけど面白いです。

이 카페는 비싸지만 커피가 맛있어요.イ カペヌン ピッサジマン コピガ マシッソヨこのカフェは高いけどコーヒーがおいしいです。

어려워요？ 어렵지만？

「지만」は「요」の場所につけるのではなく、辞書にある形の「어렵다」、「맵다」から「다」だけを取ってつけます。だから「워」ではなく、ㅂがそのまま残ります。

아 · 어요アヨ / オヨ 文を 終わらせる 形（もう知っている） 어렵다 → 어려워요オリョウォヨ맵다 → 매워요メウォヨ
지만チマン 辞書形から 다 を取って、そのまま 어렵다 → 어렵지만オリョプチマン맵다 → 맵지만メプチマン
