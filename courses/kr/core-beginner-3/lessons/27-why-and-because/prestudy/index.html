안 と 못、どっち？

「왜」のうしろに「안」か「못」を入れます。自分の思いどおりになることなら「안」、思いどおりにならないことなら「못」です。2つを続けて読みます。

今日のパターン

意味・使い方~くて・~ので理由と結果を1つの文でつなぐときに使います。

아팠어서？ 아파서？

「아파요」、「바빠요」のように、いつも使っている形から「요」だけ取って「서」をつけます。過ぎたことでも、「서」の前に「았」・「었」はつけません。「아팠어서」とは言いません。

요 → 서ヨ → ソ いつもの 形から 요を 서に かえるだけ 아파요 → 아파서アパヨ → アパソ없어요 → 없어서オプソヨ → オプソソ
-았/었-アッ / オッ 過去は うしろの ことばだけ 배가 아파서 병원에 갔어요ペガ アパソ ピョンウォネ カッソヨ바빠서 전화 못 했어요パッパソ チョヌァ モ テッソヨ
