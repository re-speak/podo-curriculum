앞일이면 려나, 지금이면 듯 (先のことなら 려나、今なら 듯)

‘려나 보다’는 아직 안 일어난 일이에요. ‘듯하다’는 지금 그런 것 같다는 뜻이고, 동사면 ‘는 듯하다’, 형용사면 ‘(으)ㄴ 듯하다’예요. 관형형 고르는 법은 와 같아요.「려나 보다」はまだ起きていないことです。「듯하다」は今そうらしいという意味で、動詞なら「는 듯하다」、形容詞なら「(으)ㄴ 듯하다」です。連体形の選び方は同じです。

(으)려나 보다 앞으로 일어날 일これから起こること 오다 → 오려나 봐요길어지다 → 길어지려나 봐요
는 듯하다 동사動詞 끝나다 → 끝나는 듯해요오다 → 오는 듯해요
(으)ㄴ 듯하다 형용사形容詞 바쁘다 → 바쁜 듯해요많다 → 많은 듯해요

원어민 팁 (ネイティブのひとこと)

‘는 듯’‘하다’는 ‘는 것 같다’와 뜻이 같아요. 다른 건 문체예요 — ‘듯하다’가 조금 더 딱딱하고 격식 있어요. 그래서 회의나 글에서 자주 보이고, 온라인에서는 하다를 아예 떼고 ~는 듯으로 잘라 써요.는 듯하다は「는 것 같다」と意味は同じです。違うのは文体で、「듯하다」のほうが少しかたく、あらたまっています。だから会議や文章でよく見かけ、オンラインでは「하다」を落として〜「는 듯」と切って使います。

위아래로 한 줄씩 읽어 주세요. 아래쪽은 채팅이나 댓글에서 쓰는 말이에요.
