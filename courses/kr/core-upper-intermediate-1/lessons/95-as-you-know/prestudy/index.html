相手も知っている事実を根拠にすることばと、先のことを控えめに推測することばです。

もう知っている単語

今日も漢字語が出てきます。音が日本語と似ているので、はじめて見る単語も見当がつきます。

パート 1

-다시피

「ご存じのとおり」「ご覧のとおり」。相手もすでに知っていること・見ていることを根拠にして話を始めます。会議や案内でよく使います。

今日のパターン

意味・使い方~のとおり「あなたもすでに知っているとおり」という意味です。

아시다시피 우리는 시간이 없어요. ご存じのとおり、私たちには時間がありません。
보시다시피 지금 자리가 없어요.ご覧のとおり、今席がありません。
말씀드렸다시피 마감은 내일까지예요.申し上げたとおり、締め切りは明日までです。

つく動詞が決まっています

これはどんな動詞にでもつくわけではありません。「알다」・「보다」・「말하다」・「듣다」 — この4つくらいです。だから「시」の入った敬語の形でほぼ固まっています。

아시다시피 ご存じのとおり 아시다시피 → 시간이 없어요아시다시피 → 오늘 회의가 있어요
보시다시피 ご覧のとおり 보시다시피 → 자리가 없어요보시다시피 → 사람이 많아요
말씀드렸다시피 申し上げたとおり 말씀드렸다시피 → 내일까지예요들으셨다시피 → 일정이 바뀌었어요

正しい言い方を選ぼう

日本語をよく見てください。

ご存じのとおり、私たちには時間がありません。 보시다시피/아시다시피 우리는 시간이 없어요.
ご覧のとおり、今席がありません。 보시다시피/아시다시피 지금 자리가 없어요.
申し上げたとおり、締め切りは明日までです。 말씀드렸다시피/들으셨다시피 마감은 내일까지예요.
ご存じのとおり、今日は会議があります。 아시니까/아시다시피 오늘 회의가 있어요.

パート 2

-(으)려나 보다 / -는 듯하다

「〜しそうです」「〜のようです」。려나 보다はこれから起こりそうなこと、는 듯하다は것 같다の少しかたい言い方です。

今日のパターン

意味・使い方~しそうだ・~のようだどちらも控えめな推測です。

비가 오려나 봐요. 雨が降りそうです。
회의가 곧 끝나는 듯해요.会議がもうすぐ終わるようです。
그분은 요즘 좀 바쁜 듯해요.あの方は最近少し忙しいようです。

先のことなら 려나、今なら 듯

「려나 보다」はまだ起きていないことです。「듯하다」は今そうらしいという意味で、動詞なら「는 듯하다」、形容詞なら「(으)ㄴ 듯하다」です。連体形の選び方は同じです。

(으)려나 보다 これから起こること 오다 → 오려나 봐요길어지다 → 길어지려나 봐요
는 듯하다 動詞 끝나다 → 끝나는 듯해요오다 → 오는 듯해요
(으)ㄴ 듯하다 形容詞 바쁘다 → 바쁜 듯해요많다 → 많은 듯해요

正しい言い方を選ぼう

日本語をよく見てください。

雨が降りそうです。 비가 오려나 봐요/오나 봐요.
外は雨が降っているみたいです。 밖에 비가 오려나 봐요/오나 봐요.
会議がもうすぐ終わるようです。 회의가 곧 끝난 듯해요/끝나는 듯해요.
あの方は最近少し忙しいようです。 그분은 요즘 좀 바쁘는 듯해요/바쁜 듯해요.

文を組み立てよう

今度は単語を順番に並べて、文を完成させてみましょうか。完成した文は声に出して言ってみましょう。

空を見ると、今日は雨が降りそうです。
비가 하늘 보니까 오려나 봐요 오늘
今日の会議はまた長くなりそうです。
길어지려나 봐요 회의도 오늘 또
中を見ると、会議がもうすぐ終わるようです。
보니 곧 끝나는 듯해요 안을 회의가
あの方は最近仕事が少し忙しいようです。
일이 그분은 좀 바쁜 듯해요 요즘
