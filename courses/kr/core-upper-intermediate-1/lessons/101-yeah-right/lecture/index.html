기는 무슨 · 은/는 무슨 · 긴 무슨 (기는 무슨・은/는 무슨・긴 무슨)

동사와 형용사에는 어간에 ‘기는 무슨’을 붙여요. 실제 대화에서는 ‘기는’을 ‘긴’으로 줄여서 더 자주 말해요.動詞と形容詞には語幹に「기는 무슨」をつけます。実際の会話では「기는」を「긴」に縮めて言うほうが多いです。

기는 무슨 동사 · 형용사動詞・形容詞 일어나다 → 일어나기는 무슨맛있다 → 맛있기는 무슨
은 · 는 무슨 명사名詞 다이어트 → 다이어트는 무슨공부 → 공부는 무슨
긴 무슨 줄인 말縮めた形 일어나기는 → 일어나긴 무슨바쁘기는 → 바쁘긴 무슨

동사 · 형용사 · 명사 (動詞・形容詞・名詞)

인용을 만들던 그 모양 그대로예요. 동사에는 ‘ㄴ다니까’나 ‘는다니까’, 형용사에는 ‘다니까’, 명사에는 ‘(이)라니까’를 붙여요. 붙이는 법을 새로 외울 게 없어요.引用を作っていたその形のままです。動詞には「ㄴ다니까」か「는다니까」、形容詞には「다니까」、名詞には「(이)라니까」をつけます。つけ方を新しく覚えることはありません。

ㄴ/는다니까 동사動詞 가다 → 간다니까먹다 → 먹는다니까
다니까 형용사形容詞 바쁘다 → 바쁘다니까싶다 → 싶다니까
(이)라니까 명사名詞 진짜 → 진짜라니까학생 → 학생이라니까

알맞은 말 고르기 (正しい言い方を選ぼう)

둘 다 앞에 한 마디를 붙이면 훨씬 살아나요. ‘기는 무슨’ 앞에는 부르는 말을, ‘다니까’ 앞에는 ‘아 진짜’를 놓아 보세요. 그리고 ‘기는’은 실제 대화에서 거의 ‘긴’으로 줄여 말해요.どちらも前にひとこと足すとずっと生きます。「기는 무슨」の前には呼びかけを、「다니까」の前には「아 진짜」を置いてみてください。そして「기는」は実際の会話ではほとんど「긴」に縮めて言います。

위아래로 한 줄씩 읽어 주세요. 아래쪽이 친구 사이에서 실제로 들리는 말이에요.
お前が早く起きるだなんて。 네가 일찍 일어나기는 무슨. 야, 네가 일찍 일어나긴 무슨.
僕、今行くってば。 나 지금 간다니까. 아 진짜, 나 지금 간다니까.
