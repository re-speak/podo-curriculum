동사면 기는커녕, 명사면 은/는커녕 (動詞なら 기는커녕、名詞なら 은/는커녕)

동사와 형용사에는 ‘기’를 붙여서 명사로 만든 다음 ‘는커녕’을 붙여요. 뒤에는 ‘도’나 ‘만’이 거의 항상 와요.動詞と形容詞には「기」をつけて名詞にしてから「는커녕」をつけます。後ろには「도」か「만」がほとんどいつも来ます。

기는커녕 동사 · 형용사動詞・形容詞 도와주다 → 도와주기는커녕쉬다 → 쉬기는커녕
은커녕 · 는커녕 명사名詞 밥 → 밥은커녕커피 → 커피는커녕
뒤에 도 · 만 거의 항상 따라옴ほとんどいつもついてくる 밥은커녕 → 물도 못 마셨어요도와주기는커녕 → 방해만 해요

조차 + 안 하지 않았음しなかった 인사조차 → 안 하고 갔어요연락조차 → 안 했어요
조차 + 모르다 · 없다 아예 없음まったくない 이름조차 → 모르는 사이예요시간조차 → 없었어요

‘도’로도 말은 돼요. ‘물도 못 마셨어요’와 ‘물조차 못 마셨어요’, 둘 다 맞아요. 다른 건 세기예요 — ‘조차’는 ‘그것마저’라는 억울함이 훨씬 세게 들려요. 앞에 ‘심지어’를 붙이면 더 살아나요.「도」でも通じます。「물도 못 마셨어요」と「물조차 못 마셨어요」、どちらも正しいです。違うのは強さで、「조차」は「それまでも」という悔しさがずっと強く聞こえます。前に「심지어」をつけるともっと生きます。

위아래로 한 줄씩 읽어 주세요. 아래쪽이 훨씬 억울하게 들려요.
水さえ飲めませんでした。 물도 못 마셨어요. 심지어 물조차 못 마셨어요.
あいさつさえせずに行きました。 인사도 안 하고 갔어요. 심지어 인사조차 안 하고 갔어요.
