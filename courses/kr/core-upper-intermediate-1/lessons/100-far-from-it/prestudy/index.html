今日のゴール

期待と正反対の状況を不平を言うことばです。どちらもよくない話にだけ使います。

もう知っている単語

今日も漢字語が出てきます。音が日本語と似ているので、はじめて見る単語も見当がつきます。

妨害→방해
連絡→연락
時間→시간
パート 1

-기는커녕

「〜どころか」。期待していたことの代わりに、正反対の悪いことが起きた、というときに使います。

今日のパターン

意味・使い方~どころか期待したことは起きず、むしろ反対のことが起きた、ということばです。

도와주기는커녕 방해만 해요. 手伝うどころか邪魔ばかりします。
쉬기는커녕 더 바빠졌어요.休むどころかもっと忙しくなりました。
밥은커녕 물도 못 마셨어요.ごはんどころか水も飲めませんでした。

動詞なら 기는커녕、名詞なら 은/는커녕

動詞と形容詞には「기」をつけて名詞にしてから「는커녕」をつけます。後ろには「도」か「만」がほとんどいつも来ます。

기는커녕 動詞・形容詞 도와주다 → 도와주기는커녕쉬다 → 쉬기는커녕
은커녕 · 는커녕 名詞 밥 → 밥은커녕커피 → 커피는커녕
뒤에 도 · 만 ほとんどいつもついてくる 밥은커녕 → 물도 못 마셨어요도와주기는커녕 → 방해만 해요

正しい言い方を選ぼう

動詞なら「기」を入れ、名詞ならパッチムを見てください。4つとも後ろに「도」か「만」が来ます。

手伝うどころか邪魔ばかりします。 도와주는커녕/도와주기는커녕 방해만 해요.
休むどころかもっと忙しくなりました。 쉬기는커녕/쉬은커녕 더 바빠졌어요.
ごはんどころか水も飲めませんでした。 밥은커녕/밥는커녕 물도 못 마셨어요.
コーヒーどころか座る時間もありませんでした。 커피은커녕/커피는커녕 앉을 시간도 없었어요.

文を組み立てよう

今度は単語を順番に並べて、文を完成させてみましょうか。完成した文は声に出して言ってみましょう。

あの人は手伝うどころか邪魔ばかりします。
방해만 그 사람은 해요 도와주기는커녕
週末は休むどころかもっと忙しくなりました。
바빠졌어요 쉬기는커녕 주말엔 더
今日はごはんどころか水も飲めませんでした。
밥은커녕 못 마셨어요 오늘은 물도
昨日はコーヒーどころか座る時間もありませんでした。
앉을 시간도 어제는 없었어요 커피는커녕
パート 2

-조차

「〜さえ」。当たり前のことすらできなかった、というときに使います。後ろは必ず否定です。

今日のパターン

意味・使い方~さえ当然できると思っていたことまでできなかった、ということばです。

물조차 못 마셨어요. 水さえ飲めませんでした。
이름조차 모르는 사이예요.名前さえ知らない間柄です。
인사조차 안 하고 갔어요.あいさつさえせずに行きました。

조차 の後ろには必ず否定

名詞にそのままつけます。パッチムがあってもなくても「조차」のままです。ただし後ろは必ず否定でなければなりません — 「못」・「안」・「없다」・「모르다」のどれかが必ず来ます。

조차 + 못 できなかった 물조차 → 못 마셨어요밥조차 → 못 먹었어요
조차 + 안 しなかった 인사조차 → 안 하고 갔어요연락조차 → 안 했어요
조차 + 모르다 · 없다 まったくない 이름조차 → 모르는 사이예요시간조차 → 없었어요

正しい言い方を選ぼう

日本語をよく見てください。最後の行は後ろが否定かどうかを見てください。

水さえ飲めませんでした。 물은커녕/물조차 못 마셨어요.
手伝うどころか邪魔ばかりします。 도와주조차/도와주기는커녕 방해만 해요.
名前さえ知らない間柄です。 이름조차/이름은커녕 모르는 사이예요.
あいさつさえせずに行きました。 인사조차 안 하고 갔어요/했어요.

文を組み立てよう

今度は単語を順番に並べて、文を完成させてみましょうか。完成した文は声に出して言ってみましょう。

昨日は忙しすぎて水さえ飲めませんでした。
물조차 어제는 못 마셨어요 너무 바빠서
私たちは名前さえ知らない間柄です。
모르는 사이예요 아직 우리는 이름조차
あの人はあいさつさえせずに行きました。
인사조차 갔어요 그 사람은 안 하고
今日は忙しすぎてごはんさえ食べられませんでした。
밥조차 오늘은 못 먹었어요 너무 바빠서
パート 3

기대와 정반대

기는커녕は期待の代わりに反対のことが起きた、조차は当たり前のことすらできなかった。どちらも不平を言う場面のことばです。

会話を読もう

ハルカが連休にゆっくり休もうとしたのに、そうできませんでした。

ハナ
연휴 잘 쉬셨어요? 얼굴이 좀 피곤해 보여요.連休はゆっくり休めましたか？顔が少し疲れて見えます。
ハルカ
쉬기는커녕 평소보다 더 바빴어요.休むどころかいつもより忙しかったです。
ハナ
어머, 무슨 일 있었어요?あら、何かあったんですか？
ハルカ
이사를 도와줬는데, 너무 바빠서 물조차 못 마셨어요.引っ越しを手伝ったんですが、忙しすぎて水さえ飲めませんでした。
ハナ
동생이 좀 도와주지 그랬어요.弟さんが少し手伝ってくれればよかったのに。
ハルカ
걔는 도와주기는커녕 방해만 했어요.あの子は手伝うどころか邪魔ばかりしました。
