今日のゴール

大変なことになるところだった瞬間と、すっかり終わってしまったことです。どちらも感情がのります。

もう知っている単語

今日も漢字語が出てきます。音が日本語と似ているので、はじめて見る単語も見当がつきます。

宿題→숙제

パート 1

-(으)ㄹ 뻔했어요

「〜するところでした」。あと少しでそうなるところだった — でも実際には起きていません。そこがいちばん大事です。

今日のパターン

意味・使い方~するところだった起こる直前まで行ったけれど、実際には起きていません。

하마터면 넘어질 뻔했어요. 危うく転ぶところでした。
지하철에서 내릴 뻔했어요.地下鉄で降りるところでした。
하마터면 큰일 날 뻔했어요.危うく大変なことになるところでした。

パッチムを見て ㄹ・을

つけ方は「텐데」と同じです。パッチムがなければㄹ、あれば「을」です。そして「뻔하다」はいつも過去形「뻔했어요」で使います — すでに過ぎた瞬間だからです。

ㄹ 뻔했어요 パッチムなし 넘어지다 → 넘어질 뻔했어요내리다 → 내릴 뻔했어요
을 뻔했어요 パッチムあり 늦다 → 늦을 뻔했어요죽다 → 죽을 뻔했어요
하마터면 前に置くことば 하마터면 → 넘어질 뻔했어요하마터면 → 큰일 날 뻔했어요

正しい言い方を選ぼう

パッチムを見てㄹか「을」かを選んでください。最後の行は実際に起きたかどうかで分かれます。

危うく転ぶところでした。 하마터면 넘어질 뻔해요/넘어질 뻔했어요.
危うく遅れるところでした。 하마터면 늦을 뻔했어요/늦를 뻔했어요.
危うく大変なことになるところでした。 하마터면 큰일 나을 뻔했어요/큰일 날 뻔했어요.
危うく転ぶところでした。まだ転んではいません。 하마터면 넘어졌어요/넘어질 뻔했어요.

文を組み立てよう

今度は単語を順番に並べて、文を完成させてみましょうか。完成した文は声に出して言ってみましょう。

昨日、階段で危うく転ぶところでした。
하마터면 어제 넘어질 뻔했어요 계단에서
地下鉄で危うく一駅早く降りるところでした。
내릴 뻔했어요 하마터면 지하철에서 한 정거장 먼저
今日は本当に危うく大変なことになるところでした。
진짜 큰일 날 뻔했어요 오늘 하마터면
昨日は遅れるところでしたが、幸い遅れませんでした。
다행히 어제 안 늦었어요 늦을 뻔했는데
パート 2

-아/어 버리다

「〜てしまう」。すっかり終わった、という言い方です。すっきりしたのか、残念なのか、感情まで一緒に伝わります。

今日のパターン

意味・使い方~してしまう完全に終わったという意味です。

케이크를 다 먹어 버렸어요. ケーキを全部食べてしまいました。
숙제를 그냥 다 해 버렸어요.宿題をいっそ全部やってしまいました。
친구가 먼저 가 버렸어요.友だちが先に行ってしまいました。

아・어・해 버리다

選び方は今までとまったく同じです。前の母音がㅏかㅗなら「아 버리다」、それ以外なら「어 버리다」、「하다」なら「해 버리다」です。前に「그냥」や「다」をよくつけます。

아 버리다 ㅏ・ㅗ の母音 가다 → 가 버렸어요팔다 → 팔아 버렸어요
어 버리다 それ以外の母音 먹다 → 먹어 버렸어요쓰다 → 써 버렸어요
해 버리다 하다動詞 하다 → 해 버렸어요정리하다 → 정리해 버렸어요

正しい言い方を選ぼう

前の動詞の母音を見て「아」か「어」かを選んでください。最後の行は実際に起きたかどうかで分かれます。

ケーキを全部食べてしまいました。 케이크를 다 먹아 버렸어요/먹어 버렸어요.
宿題をいっそ全部やってしまいました。 숙제를 그냥 다 해 버렸어요/하 버렸어요.
友だちが先に行ってしまいました。 친구가 먼저 가 버렸어요/가어 버렸어요.
お金を全部使ってしまいました。本当に使いました。 돈을 다 써 버렸어요/쓸 뻔했어요.

文を組み立てよう

혼자 어제 다 먹어 버렸어요 케이크를
宿題をいっそ全部やってしまいました。
다 해 버렸어요 그냥 숙제를 오늘
友だちが私を待たずに先に行ってしまいました。

다 콘서트 표가 팔려 버렸어요 벌써
パート 3

아슬아슬했던 순간

뻔했다は起きなかったこと、버렸다は起きてしまったこと。同じ場面でも、どちらを使うかで話がまるごと変わります。

会話を読もう

ハルカが朝、地下鉄で大変な目にあうところでした。

ハナ
얼굴이 왜 그래요? 무슨 일 있었어요?どうしたんですか？何かあったんですか？
ハルカ
아침에 하마터면 늦을 뻔했어요.朝、危うく遅れるところでした。
ハナ
어머, 그래서요?あら、それで？
ハルカ
뛰다가 계단에서 넘어질 뻔했는데 다행히 안 넘어졌어요.走っていて階段で転ぶところでしたが、幸い転びませんでした。
ハナ
다행이네요. 그럼 지각은 안 했어요?よかったですね。じゃあ遅刻はしなかったんですか？
ハルカ
네. 그런데 지하철이 제 앞에서 가 버렸어요.はい。でも地下鉄が目の前で行ってしまいました。
