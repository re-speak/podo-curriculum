ゴール

今日のゴール

どんな条件がついても結果は変わらない — それを言い切る2つの言い方です。

もう知っている単語

今日も漢字語が出てきます。音が日本語と似ているので、はじめて見る単語も見当がつきます。

学校→학교
運動→운동
相関→상관
パート 1

아무리 -아/어도

「いくら〜ても」。条件を極端まで押しても結果は変わらない、と言い切ります。「-아/어도 되다」とは別の働きです。

今日のパターン

意味・使い方どんなに~ても「それでも結果はそのまま」ということばです。

아무리 아파도 학교에 가야 해요. いくら痛くても学校に行かなければなりません。
아무리 바빠도 운동은 해요.いくら忙しくても運動はします。
아무리 생각해도 모르겠어요.いくら考えても分かりません。

아도・어도・해도

選び方は「아/어」を選んできたとおりです。「바쁘다」のようにㅡが落ちる語は「바빠도」になります — 「바빠요」を作るときと同じ道です。

아도 ㅏ・ㅗ の母音 아프다 → 아파도좋다 → 좋아도
어도 それ以外の母音 먹다 → 먹어도늦다 → 늦어도
해도 하다動詞 생각하다 → 생각해도공부하다 → 공부해도

正しい言い方を選ぼう

前の母音を見て「아도」か「어도」かを選んでください。

いくら痛くても学校に行かなければなりません。 아무리 아프어도/아파도 학교에 가야 해요.
いくら忙しくても運動はします。 아무리 바빠도/바쁘도 운동은 해요.
いくら考えても分かりません。 아무리 생각하도/생각해도 모르겠어요.
いくら高くてもこれは買います。 아무리 비싸아도/비싸도 이건 살 거예요.

文を組み立てよう

今度は単語を順番に並べて、文を完成させてみましょうか。完成した文は声に出して言ってみましょう。

パート 2

-든지 -든지

「〜でも〜でも」。どちらを選んでも結果は同じ、というときに二つ並べます。縮めて「-든 -든」とも言います。

今日のパターン

意味・使い方~でも~でも2つを並べて、どちらでもかまわないと言います。

비가 오든지 눈이 오든지 갈 거예요. 雨が降っても雪が降っても行きます。
커피든지 차든지 다 좋아요.コーヒーでもお茶でも大丈夫です。
뭘 고르든지 결과는 똑같아요.何を選んでも結果は同じです。

動詞なら 든지、名詞なら (이)든지

動詞と形容詞には語幹にそのまま「든지」をつけます。名詞はパッチムがあれば「이든지」、なければ「든지」です。縮めて「든 든」と言っても意味は同じです。

든지 動詞・形容詞 오다 → 오든지고르다 → 고르든지
(이)든지 名詞 커피 → 커피든지물 → 물이든지
든 든 縮めた形 가든지 말든지 → 가든 말든커피든지 차든지 → 커피든 차든

正しい言い方を選ぼう

動詞なら語幹にそのまま、名詞ならパッチムを見てつけてください。

雨が降っても雪が降っても行きます。 비가 오다든지/오든지 눈이 오든지 갈 거예요.
何を選んでも結果は同じです。 뭘 골르든지/고르든지 결과는 똑같아요.
コーヒーでもお茶でも大丈夫です。 커피든지/커피이든지 차든지 다 좋아요.
いくら考えても分かりません。 아무리 생각해도/생각하든지 모르겠어요.

文を組み立てよう

今度は単語を順番に並べて、文を完成させてみましょうか。完成した文は声に出して言ってみましょう。

雨が降っても雪が降っても明日は行きます。
내일은 비가 오든지 갈 거예요 눈이 오든지
何を選んでも結果は結局同じです。
똑같아요 결과는 뭘 고르든지 결국
コーヒーでもお茶でも私は全部大丈夫です。
차든지 다 좋아요 커피든지 저는
行こうが行くまいが私は本当にかまいません。
정말 가든지 말든지 상관없어요 저는
パート 3

그래도 결과는 같다

아무리 아/어도は条件を極端まで押す、든지 든지は二つ並べてどちらでもいいと言う。どちらも結論は動きません。
