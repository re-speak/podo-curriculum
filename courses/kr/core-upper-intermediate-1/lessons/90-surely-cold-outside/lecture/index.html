받침을 보고 ㄹ 텐데 · 을 텐데 (パッチムを見て ㄹ 텐데・을 텐데)

고르는 법은 지금까지와 같아요. 이미 끝난 일을 짐작할 때는 ‘았/었을 텐데’가 돼요. ‘춥다’처럼 ㅂ이 바뀌는 말은 ‘추울 텐데’예요.選び方は今までと同じです。すでに終わったことを推測するときは「았/었을 텐데」になります。「춥다」のようにㅂが変わる語は「추울 텐데」です。

ㄹ 텐데 받침 없음パッチムなし 바쁘다 → 바쁠 텐데막히다 → 막힐 텐데
을 텐데 받침 있음パッチムあり 좋다 → 좋을 텐데늦다 → 늦을 텐데
았/었을 텐데 이미 끝난 일すでに終わったこと 도착하다 → 도착했을 텐데먹다 → 먹었을 텐데

주어를 보면 뜻이 갈려요 (主語を見ると意味が分かれます)

붙이는 법은 ‘텐데’와 똑같아요. 다른 건 주어예요. 주어가 저면 제 의지, 남이나 날씨면 짐작이에요. 그리고 뒤에는 늘 시키거나 같이 하자는 말이 와요.つけ方は「텐데」とまったく同じです。違うのは主語です。主語が自分なら自分の意志、他人や天気なら推測です。そして後ろにはいつも命令やさそいがきます。

ㄹ 테니까 받침 없음パッチムなし 하다 → 할 테니까가다 → 갈 테니까
을 테니까 받침 있음パッチムあり 먹다 → 먹을 테니까있다 → 있을 테니까
주어가 저면 의지 남이면 짐작他人なら推測 제가 할 테니까 → 제가 하겠다는 뜻비가 올 테니까 → 거의 확실한 짐작

알맞은 말 고르기 (正しい言い方を選ぼう)

뒤에 시키는 말이 오면 ‘테니까’예요. 특히 주어가 저면 ‘텐데’는 쓸 수 없어요.後ろに命令やさそいがくれば「테니까」です。とくに主語が自分のときは「텐데」は使えません。

私が持ちますから、あなたは休んでください。 제가 들 테니까/들 텐데 좀 쉬세요.
私が予約しておきますから、気楽に来てください。 제가 예약할 테니까/예약할 텐데 편하게 오세요.

원어민 팁 (ネイティブのひとこと)

텐데는 문장 끝에서 혼자 쓰이기도 해요. 그러면 ‘그랬으면 좋았을 텐데’ 하는 아쉬움이 돼요. 하고 싶은데 못 한다고 말할 때 아주 자주 써요.텐데は文の終わりで単独でも使われます。すると「そうだったらよかったのに」という残念な気持ちになります。したいけどできないと言うときにとてもよく使います。

위아래로 한 줄씩 읽어 주세요. 아래쪽이 훨씬 부드럽고 한국 사람다워요.
(行きたいけど)時間がないんです。 시간이 없어요. 시간이 있으면 갈 텐데요.
(手伝いたいけど)今はできません。 지금은 안 돼요. 저도 도와드릴 수 있으면 좋을 텐데요.
