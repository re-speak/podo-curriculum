パート 1

~(으)ㄴ/는지 알다

まず、地図で見つからない駅の場所を、通りかかった人に丁寧に尋ねます。

今日のパターン

意味・使い方道で初対面の人に、場所を聞くときに使います。

혹시 명동역이 어딘지 아세요?明洞駅がどこにあるかご存じですか？
공항철도가 어디서 출발하는지 아세요?空港鉄道がどこから出発するかご存じですか？
가장 가까운 출구가 몇 번인지 아세요?いちばん近い出口が何番かご存じですか？

ㄴ지・은지・는지のつけ方

動作動詞には「는지」、形容詞はパッチムがあれば「은지」、なければ「ㄴ지」をつけます。名詞には「인지」をつけ、「어디인지」はふつう「어딘지」と縮めます。

가→가는지動作動詞＋는지가다 → 가는지출발하다 → 출발하는지
작→작은지形容詞・パッチムあり＋은지작다 → 작은지괜찮다 → 괜찮은지
하→편한지形容詞・パッチムなし＋ㄴ지편하다 → 편한지안전하다 → 안전한지
어디→어디인지名詞＋인지몇 번 → 몇 번인지어디인지 → 어딘지

パート 2

~(으)ㄹ 수 있을 만큼

場所がわかったら、次はタクシーに乗らず歩ける距離かを確かめます。

今日のパターン

意味・使い方歩いて行けるくらい近いかを、先に確かめるときに使います。

여기서 걸어갈 수 있을 만큼 가까워요?ここから歩いて行けるくらい近いですか？
짐을 들고 지나갈 수 있을 만큼 넓어요?荷物を持って通れるくらい広いですか？
두 사람이 앉을 수 있을 만큼 넓어요?二人が座れるくらい広いですか？

ㄹ 수・을 수のつけ方

パッチムがなければ「ㄹ 수」、ㄹ以外のパッチムがあれば「을 수」をつけます。ㄹパッチムはそのまま残し、「수 있을 만큼」を続けます。

가→갈 수 있을 만큼パッチムなし＋ㄹ 수걸어가다 → 걸어갈 수 있을 만큼지나가다 → 지나갈 수 있을 만큼
앉→앉을 수 있을 만큼ㄹ以外のパッチム＋을 수앉다 → 앉을 수 있을 만큼먹다 → 먹을 수 있을 만큼
열→열 수 있을 만큼ㄹを残して＋수열다 → 열 수 있을 만큼만들다 → 만들 수 있을 만큼

ㄹ 수 と 을 수

語幹のパッチムを見て、可能な程度を作る正しいほうを選びましょう。

ここから歩いて行けるくらい近いですか？여기서 걸어갈 수 있을 만큼 가까워요?/여기서 걸어가을 수 있을 만큼 가까워요?
二人が座れるくらい広いですか？두 사람이 앉ㄹ 수 있을 만큼 넓어요?/두 사람이 앉을 수 있을 만큼 넓어요?
一人で開けられるくらい軽いですか？혼자 열을 수 있을 만큼 가벼워요?/혼자 열 수 있을 만큼 가벼워요?
荷物を持って通れるくらい広いですか？짐을 들고 지나가을 수 있을 만큼 넓어요?/짐을 들고 지나갈 수 있을 만큼 넓어요?
