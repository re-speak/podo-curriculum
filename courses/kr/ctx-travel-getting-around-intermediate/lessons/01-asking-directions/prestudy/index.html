ㄴ지·은지·는지 붙이기 (ㄴ지・은지・는지のつけ方)

동작 동사에는 ‘는지’, 형용사는 받침이 있으면 ‘은지’, 없으면 ‘ㄴ지’를 붙여요. 명사에는 ‘인지’를 붙이고, ‘어디인지’는 보통 ‘어딘지’로 줄여요.動作動詞には「는지」、形容詞はパッチムがあれば「은지」、なければ「ㄴ지」をつけます。名詞には「인지」をつけ、「어디인지」はふつう「어딘지」と縮めます。

가→가는지동작 동사 + 는지動作動詞＋는지가다 → 가는지출발하다 → 출발하는지
작→작은지형용사 받침 + 은지形容詞・パッチムあり＋은지작다 → 작은지괜찮다 → 괜찮은지
하→편한지형용사 모음 + ㄴ지形容詞・パッチムなし＋ㄴ지편하다 → 편한지안전하다 → 안전한지
어디→어디인지명사 + 인지名詞＋인지몇 번 → 몇 번인지어디인지 → 어딘지

ㄹ 수와 을 수 붙이기 (ㄹ 수・을 수のつけ方)

받침이 없으면 ‘ㄹ 수’, ㄹ이 아닌 받침이 있으면 ‘을 수’를 붙여요. ㄹ 받침은 그대로 두고 ‘수 있을 만큼’을 이어요.パッチムがなければ「ㄹ 수」、ㄹ以外のパッチムがあれば「을 수」をつけます。ㄹパッチムはそのまま残し、「수 있을 만큼」を続けます。

가→갈 수 있을 만큼받침 없음 + ㄹ 수パッチムなし＋ㄹ 수걸어가다 → 걸어갈 수 있을 만큼지나가다 → 지나갈 수 있을 만큼
앉→앉을 수 있을 만큼ㄹ 외 받침 + 을 수ㄹ以外のパッチム＋을 수앉다 → 앉을 수 있을 만큼먹다 → 먹을 수 있을 만큼
열→열 수 있을 만큼ㄹ 받침 유지 + 수ㄹを残して＋수열다 → 열 수 있을 만큼만들다 → 만들 수 있을 만큼

원어민 팁 (ネイティブのひとこと)

‘저기요’는 길에서 모르는 사람을 자연스럽게 부를 때 자주 써요. ‘실례합니다’는 방해가 될 수 있는 상황에서 먼저 양해를 구하는 느낌이라 더 격식 있게 들려요.「저기요」は道で知らない人に自然に声をかけるときによく使います。「실례합니다」は、邪魔になるかもしれない場面で先に断る感じがあり、より改まって聞こえます。

둘 다 처음 보는 사람에게 쓸 수 있어요. 상황에 따라 고르는 말이지, 한쪽만 정답은 아니에요.
