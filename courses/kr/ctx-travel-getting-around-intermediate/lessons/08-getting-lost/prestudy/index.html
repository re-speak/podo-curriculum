今日のワンシーン

日が暮れるのに、同じ路地ばかり回っています。

나
길을 잘못 든 것 같은데 어떡하죠?道を間違えたようなのですが、どうしましょう？
행인
근처에 눈에 띄는 건물이 보이나요?近くに目立つ建物が見えますか？
나
편의점 하나만 보여요. 지금 있는 곳이 어디쯤인지 모르겠어요.コンビニが一つだけ見えます。今いる場所がどの辺りかわかりません。
행인
골목 끝에 큰길이 보여요. 먼저 거기로 나오세요.路地の先に大通りが見えます。まずそこへ出てください。
나
일단 큰길 쪽으로 나가면 될까요?ひとまず大通りのほうへ出ればいいですか？
행인
네. 큰길에 나가면 표지판이 바로 보여요.はい。大通りへ出れば標識がすぐ見えます。
ゴール

今日のゴール

道を間違えたようだと状況を示して助けを求め、まず何をすればよいか確認します。

道に迷ったとき

「길을 잘못 들다」は道を間違えたという意味、「큰길」は広く見つけやすい道路です。「헤매다」は道がわからず歩き回る状態です。

길을 잘못 들었어요.道を間違えました。
큰길이 어디예요?大通りはどこですか？
한참 헤맸어요.しばらく迷いました。
パート 1

~(으)ㄴ 것 같은데

まず、断定しすぎずに困った状況を示し、相手の助けを待ちます。

状況を示して助けを求めよう

意味・使い方道を間違えたみたいなときに、助けを求めることばです。

길을 잘못 든 것 같은데 어떡하죠?道を間違えたようなのですが、どうしましょう？
반대 방향으로 온 것 같은데 어떡하죠?反対方向へ来たようなのですが、どうしましょう？
막차를 놓친 것 같은데 어떡하죠?終電を逃したようなのですが、どうしましょう？

助けを求めるかたまり

今回は旅行でよく起きる完成形を丸ごと覚えます。状況だけを変え、「것 같은데 어떡하죠?」はそのまま保ちましょう。

길을 잘못 든 + 것 같은데 어떡하죠?道を間違えた＋ようなのですが、どうしましょう？
반대 방향으로 온 + 것 같은데 어떡하죠?反対方向へ来た＋ようなのですが、どうしましょう？

助けの依頼を組み立てよう

混ざった4つのかたまりで状況と助けの依頼をつなぎましょう。

道を間違えたようなのですが、どうしましょう？
것 같은데길을어떡하죠?잘못 든
反対方向へ来たようなのですが、どうしましょう？
어떡하죠?반대 방향으로것 같은데온
カードをなくしたようなのですが、どうしましょう？
것 같은데어떡하죠?카드를잃어버린
駅を通り過ぎたようなのですが、どうしましょう？
어떡하죠?지나친역을것 같은데
パート 2

일단 ~(으)면 될까요?

次に、全部を一度に解決せず、まずする一歩を確認します。

最初の行動を確認しよう

意味・使い方まずはこれからでいいか、を確かめるときに使います。

일단 큰길 쪽으로 나가면 될까요?ひとまず大通りのほうへ出ればいいですか？
일단 역으로 돌아가면 될까요?ひとまず駅へ戻ればいいですか？
일단 여기서 기다리면 될까요?ひとまずここで待てばいいですか？

으면・면を選ぼう

動詞から다を取り、パッチムがあれば으면、なければ、またはㄹパッチムなら면をつけ、その後に「될까요?」を続けます。

찾다→찾으면 될까요?パッチムあり＋으면찾다 → 찾으면 될까요?찍다 → 찍으면 될까요?
나가다→나가면 될까요?母音・ㄹ＋면가다 → 가면 될까요?기다리다 → 기다리면 될까요?

最初の行動を組み立てよう

混ざった3〜4つのかたまりで、まずすることを確認しましょう。
