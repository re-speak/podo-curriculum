내릴 때 쓰는 말 (降りるときの表現)

‘하차하다’는 ‘내리다’의 안내문 표현이고, 벨을 누르면 기사님에게 하차를 알릴 수 있어요. 보통 버스는 뒷문으로 내려요.「하차하다」は「내리다」の案内表示での表現です。ベルを押すと運転手に降車を知らせられ、通常バスは後ろのドアから降ります。

하차는 뒷문입니다.降車は後ろのドアです。
벨을 눌러 주세요.ベルを押してください。
뒷문으로 지나갈게요.後ろのドアへ通りますね。

부탁의 틀 (依頼の型)

부탁할 행동을 ~아/어 주다 형태로 만든 뒤, ‘시면 안 될까요?’를 붙여요. 이번에는 자주 쓰는 완성형으로 익혀요.頼む行動を~아/어 주다の形にし、「시면 안 될까요?」をつけます。今回はよく使う完成形で覚えます。

알려 주다 → 알려 주시면 안 될까요?教える → 教えていただけませんか？
눌러 주다 → 눌러 주시면 안 될까요?押す → 押していただけませんか？

을게요·ㄹ게요 붙이기 (을게요・ㄹ게요のつけ方)

동사에서 ‘다’를 떼고, 받침이 있으면 ‘을게요’, 없거나 ㄹ 받침이면 ‘ㄹ게요’를 붙여요.動詞から「다」を取り、パッチムがあれば「을게요」、なければ、またはㄹパッチムなら「ㄹ게요」をつけます。

먹다→먹을게요받침 + 을게요パッチムあり＋을게요먹다 → 먹을게요잡다 → 잡을게요
내리다→내릴게요모음·ㄹ + ㄹ게요母音・ㄹ＋ㄹ게요가다 → 갈게요지나가다 → 지나갈게요

원어민 팁 (ネイティブのひとこと)

사람 사이를 지나갈 때 ‘지나갈게요’만 말해도 되지만, 앞에 ‘죄송합니다’를 붙이면 몸을 움직이기 전에 양해를 더 분명히 구할 수 있어요.人の間を通るとき「지나갈게요」だけでも通じますが、先に「죄송합니다」をつけると、体を動かす前に了解をより明確に得られます。

죄송합니다. 잠깐 지나갈게요.すみません。ちょっと通りますね。
내릴게요. 잠시만요.降ります。ちょっと失礼します。
