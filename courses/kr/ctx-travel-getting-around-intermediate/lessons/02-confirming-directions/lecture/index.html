방향

右と左を聞き違えました。通りかかった人の説明を、自分の言葉でもう一度確認します。

목표

오늘의 목표 (今日のゴール)

길을 따라가면 목적지가 나오는지 묻고, 들은 방향을 내 말로 정리해 다시 확인해요.道なりに行けば目的地に着くかを尋ね、聞いた方向を自分の言葉でまとめて確認します。

방향 표현 (方向の表現)

‘쭉’은 방향을 바꾸지 않고 계속 가는 뜻이에요. 횡단보도에서는 ‘길을 건너다’, 모퉁이에서는 ‘오른쪽·왼쪽으로 돌다’를 써요.「쭉」は方向を変えずに進み続ける意味です。横断歩道では「길을 건너다」、角では「오른쪽・왼쪽으로 돌다」を使います。

이 길로 쭉 가세요.この道をまっすぐ進んでください。
횡단보도를 건너세요.横断歩道を渡ってください。
사거리에서 왼쪽으로 도세요.交差点で左に曲がってください。

으면·면 붙이기 (으면・면のつけ方)

동사에서 ‘다’를 떼고, 받침이 있으면 ‘으면’, 없거나 ㄹ 받침이면 ‘면’을 붙여요.動詞から「다」を取り、パッチムがあれば「으면」、なければ、またはㄹパッチムなら「면」をつけます。

먹다→먹으면받침 + 으면パッチムあり＋으면먹다 → 먹으면찾다 → 찾으면
가다→가면모음·ㄹ + 면母音・ㄹ＋면가다 → 가면돌다 → 돌면

확인 질문 만들기 (確認質問の作り方)

행동에 ~(으)면을 붙인 뒤 ‘되는 거죠?’를 그대로 이어요. 받침에 따른 ~(으)면 선택은 파트 1과 같아요.行動に~(으)면をつけ、そのまま「되는 거죠?」を続けます。パッチムによる~(으)면の選び方はパート1と同じです。

건너다→건너면 되는 거죠?행동 + (으)면行動＋(으)면건너다 → 건너면돌다 → 돌면
건너면→건너면 되는 거죠?+ 되는 거죠?＋すればいいんですよね？나가면 + 되는 거죠?가면 + 되는 거죠?

원어민 팁 (ネイティブのひとこと)

설명을 다시 부탁할 때 ‘다시 말해 주세요’도 맞지만, 길 안내에서는 ‘제가 맞게 이해했는지 확인할게요’라고 먼저 말하면 상대가 어느 부분을 고쳐야 할지 알기 쉬워요.説明をもう一度頼むとき「다시 말해 주세요」でも通じますが、道案内では「제가 맞게 이해했는지 확인할게요」（正しく理解したか確認します）と先に言うと、相手も直す箇所がわかりやすくなります。

전체를 다시 들을 때全部をもう一度聞くとき다시 한번 말해 주세요.もう一度言ってください。
필요에 따라 必要に応じて
내 이해를 점검할 때自分の理解を確認するとき제가 맞게 이해했는지 확인할게요.正しく理解したか確認しますね。
