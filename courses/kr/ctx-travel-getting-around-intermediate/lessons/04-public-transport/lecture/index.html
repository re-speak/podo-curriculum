대중교통

地下鉄の路線図の前で立ち止まりました。市庁まで何号線に乗り、どこで乗り換えるかを駅員に尋ねます。

지하철 말 (地下鉄の言葉)

‘호선’은 노선의 번호이고, ‘갈아타다’는 다른 열차로 바꾸어 타는 행동, ‘환승’은 그 행동을 가리키는 명사예요.「호선」は路線番号、「갈아타다」は別の列車に乗り換える行動、「환승」はその行動を指す名詞です。

몇 호선 타요?何号線に乗りますか？
어디서 갈아타요?どこで乗り換えますか？
환승이 한 번 있어요.乗り換えが一度あります。

표를 사려면 / 어디로 가야 돼요?切符を買うには、どこへ行けばいいですか？

으려면·려면 붙이기 (으려면・려면のつけ方)

동사에서 ‘다’를 떼고, 받침이 있으면 ‘으려면’, 없거나 ㄹ 받침이면 ‘려면’을 붙여요. 뒤에는 필요한 행동을 ‘~아/어야 돼요’로 말해요.動詞から「다」を取り、パッチムがあれば「으려면」、なければ、またはㄹパッチムなら「려면」をつけます。後ろは必要な行動を「~아/어야 돼요」で言います。

찾다→찾으려면받침 + 으려면パッチムあり＋으려면찾다 → 찾으려면먹다 → 먹으려면
가다→가려면모음·ㄹ + 려면母音・ㄹ＋려면가다 → 가려면팔다 → 팔려면

정보 부탁의 틀 (情報を頼む型)

지금 하는 동작은 동사에서 다를 떼고 는지를 붙여요. 명사는 인지를 붙인 뒤, ‘알려 주실 수 있어요?’로 부탁해요.現在の動作は動詞から다を取り、는지をつけます。名詞には인지をつけ、その後に「알려 주실 수 있어요?」で頼みます。

갈아타다→갈아타는지동사 + 는지動詞＋는지나가다 → 나가는지도착하다 → 도착하는지
몇 시→몇 시인지명사 + 인지名詞＋인지몇 번 → 몇 번인지어디 → 어디인지
