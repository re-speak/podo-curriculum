ㄹ게요・을게요のつけ方

パッチムがなければ「ㄹ게요」、ㄹ以外のパッチムがあれば「을게요」をつけます。ㄹパッチムはそのまま残し、「게요」を続けます。

사→살게요サルケヨパッチムなし＋ㄹ게요사다 → 살게요サダ → サルケヨ보다 → 볼게요ポダ → ポルケヨ
받→받을게요パドゥルケヨㄹ以外のパッチム＋을게요받다 → 받을게요パッタ → パドゥルケヨ입다 → 입을게요イプタ → イブルケヨ
열→열게요ヨルケヨㄹを残して＋게요열다 → 열게요ヨルダ → ヨルケヨ들다 → 들게요トゥルダ → トゥルケヨ

ㄹ게요と을게요を選ぼう

動詞の語幹のパッチムを見て、正しい形を選びましょう。

開けますね。열게요./열을게요.

아 봐도・어 봐도 の作り方

最後の母音がㅏ・ㅗなら「아 봐도」、それ以外なら「어 봐도」をつけます。「하다」は「해 봐도」になります。「만지다」は「만지어」が縮まって「만져」になります。

잡→잡아 봐도チャバ ブァドㅏ・ㅗ＋아 봐도잡다 → 잡아 봐도チャプタ → チャバ ブァド놓다 → 놓아 봐도ノタ → ノア ブァド
입→입어 봐도イボ ブァドその他の母音＋어 봐도입다 → 입어 봐도イプタ → イボ ブァド만지다 → 만져 봐도マンジダ → マンジョ ブァド
하→해 봐도ヘ ブァド하다 → 해 봐도사용하다 → 사용해 봐도サヨンハダ → サヨンヘ ブァド확인하다 → 확인해 봐도ファギナダ → ファギネ ブァド
