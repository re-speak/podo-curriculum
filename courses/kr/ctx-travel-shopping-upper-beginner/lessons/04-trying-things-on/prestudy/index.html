아도・어도の作り方

最後の母音がㅏ・ㅗなら「아도」、それ以外なら「어도」をつけます。同じ母音は一つに縮まり、「하다」は「해도」、「보다」は「봐도」になります。

가→가도 되나요?カド ドェナヨㅏ・ㅗ＋아도가다 → 가도 되나요?カダ → カド ドェナヨ보다 → 봐도 되나요?ポダ → ブァド ドェナヨ
입→입어도 되나요?イボド ドェナヨその他の母音＋어도입다 → 입어도 되나요?イプタ → イボド ドェナヨ신다 → 신어도 되나요?シンタ → シノド ドェナヨ
하→해도 되나요?ヘド ドェナヨ하다 → 해도사용하다 → 사용해도 되나요?サヨンハダ → サヨンヘド ドェナヨ

아도と어도を選ぼう

動詞の最後の母音を見て、正しい許可の形を選びましょう。

使ってもよいですか？사용하아도 되나요?/사용해도 되나요?
