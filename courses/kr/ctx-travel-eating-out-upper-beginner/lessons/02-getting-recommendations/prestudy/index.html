을까요とㄹ까요

語幹にㄹ以外のパッチムがあれば「을까요」、パッチムがなければ「ㄹ까요」をつけます。ㄹパッチムはそのままにして「까요」をつけます。

맞→맞을까요?マジュルカヨパッチムあり → 을까요먹다 → 먹을까요?モクタ → モグルカヨ
가→갈까요?カルカヨパッチムなし → ㄹ까요비싸다 → 비쌀까요?ピサダ → ピサルカヨ
