을과 ㄹ 붙이기 (을とㄹのつけ方)

동사 어간에 ㄹ이 아닌 받침이 있으면 ‘을’을 붙여요. 받침이 없으면 ‘ㄹ’을 붙이고, ㄹ 받침은 그대로 둬요.動詞の語幹にㄹ以外のパッチムがあれば「을」をつけます。パッチムがなければ「ㄹ」をつけ、ㄹパッチムはそのままにします。

앉→앉을 자리アンジュル チャリ받침 있음 → 을パッチムあり → 을앉다 → 앉을 자리アンタ → アンジュル チャリ
가→갈 시간カル シガン받침 없음 → ㄹ · ㄹ 받침 → 그대로パッチムなし → ㄹ・ㄹパッチム → そのまま가다 → 갈 시간カダ → カル シガン만들다 → 만들 자리マンドゥルダ → マンドゥル チャリ

아도와 어도 붙이기 (아도と어도のつけ方)

마지막 모음이 ㅏ·ㅗ면 ‘아도’, 나머지는 ‘어도’를 붙여요. ‘하다’는 ‘해도’가 돼요.最後の母音がㅏ・ㅗなら「아도」、それ以外は「어도」をつけます。「하다」は「해도」になります。

먹→먹어도 될까요?モゴド トェルカヨ나머지 → 어도その他 → 어도먹다 → 먹어도 될까요?モクタ → モゴド トェルカヨ
