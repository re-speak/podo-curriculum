을とㄹのつけ方

動詞の語幹にㄹ以外のパッチムがあれば「을」をつけます。パッチムがなければ「ㄹ」をつけ、ㄹパッチムはそのままにします。

앉→앉을 자리アンジュル チャリパッチムあり → 을앉다 → 앉을 자리アンタ → アンジュル チャリ
가→갈 시간カル シガンパッチムなし → ㄹ・ㄹパッチム → そのまま가다 → 갈 시간カダ → カル シガン만들다 → 만들 자리マンドゥルダ → マンドゥル チャリ

을とㄹを選ぼう

動詞の語幹のパッチムを見て、後ろの名詞を修飾する正しい形をタップしてください。

아도と어도のつけ方

最後の母音がㅏ・ㅗなら「아도」、それ以外は「어도」をつけます。「하다」は「해도」になります。

앉/놀→앉아도 / 놀아도アンジャド / ノラドㅏ・ㅗ → 아도앉다 → 앉아도 될까요?アンタ → アンジャド トェルカヨ
먹→먹어도 될까요?モゴド トェルカヨその他 → 어도먹다 → 먹어도 될까요?モクタ → モゴド トェルカヨ
하→해도 될까요?ヘド トェルカヨ하다 → 해도예약하다 → 예약해도 될까요?イェヤカダ → イェヤケド トェルカヨ
