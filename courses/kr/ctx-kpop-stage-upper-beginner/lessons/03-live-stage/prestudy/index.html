모양 확인 (形を確認)

명사는 ‘인데’, 형용사는 ‘(으)ㄴ데’, 동사는 ‘는데’로 앞뒤 상황을 이어요.名詞は「인데」、形容詞は「(으)ㄴ데」、動詞は「는데」で前後の状況をつなぎます。

명사 名詞
라이브 → 라이브인데
형용사 形容詞
빠르다 → 빠른데
동사 動詞
춤추다 → 춤추는데
