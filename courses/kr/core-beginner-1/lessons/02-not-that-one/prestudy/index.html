今日のゴール

相手が勘ちがいしていることを、こんなふうに直してあげられます。

もう知っている職業

今日あたらしく覚える単語は1つだけです。職業の名前は、もう知っています。漢字から来ているんです。

이 と 가、どっち？

この前見たパッチムのルール、ここでも同じです。パッチムがあれば「이」、なければ「가」です。

생 → 이イ パッチムあり（子音で終わる） 학생이 아니에요ハクセンイ アニエヨ회사원이 아니에요フェサウォニ アニエヨ
수 → 가ガ パッチムなし（母音で終わる） 가수가 아니에요カスガ アニエヨ의사가 아니에요ウィサガ アニエヨ

〜が。「ちがう」と言ったあと、正しいほうを差し出す助詞です。

今日のパターン

意味・使い方~が違うものを正して、正しいほうを新しく出すときに使います。

친구가 기자예요.チングガ キジャエヨ友だちが記者です。
선생님이 한국 사람이에요.ソンセンニミ ハングク サラミエヨ先生が韓国人です。

どうちがう？

おたがい分かっている話なら「은/는」、はじめて教えることなら「이/가」です。今はこれだけ覚えてください。

은 / 는ウン / ヌン すでに話に出ている人・もの 저는 학생이 아니에요チョヌン ハクセンイ アニエヨ하루카 씨는 학생이에요ハルカ シヌン ハクセンイエヨ
이 / 가イ / ガ 「これが」と、はじめて差し出す 하루카 씨가 학생이에요ハルカ シガ ハクセンイエヨ친구가 기자예요チングガ キジャエヨ
