ゴール

今日のゴール

自分が毎日していることをこんなふうに言えるようになります。

もう知っている動詞

今日は動詞です。漢字語のうしろに「해요」をつけるだけの動詞が本当に多いです。

運動→운동해요ウンドンヘヨ
料理→요리해요ヨリヘヨ
掃除→청소해요チョンソヘヨ
パート 1

-아/어요アヨ / オヨ

〜します。動詞の言い方はこれ一つ。今日から自分の一日が話せます。

今日のパターン

意味・使い方~します毎日することを言うときに使います。

저는 매일 운동해요.チョヌン メイル ウンドンヘヨ 私は毎日運動します。
저는 자주 요리해요.チョヌン チャジュ ヨリヘヨ私はよく料理します。
친구는 매일 공부해요.チングヌン メイル コンブヘヨ友だちは毎日勉強します。

아요 と 어요、どっち？

「하다」で終わる言葉は、そのまま「해요」です。あとは前の文字の母音を見てください。ㅏかㅗなら「아요」、それ以外はぜんぶ「어요」です。

살/놀 → 아요アヨ 母音が ㅏ か ㅗ 살아요サラヨ놀아요ノラヨ
먹/읽 → 어요オヨ それ以外の母音 먹어요モゴヨ읽어요イルゴヨ

正しい言葉を選ぼう

前の文字の母音を見て、正しいほうをタップしてください。

살サル 아요/어요
먹モク 어요/아요
놀ノル 어요/아요
읽イク 아요/어요

パート 2

을/를ウル / ルル

〜を。動詞ができたので、次は「何を」。日本語の「を」と同じ場所に入ります。

今日のパターン

意味・使い方~を何をするのか、その対象をつけるときに使います。

저는 커피를 좋아해요.チョヌン コピルル チョアヘヨ 私はコーヒーを好みます。
저는 책을 읽어요.チョヌン チェグル イルゴヨ私は本を読みます。
친구는 드라마를 봐요.チングヌン トゥラマルル プァヨ友だちはドラマを見ます。

을 と 를、どっち？

「은」と「는」を選ぶときに使ったあのルール、ここでも同じです。パッチムがあれば「을」、なければ「를」です。

밥 → 을ウル パッチムあり（子音で終わる） 밥을パブル책을チェグル
피 → 를ルル パッチムなし（母音で終わる） 커피를コピルル드라마를トゥラマルル

을 と 를 を選ぼう

「을」と「를」から正しいほうをタップしてください。

밥パプ 를/을
커피コピ 을/를
음악ウマク 을/를
드라마トゥラマ 을/를
