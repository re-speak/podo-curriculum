의 소리 (「의」は [에] と読む)

여기서 ‘의’는 ‘의’라고 안 읽어요. ‘에’라고 읽어요. 쓸 때만 ‘의’예요.ここでの「의」は「의」とは読みません。「에」と読みます。書くときだけ「의」です。

의 → 에エ 쓸 때는 의, 말할 때는 에書くときは의、話すときは에 친구의チングエ선생님의ソンセンニメ

제와 거 (제 と 거、どこから来た？)

‘저의’는 짧게 ‘제’가 되고, ‘것’은 말할 때 ‘거’가 돼요. 그래서 '제 거'예요.「저의」は短く「제」になり、「것」は話すとき「거」になります。だから「제 거」です。

제チェ 저의 → 제「私の」は제。友だち同士なら 나의→내 · 너의→네 제 가방チェ カバン제 거チェ コ
거コ 것 → 거「もの」は話すとき거 제 거チェ コ누구 거ヌグ コ
