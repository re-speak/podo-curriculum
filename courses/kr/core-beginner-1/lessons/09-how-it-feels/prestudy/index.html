前回までは何をするかを言いましたよね？今日は、食べてみて感じたことをその場で言います。

もう知っている語尾

日本語は「する」と「安い」で形が違いますよね？韓国語は同じです。前回習ったあの「-아요」、「-어요」を、今日もそのまま使います。

춥다 は なぜ 추워요？

パッチムにㅂがある言葉は、少し違います。ㅂが消えて「워요」がつきます。「춥다」は「추워요」、「덥다」は「더워요」。あとは前回習ったとおりです。

춥/덥 → 워요ウォヨ パッチムが ㅂ · ㅂ は消える 추워요チュウォヨ더워요トウォヨ
싸/있 → 아 · 어요アヨ / オヨ それ以外は、前回のルールのまま 싸요サヨ맛있어요マシッソヨ

아/어요 と 네요、どっち？

どちらも正しい言い方です。でも、感じが違います。ただ事実を言うなら「아요」、「어요」。今知って「へえ、そうなんだ！」と思ったら「네요」です。
