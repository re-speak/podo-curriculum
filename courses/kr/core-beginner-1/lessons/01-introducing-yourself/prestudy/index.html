今日のゴール

初めて会った人とこんなふうにあいさつができるようになります。

もう知っている単語

実は今日使う単語、もう知っています。韓国語の単語の70%が漢字から来ているんです。語順も助詞も日本語とほぼ同じです。

日本→일본イルボン
学生→학생ハクセン
会社員→회사원フェサウォン
パート 1

N이에요 / 예요N イエヨ / エヨ

Nです。まずは「私は〜です」が言えるようにします。

今日のパターン

意味・使い方~です名前・仕事・国など、自分が何者かを言うときに使います。

저는 다나카예요.チョヌン タナカエヨ 私は田中です。
저는 학생이에요.チョヌン ハクセンイエヨ私は学生です。
저는 회사원이에요.チョヌン フェサウォニエヨ私は会社員です。

이에요 と 예요、どっち？

単語の最後の文字を見てください。パッチムがあれば「이에요」、なければ「예요」をつけます。

원 → 이에요イエヨ パッチムあり（子音で終わる） 회사원이에요フェサウォニエヨ학생이에요ハクセンイエヨ
수 → 예요エヨ パッチムなし（母音で終わる） 가수예요カスエヨ다나카예요タナカエヨ

正しい言葉を選ぼう

最後の文字を見て、正しいほうをタップしてください。

私は学生です。 저는 학생이에요./예요.チョヌン ハクセン …
私は医者です。 저는 의사예요./이에요.チョヌン ウィサ …
私は韓国人です。 저는 한국 사람예요./이에요.チョヌン ハングク サラム …
私は歌手です。 저는 가수이에요./예요.チョヌン カス …

質問のパターン

意味・使い方~ですか文字はそのままで、最後だけ上げて聞きます。

학생이에요.ハクセンイエヨ 学生です。（終わりを下げる）
학생이에요?ハクセンイエヨ 学生ですか？（終わりを上げるだけ）

パート 2

은/는ウン / ヌン

〜は。話のテーマを決める助詞で、日本語と同じ場所に入ります。

今日のパターン

意味・使い方~は誰の話なのかを先に立てるときに使います。

다나카 씨는 학생이에요?タナカ シヌン ハクセンイエヨ 田中さんは学生ですか？
저는 일본 사람이에요.チョヌン イルボン サラミエヨ私は日本人です。
선생님은 한국 사람이에요.ソンセンニムン ハングク サラミエヨ先生は韓国人です。

은 と 는、どっち？

さっきのパッチムのルール、ここでも同じです。パッチムがあれば「은」、なければ「는」です。

생 → 은ウン パッチムあり（子音で終わる） 학생은ハクセンウン선생님은ソンセンニムン
저 → 는ヌン パッチムなし（母音で終わる） 저는チョヌン다나카 씨는タナカ シヌン

은 と 는 を選ぼう

「은」と「는」から正しいほうをタップしてください。

학생ハクセン 는/은
저チョ 는/은
이름イルム 은/는
다나카 씨タナカ シ 는/은
