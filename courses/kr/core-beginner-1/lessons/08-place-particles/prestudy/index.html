パート 1

N에N エ

〜に。行き先を言う助詞です。日本語の「に」と同じ場所、同じ意味。

今日のパターン

意味・使い方~に行く場所やいる場所を言うときに使います。

저는 학교에 가요.チョヌン ハッキョエ カヨ 私は学校に行きます。
저는 회사에 가요.チョヌン フェサエ カヨ私は会社に行きます。
친구는 집에 와요.チングヌン チベ ワヨ友だちは家に来ます。

時間にも 에

意味・使い方~に何時、何曜日のように時を言うときも同じ「에」を使います。

저는 아침에 운동해요.チョヌン アチメ ウンドンヘヨ 私は朝に運動します。
저는 저녁에 요리해요.チョヌン チョニョゲ ヨリヘヨ私は夕方に料理します。
주말에 뭐 해요?チュマレ ムォ ヘヨ週末に何をしますか？

パート 2

N에서N エソ

〜で。着いた先で「何をするか」を言うときは、에ではなく에서。

今日のパターン

意味・使い方~で何かをする場所を言うときに使います。

저는 카페에서 공부해요.チョヌン カペエソ コンブヘヨ 私はカフェで勉強します。
저는 집에서 밥을 먹어요.チョヌン チベソ パブル モゴヨ私は家でご飯を食べます。
친구는 도서관에서 책을 읽어요.チングヌン トソグァネソ チェグル イルゴヨ友だちは図書館で本を読みます。

에 と 에서、どっち？

音で選ぶのではありません。うしろに来る動詞を見てください。ただ行く・来るなら「에」、そこで何かをするなら「에서」です。

에エ 着く先だけを言う 학교에 가요ハッキョエ カヨ집에 와요チベ ワヨ
에서エソ そこで何かをする 학교에서 공부해요ハッキョエソ コンブヘヨ집에서 먹어요チベソ モゴヨ

에 と 에서 を選ぼう

うしろに来る動詞を見て、正しいほうをタップしてください。
