今日のゴール

画面越しの日常をたずね、見える様子をもとに相手の状態を気づかえるようになります。

見てわかる

「티 나다」は、気持ちや状態が表に出て、ほかの人に気づかれるときに使います。

피곤한 티가 나.疲れているのが見てわかる。
좋아하는 티가 나.好きなのが見てわかる。
긴장한 티가 났어.緊張しているのが見てわかった。
パート 1

~아/어 보다

画面の向こうで気になったものを、やさしく見せてもらいます。

今日のパターン

意味・使い方相手にある行動を一度してみてと言うとき、「〜아/어 봐」を使います。負担をかけず、軽く勧められます。

뒤에 그거 뭐야? 좀 보여 줘 봐.後ろのそれ、何？ちょっと見せてみて。
카메라를 창문 쪽으로 한번 돌려 봐.カメラを窓のほうへ一度向けてみて。
새로 산 조명을 켜 봐.新しく買った照明をつけてみて。

아 봐 と 어 봐

動詞の最後の母音がㅏかㅗなら「아 봐」、それ以外は「어 봐」を付けます。「하다」は「해 봐」です。

앉→앉아 봐最後の母音がㅏ・ㅗ앉다 → 앉아 봐돌다 → 돌아 봐
켜다→켜 봐それ以外보여 주다 → 보여 줘 봐켜다 → 켜 봐

合う表現を選ぼう

前のことばと意味を見て、場面に合うほうをタップしてください。

窓のほうを見てみて。창문 쪽을 봐 봐/어 봐.
照明をつけてみて。조명을 켜 봐/아 봐.
そこに座ってみて。거기 앉어 봐/아 봐.
一度電話してみて。한번 전화아 봐/해 봐.

パート 2

~(으)ㄴ가 보다

見せてもらったあと、画面に映るユジンの様子をそっと気づかいます。

今日のパターン

意味・使い方目に見える様子を根拠に状態を推測するとき、「〜(으)ㄴ가 봐」と言います。決めつけず、そっと気づかえます。

얼굴 보니까 좀 피곤한가 봐.顔を見ると、少し疲れているみたい。
방이 생각보다 작은가 봐.部屋が思ったより小さいみたい。
밖이 벌써 어두운가 봐.外はもう暗いみたい。

ㄴ가 봐 と 은가 봐

形容詞の語幹にパッチムがあれば「은가 봐」、なければ「ㄴ가 봐」を付けます。

작→작은가 봐パッチムあり작다 → 작은가 봐짧다 → 짧은가 봐
피곤하→피곤한가 봐パッチムなし피곤하다 → 피곤한가 봐어둡다 → 어두운가 봐

合う表現を選ぼう

前のことばと意味を見て、場面に合うほうをタップしてください。

少し疲れているみたい。좀 피곤하ㄴ가 봐/은가 봐.
部屋が小さいみたい。방이 작ㄴ가 봐/은가 봐.
今日は忙しいみたい。오늘 바쁘은가 봐/ㄴ가 봐.
通話が短いみたい。통화가 짧은가 봐/ㄴ가 봐.
