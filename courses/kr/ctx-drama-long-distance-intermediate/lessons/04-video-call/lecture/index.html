아 봐와 어 봐 (아 봐 と 어 봐)

동사의 마지막 모음이 ㅏ나 ㅗ면 ‘아 봐’, 나머지는 ‘어 봐’를 붙여요. ‘하다’는 ‘해 봐’예요.動詞の最後の母音がㅏかㅗなら「아 봐」、それ以外は「어 봐」を付けます。「하다」は「해 봐」です。

앉→앉아 봐ㅏ · ㅗ最後の母音がㅏ・ㅗ앉다 → 앉아 봐돌다 → 돌아 봐
켜다→켜 봐그 외それ以外보여 주다 → 보여 줘 봐켜다 → 켜 봐

ㄴ가 봐와 은가 봐 (ㄴ가 봐 と 은가 봐)

형용사 어간에 받침이 있으면 ‘은가 봐’, 없으면 ‘ㄴ가 봐’를 붙여요.形容詞の語幹にパッチムがあれば「은가 봐」、なければ「ㄴ가 봐」を付けます。

작→작은가 봐받침 있음パッチムあり작다 → 작은가 봐짧다 → 짧은가 봐
피곤하→피곤한가 봐받침 없음パッチムなし피곤하다 → 피곤한가 봐어둡다 → 어두운가 봐
