태연하다 (平然としている)

‘태연하다’는 속으로 긴장해도 겉으로는 아무렇지 않아 보일 때 써요.「태연하다」は、内心は緊張していても、表では何でもないように見えるときに使います。

완벽하게 숨기지 못하고 살짝 웃음이 새는 장면으로 읽어 주세요.

태연하게 대답했어.平然と答えた。
태연한 얼굴이었어.平然とした顔だった。

는 척과 (으)ㄴ 척 (는 척 と (으)ㄴ 척)

지금 이어지는 동작에는 ‘는 척’, 상태나 이미 끝난 일에는 ‘(으)ㄴ 척’을 붙여요.今続いている動作には「는 척」、状態やすでに終わったことには「(으)ㄴ 척」を付けます。

모르다→모르는 척지금 하는 동작今している動作모르다 → 모르는 척자다 → 자는 척
사다→안 산 척상태·끝난 일状態・終わったこと사다 → 산 척괜찮다 → 괜찮은 척

ㄹ까 봐와 을까 봐 (ㄹ까 봐 と 을까 봐)

동사나 형용사 어간에 받침이 있으면 ‘을까 봐’, 없거나 ㄹ 받침이면 ‘ㄹ까 봐’를 붙여요.動詞や形容詞の語幹にパッチムがあれば「을까 봐」、なければ、またはㄹパッチムなら「ㄹ까 봐」を付けます。

믿→믿을까 봐받침 있음パッチムあり믿다 → 믿을까 봐늦다 → 늦을까 봐
들키→들킬까 봐받침 없음·ㄹパッチムなし・ㄹ들키다 → 들킬까 봐알다 → 알까 봐
