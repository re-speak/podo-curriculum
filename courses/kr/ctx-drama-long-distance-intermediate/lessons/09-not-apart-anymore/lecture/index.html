또 (また)

‘또’는 같은 일이 다시 이어질 때 써요. 여기서는 또 만남보다, 또 떨어질 시간을 가리켜요.「또」は、同じことがもう一度続くときに使います。ここでは再会より、また離れる時間を指します。

또 떨어지고 싶지 않아.また離れたくない。

ㄹ래와 을래 (ㄹ래 と 을래)

동사 어간에 받침이 있으면 ‘을래’, 없거나 ㄹ 받침이면 ‘ㄹ래’를 붙여요.動詞の語幹にパッチムがあれば「을래」、なければ、またはㄹパッチムなら「ㄹ래」を付けます。

먹→먹을래받침 있음パッチムあり먹다 → 먹을래찾다 → 찾을래
가→갈래받침 없음·ㄹパッチムなし・ㄹ가다 → 갈래살다 → 살래

다가는과 면 (다가는 と 면)

계속하면 나쁜 결과가 예상될 때 ‘다가는’, 결과가 중립적인 조건이면 ‘(으)면’을 써요.続けると悪い結果が予想されるときは「다가는」、結果が中立的な条件なら「(으)면」を使います。

미루다→미루다가는좋지 않은 결과를 경고よくない結果を警告미루다 → 미루다가는지내다 → 지내다가는
만나다→만나면중립적인 조건中立的な条件만나다 → 만나면정하다 → 정하면
