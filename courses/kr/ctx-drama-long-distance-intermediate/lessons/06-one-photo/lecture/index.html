ユジンから届いた一枚の写真。そこにある季節は、こちらとまったく違います。

벌써 (もう)

‘벌써’는 예상한 때보다 일이 빨리 왔다고 느낄 때 써요.「벌써」は、予想した時よりも早く何かが来たと感じるときに使います。

조금 놀랐지만 반가운 소식을 본 느낌으로 읽어 주세요.
벌써 눈이 와.もう雪が降る。
벌써 겨울이네.もう冬だね。
벌써 일 년이 지났어.もう1年が過ぎた。
パート 1

~치고는

写真の季節に驚いたあと、こちらの意外な暖かさを基準と比べます。

오늘의 패턴 (今日のパターン)

뜻과 쓰임 意味・使い方어떤 기준에서 예상한 것과 다를 때 ‘~치고는’을 써요. 계절이나 날씨의 뜻밖인 점을 말하기 좋아요.ある基準から予想したことと違うとき、「〜치고는」を使います。季節や天気の意外な点を言うのに便利です。

장면 속 말처럼 자연스럽게 읽고, 강조된 부분을 한 번 더 짚어 주세요.

겨울치고는 눈이 별로 안 와.冬にしては、雪があまり降らない。
아침치고는 기온이 높아.朝にしては、気温が高い。

첫눈치고는 눈이 많이 쌓였어.初雪にしては、雪がたくさん積もった。

치고는과 보다 (치고는 と 보다)

기준에서 뜻밖이면 ‘치고는’, 두 대상을 단순히 비교하면 ‘보다’를 써요.基準から見て意外なら「치고는」、二つの対象を単純に比べるなら「보다」を使います。

십일월→십일월치고는기준에서 뜻밖일 때基準から見て意外なとき십일월 → 십일월치고는겨울 → 겨울치고는
어제→어제보다두 대상을 비교할 때二つを比べるとき어제 → 어제보다서울 → 서울보다

인데와 는데 (인데 と 는데)

명사 뒤에는 ‘인데’, 지금 하는 동작 뒤에는 ‘는데’를 붙여 배경을 이어요.名詞の後には「인데」、今している動作の後には「는데」を付け、背景をつなぎます。

하늘→하늘인데명사 + 인데名詞 + 인데하늘 → 하늘인데십일월 → 십일월인데
보다→보는데동작 + 는데動作 + 는데보다 → 보는데걷다 → 걷는데
