참다 (こらえる)

‘참다’는 눈물이나 하고 싶은 말을 바로 내보내지 않고 견딜 때 써요.「참다」は、涙や言いたいことをすぐ出さず、こらえるときに使います。

억지로 강해 보이기보다, 울컥한 마음을 누르는 소리로 읽어 주세요.
눈물을 참다.涙をこらえる。
하고 싶은 말을 참다.言いたいことをこらえる。
더는 못 참겠어.もうこれ以上こらえられない。

~자마자 만들기 (〜자마자 の作り方)

동사에서 ‘다’를 떼고 ‘자마자’를 붙여요. 바로 이어지지 않으면 ‘고 나서’가 더 자연스러워요.動詞から「다」を取って「자마자」を付けます。すぐ続かないなら「고 나서」のほうが自然です。

도착하다→도착하자마자바로 이어질 때すぐ続くとき도착하다 → 도착하자마자내리다 → 내리자마자
도착하다→도착하고 나서순서만 말할 때順番だけを言うとき도착하다 → 도착하고 나서쉬다 → 쉬고 나서
