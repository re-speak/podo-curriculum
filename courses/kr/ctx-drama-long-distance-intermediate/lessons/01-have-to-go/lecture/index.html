다니와 라니 (다니 と 라니)

동사나 형용사 뒤에는 ‘다니’, 명사 뒤에는 ‘(이)라니’를 붙여요.動詞や形容詞の後には「다니」、名詞の後には「(이)라니」を付けます。

가다→간다니동사·형용사 + 다니動詞・形容詞 + 다니가다 → 간다니멀다 → 멀다니
일 년→일 년이라니명사 + (이)라니名詞 + (이)라니일 년 → 일 년이라니다음 달 → 다음 달이라니
