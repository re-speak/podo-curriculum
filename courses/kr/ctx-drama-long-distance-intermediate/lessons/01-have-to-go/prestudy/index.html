パート 1

~다니

信じられない知らせを受け止める、最初のひと言です。

今日のパターン

意味・使い方信じがたいことを聞いて驚いたとき、「〜다니」と言います。怒るより、驚いた気持ちを込めます。

갑자기 간다니, 그게 무슨 말이야.急に行くだなんて、どういうこと？
일 년이나 떨어져 있다니 믿기지 않아.1年も離れているなんて信じられない。
다음 달이라니 너무 갑작스러워.来月だなんて、あまりにも急だよ。

다니 と 라니

動詞や形容詞の後には「다니」、名詞の後には「(이)라니」を付けます。

가다→간다니動詞・形容詞 + 다니가다 → 간다니멀다 → 멀다니
일 년→일 년이라니名詞 + (이)라니일 년 → 일 년이라니다음 달 → 다음 달이라니

合う表現を選ぼう

前のことばと意味を見て、場面に合うほうをタップしてください。

ユジンが行くだなんて！유진이 간라니/다니!
1年だなんて！일 년이라니/다니!
距離が遠いなんて！거리가 멀다니/라니!
来月だなんて！다음 달이라니/다니!

文を組み立てよう

ことばのまとまりを順番に並べて、完成した文を言ってみましょう。

急にユジンが遠くへ行くだなんて信じられない。
간다니갑자기믿기지 않아유진이 멀리
1年も離れているなんて、長すぎる。
있다니일 년이나너무 길어떨어져
来月出発するなんて、本当に驚いた。
정말다음 달에놀랐어출발한다니
こんなに急に決まったなんて、複雑な気持ちだ。
마음이이렇게 갑자기복잡해결정됐다니
パート 2

~(으)ㄴ/는지 알다

驚いたあと、わからない時間を落ち着いて確かめます。

今日のパターン

意味・使い方わからない内容を確かめるとき、「〜는지 알아？」と聞きます。動作には「는지」、状態には「(으)ㄴ지」を使います。

얼마나 가 있어야 하는지는 알아?どのくらい行っていなきゃいけないかは、わかる？
언제 출발하는지는 알아?いつ出発するかは、わかる？
거기가 얼마나 먼지는 알아?そこがどれくらい遠いかは、わかる？

는지 と (으)ㄴ지

今する動作は「는지」、状態や性質は「(으)ㄴ지」で確かめます。

머무르다→머무르는지動作 + 는지머무르다 → 머무르는지출발하다 → 출발하는지
멀다→먼지状態 + (으)ㄴ지멀다 → 먼지바쁘다 → 바쁜지

合う表現を選ぼう

前のことばと意味を見て、場面に合うほうをタップしてください。

いつ出発するかわかる？언제 출발하는지/ㄴ지 알아?
そこが遠いかわかる？거기가 머ㄴ지/는지 알아?
どのくらい滞在するかわかる？얼마나 머무르ㄴ지/는지 알아?
今忙しいかわかる？지금 바쁘ㄴ지/는지 알아?

ことばのまとまりを順番に並べて、完成した文を言ってみましょう。
