이제 같은 집으로 가자.これからは同じ家に帰ろう。
앞으로도 서로 잘 챙기자.これからもお互いを大切にしよう。

앞으로도 같이 웃자.これからも一緒に笑おう。

~자 만들기 (〜자 の作り方)

동사에서 ‘다’를 떼고 ‘자’를 붙이면 돼요.動詞から「다」を取って、「자」を付ければ完成です。

살다 → 살자 동사 + 자動詞 + 자 살다 → 살자가다 → 가자

ㄹ게와 을게 (ㄹ게 と 을게、どっち？)

동사에서 ‘다’를 떼고 봐 주세요. 받침이 있으면 ‘을게’, 없으면 ‘ㄹ게’를 붙여요.動詞から「다」を取って見てください。パッチムがあれば「을게」、なければ「ㄹ게」を付けます。

먹 → 을게 받침 있음パッチムあり 먹다 → 먹을게잡다 → 잡을게
보 → ㄹ게 받침 없음パッチムなし 보다 → 볼게보내다 → 보내ㄹ게
