パート 1

~(으)ㄴ/는 것 같다

まず、二人の関係を少しやわらかく言葉にします。

今日のパターン

意味・使い方感じたことや判断を断定しすぎず、やわらかく言うとき、「〜것 같아」を使います。

알고 보니 우리 진짜 잘 맞는 것 같아.私たち本当に気が合うみたい。
우리 많이 친해진 것 같아.私たち、かなり仲よくなったみたい。
너랑 있으면 편한 것 같아.あなたといると気楽みたい。

는것 と ㄴ것

動きを表す動詞には「는 것 같아」、状態を表す形容詞には「(으)ㄴ 것 같아」をつけます。

만나다→만나는 것 같아動きを表す言葉오다 → 오는 것 같아맞다 → 맞는 것 같아
편하다→편한 것 같아状態を表す言葉좋다 → 좋은 것 같아가깝다 → 가까운 것 같아

正しい形を選ぼう

前の言葉を見て、正しいほうをタップしてください。

よく会ってるみたい。자주 만나ㄴ 것 같아/는 것 같아.
本当にいいみたい。정말 좋은 것 같아/는 것 같아.
気が合うみたい。잘 맞는 것 같아/은 것 같아.
少し小さいみたい。조금 작는 것 같아/은 것 같아.

文を組み立てよう

ことばのまとまりを順番に並べて言ってみましょう。

私たち本当に気が合うみたい。
우리진짜잘 맞는 것 같아
私たち、かなり仲よくなったみたい。
많이친해진 것 같아우리
あなたといると気楽みたい。
편한 것 같아너랑 있으면
最近、よく会ってるみたい。

~자

最後に、これからも会おうとまっすぐ約束します。

今日のパターン

意味・使い方親しい人と、これから一緒にすることを決めて約束するとき、「〜자」と言います。

우리 오래 보자.私たち、ずっと会おう。
앞으로도 자주 만나자.これからもよく会おう。
힘들 때 서로 연락하자.つらいときはお互い連絡しよう。

動詞に 자 をつけよう

動詞から「다」を取り「자」をつけると、一緒にすることをすぐ約束できます。

만나다→만나자語幹 ＋ 자보다 → 보자연락하다 → 연락하자
