는 것과 ㄴ 것 (는것 と ㄴ것)

움직임을 말하는 동사에는 ‘는 것 같아’, 상태를 말하는 형용사에는 ‘(으)ㄴ 것 같아’를 붙여요.動きを表す動詞には「는 것 같아」、状態を表す形容詞には「(으)ㄴ 것 같아」をつけます。

만나다→만나는 것 같아동사動きを表す言葉오다 → 오는 것 같아맞다 → 맞는 것 같아
편하다→편한 것 같아형용사状態を表す言葉좋다 → 좋은 것 같아가깝다 → 가까운 것 같아

동사에 자 붙이기 (動詞に 자 をつけよう)

동사에서 ‘다’를 떼고 ‘자’를 붙이면, 함께 할 일을 바로 약속할 수 있어요.動詞から「다」を取り「자」をつけると、一緒にすることをすぐ約束できます。

만나다→만나자어간 + 자語幹 ＋ 자보다 → 보자연락하다 → 연락하자
