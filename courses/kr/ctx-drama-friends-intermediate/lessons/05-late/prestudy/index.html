パート 1

~잖아

まずは、二人とも知っている「20分」を軽く持ち出します。

今日のパターン

意味・使い方相手も知っている事実をもう一度持ち出し、「知ってるでしょ」という感じを出すとき、「〜잖아」と言います。

이십 분이나 기다렸잖아.20分も待ったじゃん。
오늘 만나기로 했잖아.今日会うことにしたじゃん。
내가 먼저 연락했잖아.私が先に連絡したじゃん。

語尾に 잖아 をつけよう

すでに知っている事実のあとに「잖아」をつけると、その事実を一緒に思い出させます。

기다렸다→기다렸잖아知っている事実 ＋ 잖아했다 → 했잖아왔다 → 왔잖아

文を組み立てよう

意味のかたまりを順番に並べて言ってみましょう。

20分も待ったじゃん。
기다렸잖아이십 분이나
今日会うことにしたじゃん。
오늘만나기로 했잖아
私が先に連絡したじゃん。
연락했잖아내가 먼저
さっき2時だと言ったじゃん。
두 시라고했잖아아까
パート 2

~(으)ㄹ 것 같다

次は、遅れそうな時の連絡をやわらかく頼みます。

今日のパターン

意味・使い方まだ確実ではないものの、これからそうなる可能性があると言うとき、「〜(으)ㄹ 것 같아」と言います。

다음엔 늦을 것 같으면 미리 연락해 줘.遅れそうなら先に連絡して。
비가 올 것 같아.雨が降りそう。
길이 막힐 것 같아.道が混みそう。

ㄹ것 と 을것

動詞や形容詞から「다」を取り、パッチムがあれば「을 것 같아」、なければ「ㄹ 것 같아」をつけます。

늦→을 것 같아パッチムあり늦다 → 늦을 것 같아막히다 → 막힐 것 같아
오→ㄹ 것 같아パッチムなし오다 → 올 것 같아가다 → 갈 것 같아

正しい形を選ぼう

前の言葉を見て、正しいほうをタップしてください。

少し遅れそう。조금 늦을 것 같아/ㄹ 것 같아.
雨が降りそう。비가 오ㄹ 것 같아/을 것 같아.
道が混みそう。길이 막히ㄹ 것 같아/을 것 같아.
もうすぐ終わりそう。곧 끝나을 것 같아/ㄹ 것 같아.

文を組み立てよう

意味のかたまりを順番に並べて言ってみましょう。
