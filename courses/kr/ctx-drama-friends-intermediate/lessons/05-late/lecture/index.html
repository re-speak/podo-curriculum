ㄹ 것과 을 것 (ㄹ것 と 을것)

동사나 형용사에서 ‘다’를 떼고, 받침이 있으면 ‘을 것 같아’, 없으면 ‘ㄹ 것 같아’를 붙여요.動詞や形容詞から「다」を取り、パッチムがあれば「을 것 같아」、なければ「ㄹ 것 같아」をつけます。

늦→을 것 같아받침 있음パッチムあり늦다 → 늦을 것 같아막히다 → 막힐 것 같아
오→ㄹ 것 같아받침 없음パッチムなし오다 → 올 것 같아가다 → 갈 것 같아

원어민 팁 (ネイティブのひとこと)

‘기다렸잖아’는 둘 다 아는 사실을 짚으면서 서운함까지 얹어요. ‘기다렸어’는 사실만 말해요 — 앞의 것은 친한 사이라서 부릴 수 있는 투정이에요.「기다렸잖아」は二人とも知っている事実を持ち出しながら、拗ねる気持ちまで乗せます。「기다렸어」は事実だけを言う言い方で、前者は親しいからこそ言える甘えです。

필요한 행동을 바로 말할 때必要な行動をそのまま言うとき미리 연락해 줘.先に連絡して。
