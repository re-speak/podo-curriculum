ㄹ래와 을래 (ㄹ래 と 을래)

동사에서 ‘다’를 떼고, 받침이 있으면 ‘을래’, 없으면 ‘ㄹ래’를 붙여요.動詞から「다」を取り、パッチムがあれば「을래」、なければ「ㄹ래」をつけます。

먹→을래받침 있음パッチムあり먹다 → 먹을래읽다 → 읽을래
보→ㄹ래받침 없음パッチムなし보다 → 볼래들다 → 들어 줄래

가다→가도ㅏ · ㅗ母音が ㅏ・ㅗ가다 → 가도오다 → 와도
먹다→먹어도그 외それ以外먹다 → 먹어도쉬다 → 쉬어도
