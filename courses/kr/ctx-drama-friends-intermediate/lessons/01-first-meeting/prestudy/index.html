今日のパターン

意味・使い方前に見たことがある、と声をかけるときに使います。

우리 어디서 본 적 있지 않아요? 私たち、どこかで会ったことありませんか？
한국에 간 적 있어요.韓国に行ったことがあります。
그 사람 만난 적 없어요.あの人に会ったことはありません。

ㄴ적 と 은적、どっち？

動詞から「다」を取って、残った文字を見てください。パッチムがあれば「은 적」、なければ「ㄴ 적」です。

먹 → 은 적 パッチムあり（子音で終わる） 먹다 → 먹은 적읽다 → 읽은 적
보 → ㄴ 적 パッチムなし（母音で終わる） 보다 → 본 적가다 → 간 적

ㄴ と 은 を選ぼう

パッチムを見て、正しいほうをタップしてください。

トッポッキを食べたことがあります。 떡볶이 먹은/ㄴ 적 있어요.
あのカフェに行ったことがあります。 그 카페에 가은/ㄴ 적 있어요.
読んだことがあります。 읽ㄴ/은 적 있어요.
会ったことがあります。 만나ㄴ/은 적 있어요.

아도 と 어도、どっち？

動詞から「다」を取って、最後の母音を見てください。ㅏかㅗなら「아도」、それ以外は全部「어도」です。

앉 / 놀 → 아도 最後の母音が ㅏ か ㅗ 앉다 → 앉아도놀다 → 놀아도
먹 / 찍 → 어도 ㅓ ㅜ ㅡ ㅣ … それ以外の母音 먹다 → 먹어도찍다 → 찍어도

아도 と 어도 を選ぼう

最後の母音を見て、正しいほうをタップしてください。

ここに座ってもいいですか？ 여기 앉아도/어도 돼요?
これ、食べてもいいですか？ 이거 먹아도/어도 돼요?
写真を撮ってもいいですか？ 사진 찍어도/아도 돼요?
これ、もらってもいいですか？ 이거 받아도/어도 돼요?
