私の番

シーンに出てきた表現です。友だちに話すように、3つの文を読んでみましょうか？

이번엔 내 차례야.今回は私の番。
다음은 네 차례야.次はあなたの番。
누구 차례지?誰の番だっけ？
パート 1

~(으)ㄹ게

まず、今日の会計は自分が引き受けると約束します。

今日のパターン

意味・使い方相手に、今自分がすると約束したり引き受けることを言うとき、「〜(으)ㄹ게」と言います。

오늘은 내가 살게.今日は私がおごる。
이번에는 내가 낼게.今回は私が払う。
커피는 내가 살게.コーヒーは私がおごる。

ㄹ게 と 을게

動詞から「다」を取り、パッチムがあれば「을게」、なければ「ㄹ게」をつけます。

먹→을게パッチムあり먹다 → 먹을게갚다 → 갚을게
사→ㄹ게パッチムなし사다 → 살게내다 → 낼게

正しい形を選ぼう

前の言葉を見て、正しいほうをタップしてください。

私が食べるね。내가 먹ㄹ게/을게.
私がおごる。내가 사ㄹ게/을게.
私が払う。내가 내을게/ㄹ게.
私が読むね。내가 읽ㄹ게/을게.

文を組み立てよう

ことばのまとまりを順番に並べて言ってみましょう。

今日は私がおごる。
내가살게오늘은
今回は私が払う。
이번에는낼게내가
コーヒーは私がおごる。
내가커피는살게
次は必ず返すね。
꼭갚을게다음엔
パート 2

~(으)니까

次は、自分が払う理由をユジンに伝えます。

今日のパターン

意味・使い方自分の判断や提案の理由をはっきり言うとき、「〜(으)니까」を使います。

저번에 네가 샀으니까 이번엔 내 차례지.前回はあなたがおごったから、今回は私の番でしょ。
오늘은 내가 초대했으니까 내가 낼게.今日は私が誘ったから、私が払う。
네가 도와줬으니까 커피는 내가 살게.手伝ってくれたから、コーヒーは私がおごる。

니까 と 으니까

動詞や形容詞から「다」を取り、パッチムがあれば「으니까」、なければ「니까」をつけます。

먹→으니까パッチムあり먹다 → 먹으니까있다 → 있으니까
사→니까パッチムなし사다 → 사니까도와주다 → 도와주니까

正しい形を選ぼう

前の言葉を見て、正しいほうをタップしてください。

食べるから。먹으니까/니까.
買うから。사니까/으니까.
あるから。있니까/으니까.
手伝うから。도와주으니까/니까.

文を組み立てよう

ことばのまとまりを順番に並べて言ってみましょう。

前回はあなたがおごったから、今回は私の番でしょ。
이번엔 내 차례지네가 샀으니까저번에
今日は私が誘ったから、私が払う。
내가 낼게내가 초대했으니까오늘은
手伝ってくれたから、コーヒーは私がおごる。
커피는 내가 살게네가 도와줬으니까
時間があるから、ゆっくり食べよう。
천천히 먹자시간이 있으니까
パート 3

이제 당신 차례예요

2つのパターンがそろいました。第8話の「나」は、ここからあなたです。
