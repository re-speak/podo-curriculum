ㄹ 줄과 을 줄 (ㄹ줄 と 을줄、どっち？)

동사에서 다를 떼고, 남은 글자를 봐 주세요. 받침이 있으면 ‘을 줄’, 없으면 ‘ㄹ 줄’이에요.動詞から「다」を取って、残った文字を見てください。パッチムがあれば「을 줄」、なければ「ㄹ 줄」です。

먹 → 을 줄 받침 있음パッチムあり（子音で終わる） 먹다 → 먹을 줄웃다 → 웃을 줄
보 → ㄹ 줄 받침 없음パッチムなし（母音で終わる） 보다 → 볼 줄오다 → 올 줄

ㄹ과 을 고르기 (ㄹ と 을 を選ぼう)

받침을 보고, 맞는 쪽을 눌러 보세요.パッチムを見て、正しいほうをタップしてください。

나 봐와 ㄴ가 봐 (나봐 と ㄴ가봐、どっち？)

움직임을 나타내는 말이면 ‘나 봐’, 상태를 나타내는 말이면 ‘ㄴ가 봐’예요.動きを表す言葉なら「나 봐」、状態を表す言葉なら「ㄴ가 봐」です。

살다는 사나 봐로 ㄹ이 떨어진다고 알려 주세요.
가다 → 나 봐 동사動きを表す言葉 가다 → 가나 봐먹다 → 먹나 봐
바쁘다 → ㄴ가 봐 형용사状態を表す言葉 바쁘다 → 바쁜가 봐좋다 → 좋은가 봐
