언젠가 (いつか)

‘언젠가’는 날짜를 정하지 않은 미래를 말해요. 부담 없이 앞날을 꺼낼 때 잘 어울려요. 네 문장을 읽어 볼까요?「언젠가」は、日付を決めていない未来を表します。負担をかけずに将来を話すときによく合います。4つの文を読んでみましょうか？

언젠가라는 말도 설레네.「いつか」ということばもわくわくするね。

는다면과 ㄴ다면 (는다면 と ㄴ다면)

동사 어간에 받침이 있으면 ‘는다면’, 없거나 ‘ㄹ’ 받침이면 ‘ㄴ다면’를 써요.動詞の語幹にパッチムがあれば「는다면」、なければ、またはㄹパッチムなら「ㄴ다면」を使います。

먹→먹는다면받침 있음パッチムあり・는다면먹다 → 먹는다면받다 → 받는다면
가→간다면받침 없음パッチムなし・ㄴ다면가다 → 간다면고르다 → 고른다면
살→산다면ㄹ 받침ㄹパッチム・ㄴ다면살다 → 산다면놀다 → 논다면

을 뿐과 ㄹ 뿐 (을 뿐 と ㄹ 뿐)

받침이 있으면 ‘을 뿐’, 없으면 ‘ㄹ 뿐’을 붙여요. 이미 한 일은 ‘았/었을 뿐’으로 말해요.パッチムがあれば「을 뿐」、なければ「ㄹ 뿐」を付けます。すでにしたことは「았／었을 뿐」で言います。

먹→먹을 뿐받침 있음パッチムあり먹다 → 먹을 뿐있다 → 있을 뿐
보→볼 뿐받침 없음パッチムなし보다 → 볼 뿐상상하다 → 상상했을 뿐
