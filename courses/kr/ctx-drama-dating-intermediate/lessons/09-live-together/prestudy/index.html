今日のゴール

さっきのシーンのように、まだ早いと分かりながら、一緒に暮らす未来を仮定として話します。

いつか

「언젠가」は、日付を決めていない未来を表します。負担をかけずに将来を話すときによく合います。4つの文を読んでみましょうか？

언젠가 같이 여행 가자.いつか一緒に旅行しよう。
언젠가 이런 집에서 살고 싶어.いつか、こんな家に住みたい。
언젠가 꼭 다시 와 보자.いつか必ずまた来よう。
언젠가라는 말도 설레네.「いつか」ということばもわくわくするね。
パート 1

~(느)ㄴ다면

まず、「今すぐ」ではない未来を仮定として描きます。

今日のパターン

意味・使い方まだ決まっていないことや、実現が先のことを仮定して想像するときに使います。

언젠가 같이 산다면 어떨 것 같아?いつか一緒に暮らすとしたら、どう思う？
둘이 산다면 아침은 누가 할까?ふたりで暮らすとしたら、朝ごはんはだれが作る？
집을 고른다면 어디가 좋을까?家を選ぶとしたら、どこがいいかな？

는다면 と ㄴ다면

動詞の語幹にパッチムがあれば「는다면」、なければ、またはㄹパッチムなら「ㄴ다면」を使います。

먹→먹는다면パッチムあり・는다면먹다 → 먹는다면받다 → 받는다면
가→간다면パッチムなし・ㄴ다면가다 → 간다면고르다 → 고른다면
살→산다면ㄹパッチム・ㄴ다면살다 → 산다면놀다 → 논다면

正しい形を選ぼう

文を読んで、正しいほうをタップしてください。

一緒に暮らすとしたら、どう思う？같이 살는다면/산다면 어떨 것 같아?
家を選ぶとしたら、どこがいい？집을 고르는다면/고른다면 어디가 좋아?
毎朝食べるとしたら、何がいい？매일 아침 먹는다면/ㄴ다면 뭐가 좋아?
週末に遊ぶとしたら、何をする？주말에 놀는다면/논다면 뭐 할까?

文を組み立てよう

ことばのまとまりを順番に並べて、文全体を言ってみましょう。

週末を一緒に過ごすとしたら、何からしよう？

パート 2

~(으)ㄹ 뿐이야

相手の反応を見ながら、今すぐ決める話ではないとやわらげます。

今日のパターン

意味・使い方ほかの意図や行動はなく、言ったそれだけだと範囲をしぼるときに使います。

그냥 그런 생각이 들었을 뿐이야.ただ、そんな考えが浮かんだだけ。
한번 상상해 봤을 뿐이야.一度、想像してみただけ。
네 생각이 궁금했을 뿐이야.ユジンの考えが気になっただけ。

을 뿐 と ㄹ 뿐

パッチムがあれば「을 뿐」、なければ「ㄹ 뿐」を付けます。すでにしたことは「았／었을 뿐」で言います。

먹→먹을 뿐パッチムあり먹다 → 먹을 뿐있다 → 있을 뿐
보→볼 뿐パッチムなし보다 → 볼 뿐상상하다 → 상상했을 뿐

正しい形を選ぼう

文を読んで、正しいほうをタップしてください。

ただ考えただけ。그냥 생각했을 뿐이야/ㄹ 뿐이야
