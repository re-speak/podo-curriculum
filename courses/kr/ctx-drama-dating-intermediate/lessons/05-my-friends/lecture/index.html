은 N과 ㄴ N (은 N と ㄴ N)

받침이 있으면 ‘은’, 없으면 ‘ㄴ’을 붙여서 뒤의 명사를 꾸며요. ‘ㄹ’ 받침은 빠지고 ‘ㄴ’이 붙어요.パッチムがあれば「은」、なければ「ㄴ」を付けて後ろの名詞を説明します。ㄹパッチムは取れて「ㄴ」が付きます。

먹→먹은 음식받침 있음パッチムあり먹다 → 먹은 음식읽다 → 읽은 책
오→온 친구받침 없음パッチムなし오다 → 온 친구말하다 → 말한 사람

아도와 어도 (아도 と 어도)

마지막 모음이 ‘ㅏ·ㅗ’면 ‘아도’, 나머지는 ‘어도’를 붙여요. ‘하다’는 ‘해도’가 돼요.最後の母音が「ㅏ・ㅗ」なら「아도」、それ以外は「어도」を付けます。「하다」は「해도」になります。

앉→앉아도ㅏ · ㅗㅏ・ㅗ・아도앉다 → 앉아도놀다 → 놀아도
먹→먹어도나머지 모음それ以外・어도먹다 → 먹어도물어보다 → 물어봐도
하다→해도하다하다・해도말하다 → 말해도편하게 하다 → 편하게 해도
