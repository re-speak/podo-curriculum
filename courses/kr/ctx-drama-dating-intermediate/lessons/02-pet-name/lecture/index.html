을까와 ㄹ까 (을까 と ㄹ까)

받침이 있으면 ‘을까’, 없으면 ‘ㄹ까’를 붙여요. ‘ㄹ’ 받침은 그대로 ‘까’를 붙여요.パッチムがあれば「을까」、なければ「ㄹ까」を付けます。ㄹパッチムには、そのまま「까」を付けます。

먹→먹을까받침 있음パッチムあり먹다 → 먹을까입다 → 입을까
가→갈까받침 없음パッチムなし가다 → 갈까부르다 → 부를까

은 것 같아와 는 것 같아 (은 것 같아 と 는 것 같아)

형용사는 받침에 따라 ‘은/ㄴ 것 같아’, 동사는 ‘는 것 같아’를 써요.形容詞はパッチムに合わせて「은／ㄴ 것 같아」、動詞は「는 것 같아」を使います。

편→편한 것 같아형용사形容詞・은/ㄴ편하다 → 편한 것 같아좋다 → 좋은 것 같아
어울리다→어울리는 것 같아동사動詞・는어울리다 → 어울리는 것 같아웃다 → 웃는 것 같아
