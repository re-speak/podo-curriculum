今日のゴール

さっきのシーンのように、呼び方を提案して、気恥ずかしいものは笑いながら選び分けます。

照れくさい

「낯간지럽다」は、やさしいことばを言ったり聞いたりするときの、照れくさくて気恥ずかしい感じです。自然に読んでみましょうか？

그렇게 부르니까 좀 낯간지럽다.そう呼ばれると、ちょっと照れくさい。
처음에는 조금 낯간지러웠어.最初は少し照れくさかった。
다정한 말을 하려니 낯간지럽네.やさしいことを言おうとすると照れくさいね。
그래도 싫지는 않아.でも、嫌ではないよ。
パート 1

~(으)ㄹ까?

まず、ふたりで試したい呼び方を提案します。

今日のパターン

意味・使い方一緒にすることを軽く提案して、相手の気持ちを聞くときに使います。

이제 이름 말고 다르게 불러 볼까?これからは名前じゃなくて、違う呼び方にしてみる？
둘만 있을 때만 써 볼까?ふたりだけのときに使ってみる？
짧은 애칭으로 정할까?短い愛称に決めようか？

을까 と ㄹ까

パッチムがあれば「을까」、なければ「ㄹ까」を付けます。ㄹパッチムには、そのまま「까」を付けます。

먹→먹을까パッチムあり먹다 → 먹을까입다 → 입을까
가→갈까パッチムなし가다 → 갈까부르다 → 부를까

正しい形を選ぼう

文を読んで、正しいほうをタップしてください。

短い愛称に決めようか？짧은 애칭으로 정하을까?/정할까?
この呼び方を使ってみようか？이 호칭을 써 보을까?/써 볼까?
どれがいいか探そうか？어떤 게 좋은지 찾을까?/찾ㄹ까?
そのまま名前で呼ぼうか？그냥 이름으로 부르을까?/부를까?

文を組み立てよう

ことばのまとまりを順番に並べて、文全体を言ってみましょう。

これからは名前じゃなくて、違う呼び方にしてみる？
다르게이제 이름 말고불러 볼까?
ふたりだけのときに使ってみる？
써 볼까?둘만있을 때만
私たち、短い愛称に決めようか？
정할까?우리짧은 애칭으로

パート 2

~(으)ㄴ/는 것 같아

候補を出したら、どんな感じがするかやわらかく伝えます。

今日のパターン

意味・使い方はっきり断定せず、自分の感じや考えをやわらかく言うときに使います。

그건 좀 오글거리는 것 같은데.それはちょっと気恥ずかしい気がする。
이건 덜 어색한 것 같아.これはあまり気まずくない気がする。
이름이 제일 편한 것 같아.名前がいちばん気楽な気がする。

은 것 같아 と 는 것 같아

形容詞はパッチムに合わせて「은／ㄴ 것 같아」、動詞は「는 것 같아」を使います。

편→편한 것 같아形容詞・은/ㄴ편하다 → 편한 것 같아좋다 → 좋은 것 같아
어울리다→어울리는 것 같아動詞・는어울리다 → 어울리는 것 같아웃다 → 웃는 것 같아

正しい形を選ぼう

文を読んで、正しいほうをタップしてください。

この呼び方は気楽な気がする。이 호칭은 편하은 것 같아/편한 것 같아
その呼び方は少し短い気がする。그 호칭은 좀 짧은 것 같아/짧ㄴ 것 같아
これは私たちに似合う気がする。이건 우리한테 어울리는 것 같아/어울리ㄴ 것 같아
ユジンが笑っている気がする。유진이 웃은 것 같아/는 것 같아

文を組み立てよう

ことばのまとまりを順番に並べて、文全体を言ってみましょう。

それはちょっと気恥ずかしい気がする。
오글거리는 것 같은데그건좀
これはあまり気まずくない気がする。
덜이건어색한 것 같아
名前がいちばん気楽な気がする。
제일이름이편한 것 같아
これは私たちによく似合う気がする。
우리한테이건잘어울리는 것 같아
