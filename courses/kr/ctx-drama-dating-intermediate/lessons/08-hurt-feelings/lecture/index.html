았으면과 었으면 (았으면 と 었으면)

마지막 모음이 ‘ㅏ·ㅗ’면 ‘았으면’, 나머지는 ‘었으면’이에요. ‘하다’는 ‘했으면’이 돼요.最後の母音が「ㅏ・ㅗ」なら「았으면」、それ以外は「었으면」です。「하다」は「했으면」になります。

가 → 갔으면 ㅏ · ㅗ았으면 가다 → 갔으면오다 → 왔으면
먹 → 먹었으면 나머지 모음それ以外の母音・었으면 먹다 → 먹었으면늦다 → 늦었으면
하다→했으면 하다했으면 말하다 → 말했으면연락하다 → 연락했으면
