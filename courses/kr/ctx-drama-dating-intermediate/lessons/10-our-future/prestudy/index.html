今日のワンシーン

元日、今年一緒にしたいことを書くシーンです。穏やかにこれからを描きながら読んでみましょうか？

유진
우리 벌써 새해를 같이 맞네.私たち、もう一緒に新年を迎えるんだね。
나
시간이 갈수록 더 좋아지는 것 같아.時間がたつほど、もっと好きになる気がする。
유진
나도. 처음보다 훨씬 편해졌어.私も。最初よりずっと気楽になった。
나
올해 같이 하고 싶은 거 하나씩 적어 볼까?今年、一緒にしたいことを1つずつ書いてみる？
유진
좋아. 나는 같이 여행 가기.いいね。私は一緒に旅行すること。
나
나 진짜 잘해야겠다.私、本当にもっと大切にしないと。
유진
지금도 잘하고 있어.今も十分大切にしてくれてるよ。
나
그래도 앞으로 더 자주 표현할게.それでも、これからもっとよく気持ちを伝えるよ。
ゴール

今日のゴール

さっきのシーンのように、時間とともに深まった気持ちを伝え、もっと大切にすると自分に誓います。

これから

「앞으로」は、今から続く時間を表します。約束や決意の前に置くと、気持ちの向きがはっきりします。4つの文を読んでみましょうか？

앞으로 더 자주 말할게.これからは、もっとよく言うね。
앞으로도 같이 많이 웃자.これからも一緒にたくさん笑おう。
앞으로 바쁠 때도 꼭 연락할게.これからは忙しいときも必ず連絡する。
앞으로가 더 기대돼.これからがもっと楽しみ。
パート 1

~(으)ㄹ수록

まず、時間とともに大きくなった気持ちを伝えます。

今日のパターン

意味・使い方ある行動や時間が続くほど、程度がさらに大きくなるときに使います。

시간이 갈수록 더 좋아지는 것 같아.時間がたつほど、もっと好きになる気がする。
함께할수록 더 편해져.一緒にいるほど、もっと気楽になる。
이야기할수록 서로 잘 알게 돼.話すほど、お互いをよく知るようになる。

을수록 と ㄹ수록

パッチムがあれば「을수록」、なければ、またはㄹパッチムなら「ㄹ수록」を付けます。

먹→먹을수록パッチムあり먹다 → 먹을수록알다 → 알수록
가→갈수록パッチムなし가다 → 갈수록함께하다 → 함께할수록

正しい形を選ぼう

文を読んで、正しいほうをタップしてください。

時間がたつほど、もっと好きになる。시간이 갈수록/가을수록 더 좋아져.
話すほど、よく分かる。이야기할수록/이야기하을수록 잘 알게 돼.
知るほど、もっと気楽になる。알수록/알을수록 더 편해져.
一緒にいるほど、笑うことが増える。함께하을수록/함께할수록 많이 웃게 돼.

文を組み立てよう

ことばのまとまりを順番に並べて、文全体を言ってみましょう。

時間がたつほど、もっと好きになる気がする。
더 좋아지는 것 같아시간이갈수록
時間を一緒に過ごすほど、もっと気楽になる。
더 편해져시간을함께할수록
話すほど、お互いをよく知るようになる。
서로잘 알게 돼이야기할수록
考えるほど、ありがたいことが多い。
고마운 일이생각할수록많아
パート 2

~아/어야겠다

気持ちを伝えたら、これから自分がしたいことを決意します。

今日のパターン

意味・使い方状況を見て、今すべきことに自分で気づき、決意するときに使います。

나 진짜 잘해야겠다.私、本当にもっと大切にしないと。
올해는 더 자주 표현해야겠다.今年はもっとよく気持ちを伝えないと。
약속은 꼭 지켜야겠다.約束は必ず守らないと。

아야 と 어야

最後の母音が「ㅏ・ㅗ」なら「아야」、それ以外は「어야」を付けます。「하다」は「해야」になります。

잡→잡아야ㅏ・ㅗ・아야잡다 → 잡아야보다 → 봐야
지키→지켜야それ以外・어야지키다 → 지켜야먹다 → 먹어야
하다→해야하다・해야연락하다 → 연락해야잘하다 → 잘해야

正しい形を選ぼう

文を読んで、正しいほうをタップしてください。

約束は必ず守らないと。약속은 꼭 지키아야겠다/지켜야겠다
もっとよく表現しないと。더 자주 표현하아야겠다/표현해야겠다
相手の手をしっかり握らないと。손을 꼭 잡아야겠다/어야겠다
忙しいときも連絡しないと。바쁠 때도 연락하아야겠다/연락해야겠다

文を組み立てよう

ことばのまとまりを順番に並べて、文全体を言ってみましょう。

私、本当にもっと大切にしないと。
나진짜잘해야겠다
今年はもっとよく気持ちを伝えないと。
더 자주올해는표현해야겠다
約束は必ず守らないと。
꼭약속은지켜야겠다
忙しいときも、短くても連絡しないと。
연락해야겠다바쁠 때도짧게
