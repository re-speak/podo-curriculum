ゴール

今日のゴール

今日は新しく勉強する文字はありません。パッチムの移動と ㅎ の音の変化、この2つだけを練習します。

パート 1

パッチムが移る

1つめ。今日練習する変化のなかで、これがいちばんよく出ます。

移る先の席

ㅇ は音がありません。席が空いています。だから前のパッチムが、その空いた席へ移ります。

국어 → 구거 次が ㅇ ＝ 空いた席。パッチムが移る 한국어 → 한구거음악 → 으막
김치 → 김치 次が子音 ＝ 席はふさがっている。そのまま 안녕 → 안녕언니 → 언니

移る単語さがし

パッチムの次に ㅇ が来る単語を、全部タップしてください。3つあります。

二重パッチムも移る

二重パッチムは、ふだんは片方しか音が出ませんね。でも次に ㅇ が来ると、かくれていた文字が移ります。

값이 → 갑씨 かくれていた ㅅ が移る。移った ㅅ は強く「ㅆ」 값 → 갑값이 → 갑씨
パート 2

ㅎ の音が変わる

2つめ。ㅎ のあとに、どの文字が来るかを見ましょう。

パッチム ㅎ の2つの顔

次が ㅇ なら ㅎ は消えます。ㄱ・ㄷ・ㅈ なら息を足して、ㅋ・ㅌ・ㅊ と読みます。

좋아 → 조아 ㅎ は音を残さずに消える 좋아요 → 조아요넣어요 → 너어요
많다 → 만타 息を足して ㅋ・ㅌ・ㅊ 좋다 → 조타싫다 → 실타
ㅇ の前では消えるㄱ・ㄷ・ㅈ の前では強い息
