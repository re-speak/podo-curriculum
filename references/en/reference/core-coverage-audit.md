# Core Coverage and Disposition Audit

**Status:** read-only audit during native catalog review  
**Audited:** 2026-08-13  
**Scope:** 122 Core lessons; no TOC or generated catalog edits

## Verdict

The Core spine is broadly coherent, but it is not ready to freeze unchanged. The audit found:

- **3 high-value beginner functions absent as primary Core targets;**
- **1 important function only partially covered;**
- **3 exact duplicate pattern frames;**
- **2 advanced lessons that should probably be demoted from primary production;** and
- **1 pair of lessons that the TOC itself says should be one contrastive lesson.**

The cleanest correction does not increase the 122-lesson total: merge or demote redundant advanced
material and use the recovered slots for ability, activity preferences and invitations.

This is a triage result, not permission to edit the active review surface. Native feedback and the
corpus/naturalness pass still decide exact wording.

## 1. Disposition of the six evidence-priority lessons

| Lesson | Audit disposition | Why | Replacement or next check |
| --- | --- | --- | --- |
| **Core 76** `have something done` | **merge with 77** | Useful service function, but no direct Core Inventory item was found. More importantly, Core 77's own JP note says the two causatives should be paired and contrasted in one lesson. | One contrastive service/arrangement lesson; verify both forms in EGP or an authorized equivalent. |
| **Core 77** `get someone to do` | **merge with 76** | Separate treatment contradicts its own teaching rationale and spends two lessons on one Japanese `てもらう` contrast. | Preserve the contrast, not two lesson slots. |
| **Core 79** future perfect | **demote unless workplace evidence is strong** | The Core Inventory places future perfect at B2; the current band is B1+. The TOC itself calls the form low-frequency in speech and a likely demotion candidate. | Keep `by Friday` deadline language in Core 80 or 82; make future perfect optional grammar unless corpus/native review earns production. |
| **Core 84** diplomatic request | **keep provisionally** | The communicative need is strong and completes the politeness progression. The evidence gap concerns the exact exponent and band, not the need. | Native/corpus check `I was wondering if you could`; treat B1+ as provisional. |
| **Core 105** negative-adverbial inversion | **demote** | The Core Inventory associates this with C1, not the current B2 band. The TOC independently calls it low-frequency in speech and its strongest demotion candidate. | Keep `not only ...` as an expression or receptive item; do not require productive `Never have I ...`. |
| **Core 112** `With all due respect` | **make receptive or remove as a Core lesson** | Its own note says “receptive first” and warns that learner production can start a fight. That conflicts with Core's two-primary-production-pattern contract. | Move recognition to Contextual/Freetalking support; retain only if native review supplies a safe productive outcome. |

### Practical result

Merging 76/77 and demoting 79, 105 and 112 can recover **up to four slots**. These slots are better
spent on the missing beginner functions below. Core 84 does not need removal unless native review
rejects its wording.

## 3. Duplicate and competing lessons

### Exact duplicate pattern strings

| Pattern | Lessons | Audit |
| --- | --- | --- |
| `I don't ___.` | Core 14 and 27 | Core 14 owns present-simple negation. Core 27 should be rewritten around a communicative preference or mental-state exchange, not count the same shell again. |
| `I'm not sure ___.` | Core 18 and 85 | Core 18 owns uncertainty. Core 85 should rely on `I see your point, but ...` and use a genuinely more advanced second move. |
| `Let's just say ___.` | Core 119 and 121 | Direct duplication two lessons apart. Merge the restraint/vagueness outcomes or replace one pattern. |

### Near-duplicate lesson functions

- **Core 85 and 95** both teach acknowledge-then-disagree (`I see your point, but` / `I take your
  point, but`). The B2 version needs a materially different discourse job or the pair should merge.
- **Core 93 and 115** both teach concede-then-counter. A level progression may justify both, but the
  corpus audit must show that Core 115 adds more than elevated vocabulary.
- **Core 119 and 121** are not merely related: they share a primary pattern and both withhold detail.
  One lesson should own this move.

Graded recurrences such as Core 20→60→84→108 requests, Core 21→61 permission, and Core 57→66
conditionals are not duplicates. Their communicative pressure or form changes materially at each
stage.

## 4. Inventory items that should not automatically become lessons

The inverse comparison also found source items absent from primary patterns that should remain
support, lexical metadata or deliberate exclusions:

- **Possessive `’s`, question tags and phrasal-verb splitting:** useful forms, but not independent
  communicative outcomes. Carry them in grammar support, expressions or vocabulary provenance.
- **Zero conditional:** add as support beside Core 57 if needed; it does not automatically deserve a
  separate two-pattern lesson.
- **Extended passive range and mixed conditionals:** valid B2/C1 language, but require a real spoken
  can-do before occupying Core slots.
- **Future perfect continuous:** keep excluded. The curriculum's existing boundary and Cambridge's
  public EGP discussion both identify it as low-frequency; source presence alone is not a reason to
  teach it.

## 5. Level and endpoint finding

Individual C1-associated expressions do not demonstrate C1 proficiency. Core 108–122 supplies
useful register, stance and implication language, but the CEFR's C1 claims concern flexible,
precise and sustained performance as well as possession of exponents. Until representative lessons
and recorded performance exist, describe this section as a **C1 bridge / C1-associated language**,
not evidence that completing Core produces a C1 speaker.

This is a product-claim correction, not necessarily a reason to delete Units 20–22.
