    유명하다 → 유명했습니다・유명했어요（有名でした）

┌──────────────────────────────────────────────────────────────┐
│ (6) 名詞の場合は                                              │

└──────────────────────────────────────────────────────────────┘

例) 수도이다 → 수도였습니다・수도였어요（首都でした）
    학생이다 → 학생이었습니다・학생이었어요（学生でした）
    식당이 아니다 → 식당이 아니었습니다・식당이 아니었어요
