A different career you might have chosen (選んでいたかもしれない別のキャリア)

Let's explore what makes another career interesting. Please read the title aloud.別のキャリアが興味深く感じられる理由を考えましょう。タイトルを声に出して読んでください。

Have the learner read the title once, then move on.

An alternative path can clarify present values (別の進路から今の価値観が見える)

Did you have any questions about the article?記事について何か質問はありましたか？

Answer the learner's questions, then move on. If there are none—or the learner did not complete the pre-study—skip the article; do not spend class time reading it.
An imagined career path is not the same as a plan to leave.別のキャリアを想像しても、辞める計画があるとは限りません。career pathキャリアの進路
Career paths can include paid work, study, care, creative work, and service.キャリアの進路には、仕事、勉強、ケア、創作、社会への貢献などがあります。
A different path may appeal because of the work itself.別の進路は、仕事そのものに魅力がある場合があります。
A public or fictional person can provide an example.公に知られた人や架空の人物を例にできます。
Every path has gains and limits.どの進路にも、得るものと制約があります。
Timing can affect whether a path was realistic.その進路が現実的だったかは、時期にも左右されます。
A path not taken can still influence present choices.選ばなかった進路も、今の選択に影響することがあります。
Regret is only one possible response.別の進路に対する気持ちは、後悔だけではありません。
Values can remain stable even when jobs change.仕事が変わっても、価値観は変わらないことがあります。
Imagining another path can reveal one change worth making now.別の進路を想像すると、今できる小さな変更が見えることがあります。

8 QUESTION POOL

Let's talk (話そう)

We don't need to answer every question. Let's follow the most interesting parts of your answers.全部の質問に答える必要はありません。答えの中でいちばん面白いところを広げていきましょう。

Treat these pages as a pool, not a sequence. React or share briefly before choosing the next prompt, skip freely, and move to feedback with 2–3 minutes left.

Another path (別の進路)

WARM-UP 1Which alternative career would be most interesting to try for one year?どの別のキャリアを一年間試すと最も面白そうですか？

Follow up
  • What first drew your attention to the career?
  • If no career comes to mind, which sounds better: creative, practical, or people-focused work?

A normal day (普通の一日)

WARM-UP 2What would a normal day in a job you'd like to try actually look like?試してみたい仕事の普通の一日は、実際にはどんな一日ですか？

Follow up
  • Which task would take the most time?
  • Which part might be less enjoyable?

The disappointing part (がっかりしそうな点)

QUESTION 1What might disappoint you about a career that looks exciting?面白そうに見える仕事でも、どんな点にはがっかりしそうですか？

Follow up
  • Which daily task could become tiring?
  • Would you still try it for a year?

What made it possible (可能にする条件)

QUESTION 2What would make a different career possible to try?別のキャリアを試せるようにするには、何が必要ですか？

Follow up
  • Would time, money, training, location, or family duties be hardest?
  • What small test could happen before a full career change?

A useful skill (役立つスキル)

QUESTION 3Which skill from your current life would help in a different career?今の生活で身につけたどんなスキルが、別の仕事でも役立ちますか？

Follow up
  • Where did you learn it?
  • What new skill would you still need?

How it feels now (今の気持ち)

QUESTION 4How might someone feel about a career they never chose?実現しなかったキャリアは、時間とともにどんな感情を生み得ますか？

Follow up
  • Would you feel curious, regretful, relieved, or none of these?
  • What could make that reaction different later?

A value to use now (今生かせる価値)

QUESTION 5Which part of another career could fit into life as a hobby or side project?別のキャリアのどの部分なら、趣味や小さなプロジェクトとして生活に取り入れられますか？

Follow up
  • Could a course, volunteer role, or weekend project test it?
  • What would remain impossible without changing careers?

Advice to a younger person (若い人への考え)

QUESTION 6What should a young person ask before choosing a career?若い人は、キャリアを選ぶ前に何を質問すべきですか？

Follow up
  • Which attractive promise should they check carefully?
  • Who could tell them about the difficult parts?

Today's feedback (今日のフィードバック)

Before we finish, here's one strength and one thing to focus on next.最後に、よかった点を一つと、次に意識する点を一つ伝えます。

Before closing, ask the learner to repeat one useful correction.
